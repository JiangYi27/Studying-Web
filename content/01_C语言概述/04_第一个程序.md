# 第一个程序：Hello World 详解

## 编写第一个 C 程序

### 完整代码

```c
#include <stdio.h>

int main(void) {
    printf("Hello, World!\n");
    return 0;
}
```

### 代码逐行解析

#### `#include <stdio.h>`

预处理指令，告诉编译器在编译前将标准输入输出头文件的内容包含到当前文件中。

- `stdio.h` 是 "Standard Input Output Header" 的缩写
- 该头文件声明了 `printf`、`scanf`、`fprintf`、`fscanf` 等输入输出函数
- 使用 `<>` 表示从系统标准路径搜索头文件
- 使用 `""` 表示先从当前目录搜索，适用于用户自定义头文件

#### `int main(void)`

主函数，每个 C 程序有且仅有一个主函数。

- **`int`**：主函数的返回类型是整数
- **`main`**：函数名，固定为 `main`，是程序的入口点
- **`(void)`**：参数列表为空，表示主函数不接受任何参数
- **`{` 和 `}`**：函数体开始和结束的花括号

> **注意**：在 C 语言中，`main` 也可以写成 `int main(int argc, char *argv[])` 来接收命令行参数。

#### `printf("Hello, World!\n");`

格式化输出函数，将字符串输出到标准输出（通常是终端/控制台）。

- **`printf`**：格式化输出函数，定义在 `stdio.h` 中
- **`"Hello, World!\n"`**：格式字符串
  - `Hello, World!` 是要输出的文本
  - `\n` 是转义字符，表示换行
- **`;`**：C 语句必须以分号结尾

#### `return 0;`

`return` 语句结束函数的执行并返回值。

- `main` 函数返回 `0` 表示程序正常结束
- 返回非零值（通常为 `1`）表示程序异常终止
- 操作系统可以通过返回值判断程序是否执行成功

## 编译和链接过程详解

C 程序的编译过程分为四个阶段，理解这个过程对排查编译错误非常重要。

### 四个阶段

```
C源代码 (.c) → 预处理 → 编译 → 汇编 → 链接 → 可执行文件
```

### 1. 预处理（Preprocessing）

预处理器处理源代码中的预处理指令：

- **`#include`**：将头文件的内容插入到当前位置
- **`#define`**：展开宏定义
- **条件编译**：处理 `#ifdef`、`#ifndef`、`#if`、`#elif`、`#else`、`#endif`
- **删除注释**：移除所有注释内容

```bash
# 仅执行预处理，生成 .i 文件
gcc -E hello.c -o hello.i
```

预处理后的 `hello.i` 文件包含了所有头文件展开后的完整代码。

### 2. 编译（Compilation）

编译器将预处理后的 C 代码翻译成汇编语言：

- 进行词法分析（将源代码分解为记号/token）
- 进行语法分析（构建语法树）
- 进行语义分析（检查类型匹配等）
- 进行代码优化
- 生成汇编代码

```bash
# 编译到汇编代码，生成 .s 文件
gcc -S hello.i -o hello.s
```

### 3. 汇编（Assembly）

汇编器将汇编代码翻译成机器语言（二进制指令）：

- 将汇编指令翻译为对应的机器码
- 生成目标文件（Object File）

```bash
# 汇编到目标文件，生成 .o 文件
gcc -c hello.s -o hello.o
```

目标文件是二进制格式，包含机器代码但尚未解析外部引用（如 `printf` 的地址）。

### 4. 链接（Linking）

链接器将目标文件与所需的库文件链接在一起：

- 解析外部符号引用（如 `printf` 的地址）
- 合并多个目标文件
- 生成最终的可执行文件

```bash
# 链接生成可执行文件
gcc hello.o -o hello
```

### 一步完成所有阶段

在实际开发中，通常一步完成所有阶段：

```bash
# 编译并链接，生成可执行文件
gcc hello.c -o hello
```

### 运行程序

```bash
# 在终端中运行
./hello
```

输出：
```
Hello, World!
```

## 编译错误类型

### 语法错误（Syntax Error）

代码不符合 C 语言的语法规则，编译器无法解析。

```c
// 错误示例：缺少分号
int main(void) {
    printf("Hello")  // 缺少分号
    return 0;
}
```

编译器会报告错误位置和类型，如：
```
error: expected ';' before 'return'
```

### 链接错误（Linker Error）

链接阶段无法找到函数或变量的定义。

```c
// 错误示例：使用了未定义的函数
int main(void) {
    printf("Hello\n");
    myFunction();  // 未定义的函数
    return 0;
}
```

### 运行时错误（Runtime Error）

程序可以编译通过，但在运行时出错。

- 除零错误
- 空指针解引用
- 数组越界

## 常见编译命令总结

```bash
# 基本编译
gcc hello.c -o hello

# 启用所有警告
gcc -Wall hello.c -o hello

# 使用 C11 标准
gcc -std=c11 hello.c -o hello

# 生成调试信息（配合 GDB 使用）
gcc -g hello.c -o hello

# 编译但不链接（生成目标文件）
gcc -c hello.c -o hello.o

# 仅预处理
gcc -E hello.c -o hello.i

# 仅编译到汇编
gcc -S hello.c -o hello.s

# 链接数学库
gcc program.c -o program -lm
```

## Hello World 的变体

### 带格式输出的程序

```c
#include <stdio.h>

int main(void) {
    int age = 20;
    char name[] = "Alice";

    printf("Name: %s, Age: %d\n", name, age);
    return 0;
}
```

### 多行输出

```c
#include <stdio.h>

int main(void) {
    printf("Hello, World!\n");
    printf("Welcome to C programming!\n");
    printf("-------------------\n");
    return 0;
}
```

### 使用宏定义

```c
#include <stdio.h>

#define MESSAGE "Hello, World!"

int main(void) {
    printf("%s\n", MESSAGE);
    return 0;
}

## 经典入门例题（参照谭浩强教材）

掌握了 printf 和变量后，试着动手解决下面几个经典问题，它们是所有 C 语言教材的开篇例程。

### 例1：求两个数之和

```c
#include <stdio.h>

int main(void) {
    int a = 123, b = 456;
    int sum;

    sum = a + b;
    printf("sum = %d\n", sum);
    return 0;
}
```

### 例2：求两个整数中较大的数

```c
#include <stdio.h>

int main(void) {
    int a = 5, b = 8;

    if (a > b) {
        printf("max = %d\n", a);
    } else {
        printf("max = %d\n", b);
    }
    return 0;
}
```

### 例3：用 printf 输出图案

利用 printf 逐行输出字符串，可以拼出各种图案。这是理解"输出顺序 = 代码顺序"的最好练习：

```c
#include <stdio.h>

int main(void) {
    printf("*\n");
    printf("**\n");
    printf("***\n");
    printf("****\n");
    printf("*****\n");
    return 0;
}
```

运行结果：

```
*
**
***
****
*****
```
