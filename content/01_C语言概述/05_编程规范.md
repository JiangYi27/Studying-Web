# 编程规范

## 代码风格

### 命名规范

#### 变量命名

- 使用有意义的英文名称，避免使用拼音或无意义的缩写
- 使用小写字母，单词之间用下划线连接（snake_case）

```c
// 推荐
int student_count;
float average_score;
char first_name[50];

// 不推荐
int sc;
float avg;
char fn[50];
```

#### 常量命名

- 使用全大写字母，单词之间用下划线连接

```c
#define MAX_SIZE 100
#define PI 3.14159265
#define DEFAULT_NAME "Unknown"
```

#### 函数命名

- 使用小写字母，单词之间用下划线连接
- 函数名应体现其功能

```c
// 推荐
int calculate_sum(int a, int b);
void print_array(int arr[], int size);
char* get_string(void);

// 不推荐
int func1(int a, int b);
void p(int arr[], int n);
```

#### 类型命名

- 使用大写字母开头的驼峰命名法（PascalCase）

```c
typedef struct {
    char name[50];
    int age;
} StudentInfo;

typedef enum {
    STATUS_OK,
    STATUS_ERROR,
    STATUS_UNKNOWN
} StatusCode;
```

### 缩进与格式

#### 缩进

- 使用 **4 个空格** 作为缩进单位（推荐）
- 不要使用 Tab 键（不同编辑器对 Tab 的显示宽度不同）

```c
// 推荐
int main(void) {
    int a = 10;
    int b = 20;
    int sum = a + b;

    printf("Sum: %d\n", sum);
    return 0;
}
```

#### 空格使用

- 运算符两侧加空格
- 逗号后加空格
- 关键字 `if`、`for`、`while` 等与左括号之间加空格

```c
// 推荐
if (a > b) {
    sum = a + b;
    for (int i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }
}

// 不推荐
if(a>b){
    sum=a+b;
    for(int i=0;i<n;i++){
        printf("%d",arr[i]);
    }
}
```

#### 空行使用

- 函数之间用空行分隔
- 逻辑块之间用空行分隔
- 不要连续空行

```c
#include <stdio.h>

#define MAX 100

int calculate_sum(int a, int b) {
    return a + b;
}

int main(void) {
    int result = calculate_sum(3, 5);

    printf("Result: %d\n", result);

    return 0;
}
```

#### 行长度

- 每行代码建议不超过 **80 个字符**
- 过长的语句应适当换行

```c
// 推荐：换行
int result = very_long_function_name(argument1, argument2,
                                    argument3, argument4);

// 推荐：多个短语句
int a = compute_x();
int b = compute_y();
int sum = a + b;
```

### 花括号风格

C 语言中常见的花括号风格有两种：

#### K&R 风格（推荐）

```c
if (condition) {
    // 代码
} else {
    // 代码
}

for (int i = 0; i < n; i++) {
    // 代码
}
```

#### Allman 风格

```c
if (condition)
{
    // 代码
}
else
{
    // 代码
}
```

**推荐使用 K&R 风格**，这是大多数 C 语言项目（包括 Linux 内核）的标准风格。

## 注释规范

### 单行注释（`//`）

C99 标准引入了 `//` 单行注释，适用于简短说明。

```c
// 计算两个数的和
int sum = a + b;

// 循环遍历数组
for (int i = 0; i < n; i++) {
    printf("%d ", arr[i]);
}
```

### 多行注释（`/* */`）

适用于较长的说明或临时注释掉大段代码。

```c
/*
 * 这是一个多行注释
 * 用于描述函数的功能、参数和返回值
 * 作者：张三
 * 日期：2024-01-01
 */
int calculate_sum(int a, int b) {
    return a + b;
}
```

### 注释的最佳实践

#### 1. 函数注释

每个函数应有注释说明其功能、参数和返回值。

```c
/**
 * @brief 计算两个整数的和
 *
 * @param a 第一个加数
 * @param b 第二个加数
 * @return 两个加数的和
 */
int calculate_sum(int a, int b) {
    return a + b;
}
```

#### 2. 文件头部注释

每个源文件头部应有注释说明文件用途、作者和日期。

```c
/**
 * @file hello.c
 * @brief 第一个 C 程序，演示基本输入输出
 * @author 张三
 * @date 2024-01-01
 */
```

#### 3. 行内注释

在复杂或不易理解的代码旁添加注释。

```c
int index = (a > b) ? a : b;  // 取较大值的索引

// 使用位运算判断奇偶性
if (n & 1) {
    printf("奇数\n");
}
```

#### 4. 注释的原则

- **注释应解释"为什么"，而非"做了什么"**
  - 好的注释：`// 使用快速排序以提高大数据集的性能`
  - 差的注释：`// 调用快速排序函数`
- **保持注释与代码同步**，修改代码时同时更新注释
- **避免过度注释**，清晰的代码本身就是最好的注释
- **删除无用的注释**，不要保留已废弃的代码

### 条件编译注释

```c
#ifdef DEBUG
    printf("Debug: x = %d\n", x);  // 调试输出
#endif
```

## 代码组织

### 头文件与源文件分离

- **头文件（`.h`）**：声明函数原型、宏定义、类型定义
- **源文件（`.c`）**：实现函数定义和主程序

```c
// math_utils.h
#ifndef MATH_UTILS_H
#define MATH_UTILS_H

int add(int a, int b);
int subtract(int a, int b);

#endif
```

```c
// math_utils.c
#include "math_utils.h"

int add(int a, int b) {
    return a + b;
}

int subtract(int a, int b) {
    return a - b;
}
```

### 头文件守卫

使用 `#ifndef...#define...#endif` 防止头文件重复包含：

```c
#ifndef MY_HEADER_H
#define MY_HEADER_H

// 头文件内容

#endif
```

或者使用 `#pragma once`（非标准但广泛支持）：

```c
#pragma once

// 头文件内容
```

## 常见编码错误与避免方法

### 1. 忘记分号

```c
// 错误
printf("Hello")

// 正确
printf("Hello");
```

### 2. 括号不匹配

```c
// 错误
if (a > b {
    printf("a is greater");
}

// 正确
if (a > b) {
    printf("a is greater");
}
```

### 3. 变量未初始化

```c
// 错误：x 的值是不确定的
int x;
printf("%d\n", x);

// 正确：初始化变量
int x = 0;
printf("%d\n", x);
```

### 4. 数组越界

```c
int arr[5] = {1, 2, 3, 4, 5};

// 错误：访问 arr[5]，有效索引是 0-4
printf("%d\n", arr[5]);

// 正确
printf("%d\n", arr[4]);
```

### 5. 混淆赋值与比较

```c
// 错误：应该用 == 而不是 =
if (a = 5) {
    // 这会将 5 赋值给 a，然后判断 a 是否为非零
}

// 正确
if (a == 5) {
    // 判断 a 是否等于 5
}
```

## 推荐的开发流程

1. **编写代码**：先写核心逻辑
2. **编译检查**：使用 `-Wall` 启用所有警告
3. **测试运行**：验证程序功能
4. **代码审查**：检查命名、注释、缩进是否符合规范，消除重复代码
5. **重构优化**：改进代码结构和性能
