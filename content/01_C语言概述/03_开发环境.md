# 开发环境

## 主流编译器

### GCC（GNU Compiler Collection）

GCC 是 GNU 项目开发的编译器套件，支持 C、C++、Objective-C、Fortran、Ada 等多种语言。它是 Linux 和 macOS 系统上最常用的 C 编译器。

#### 安装方式

**Linux（Ubuntu/Debian）：**
```bash
sudo apt update
sudo apt install build-essential
```

**macOS：**
```bash
# 通过 Homebrew 安装
brew install gcc
```

**Windows（MinGW-w64）：**
1. 访问 [MinGW-w64 官网](https://www.mingw-w64.org/) 下载安装包
2. 选择架构（x86_64）和线程模型（posix）
3. 安装后将 `bin` 目录添加到系统 PATH 环境变量
4. 验证安装：
```bash
gcc --version
```

#### GCC 常用选项

| 选项 | 说明 |
|------|------|
| `-E` | 仅执行预处理 |
| `-S` | 编译到汇编代码，不进行汇编 |
| `-c` | 编译到目标文件，不进行链接 |
| `-o <file>` | 指定输出文件名 |
| `-Wall` | 启用所有警告 |
| `-g` | 生成调试信息 |
| `-std=c11` | 指定 C 语言标准 |
| `-lm` | 链接数学库 |

### MSVC（Microsoft Visual C++）

MSVC 是微软开发的 C/C++ 编译器，集成在 Visual Studio 中。

#### 安装方式

1. 下载并安装 [Visual Studio Community](https://visualstudio.microsoft.com/)（免费版）
2. 安装时选择"使用 C++ 的桌面开发"工作负载
3. Visual Studio 会自动安装 MSVC 编译器和相关工具

#### MSVC 常用选项

```bash
# 在开发者命令提示符中使用
cl hello.c /Fe:hello.exe
```

### Clang

Clang 是基于 LLVM 的编译器，以清晰的错误提示和快速编译著称。

```bash
# 安装（Linux）
sudo apt install clang

# 编译
clang hello.c -o hello
```

## IDE（集成开发环境）

### VS Code

VS Code 是微软开发的轻量级代码编辑器，通过扩展可以成为强大的 C 语言 IDE。

#### 安装与配置步骤

1. **下载安装 VS Code**：从 [code.visualstudio.com](https://code.visualstudio.com/) 下载
2. **安装 C/C++ 扩展**：搜索并安装 Microsoft 官方的 `C/C++` 扩展（由 Microsoft 提供）
3. **安装 MinGW 或配置其他编译器**：确保 `gcc` 在系统 PATH 中
4. **配置 `tasks.json`**：在项目目录下创建 `.vscode/tasks.json`，配置编译任务

```json
{
    "version": "2.0.0",
    "tasks": [
        {
            "type": "cppbuild",
            "label": "C/C++: gcc build active file",
            "command": "gcc",
            "args": [
                "-fdiagnostics-color=always",
                "-g",
                "${file}",
                "-o",
                "${fileDirname}/${fileBasenameNoExtension}"
            ],
            "options": {
                "cwd": "${workspaceFolder}"
            },
            "problemMatcher": ["$gcc"],
            "group": {
                "kind": "build",
                "isDefault": true
            }
        }
    ]
}
```

5. **配置 `launch.json`**：用于调试配置

```json
{
    "version": "0.2.0",
    "configurations": [
        {
            "name": "gcc - Build and debug active file",
            "type": "cppdbg",
            "request": "launch",
            "program": "${fileDirname}/${fileBasenameNoExtension}",
            "args": [],
            "stopAtEntry": false,
            "cwd": "${workspaceFolder}",
            "environment": [],
            "externalConsole": false,
            "MIMode": "gdb",
            "setupCommands": [
                {
                    "description": "Enable pretty-printing for gdb",
                    "text": "-enable-pretty-printing",
                    "ignoreFailures": true
                }
            ],
            "preLaunchTask": "C/C++: gcc build active file"
        }
    ]
}
```

### CLion

CLion 是 JetBrains 开发的跨平台 C/C++ IDE，功能强大但需要付费（个人开发可申请免费许可）。

#### 主要特点

- 智能代码补全和重构
- 内置 CMake 支持
- 强大的调试功能
- 集成的版本控制
- 跨平台支持（Windows、macOS、Linux）

#### 安装与配置

1. 从 [JetBrains 官网](https://www.jetbrains.com/clion/) 下载安装
2. 安装时选择安装 MinGW（Windows）或使用系统已有的 GCC
3. 打开项目，CLion 会自动检测 CMakeLists.txt 或提示创建

### Dev-C++

Dev-C++ 是面向初学者的免费 C/C++ IDE，基于 MinGW 编译器。

#### 安装与使用

1. 从 [SourceForge](https://sourceforge.net/projects/dev-cpp/) 下载 Dev-C++ 安装包
2. 安装后即可使用，内置 GCC 编译器
3. 创建新项目 → 选择 Console Application → 选择 C 语言
4. 编写代码后按 `F11` 编译运行

#### Dev-C++ 的优缺点

- **优点**：轻量、简单、适合初学者
- **缺点**：界面较旧，更新不频繁，调试功能有限

## 编译器对比

| 特性 | GCC | MSVC | Clang |
|------|-----|------|-------|
| 开源 | ✅ | ❌ | ✅ |
| 跨平台 | ✅ | Windows | ✅ |
| 错误提示 | 一般 | 详细 | 非常清晰 |
| 编译速度 | 中等 | 快 | 快 |
| 标准支持 | 良好 | 良好 | 优秀 |
| 调试支持 | GDB | Visual Studio Debugger | GDB/LLDB |

## 推荐学习路径

对于初学者，推荐以下开发环境组合：

1. **Windows 用户**：VS Code + MinGW-w64 + GCC
2. **macOS 用户**：VS Code + Xcode Command Line Tools（自带 clang）
3. **Linux 用户**：VS Code 或 CLion + GCC（系统自带或通过包管理器安装）
