# 计算机与编程

## 什么是计算机？

计算机（Computer）是一种能够按照程序自动执行指令的电子设备。它能够对数据进行接收、存储、处理和输出，是现代社会最重要的工具之一。

### 计算机的定义

计算机是一种电子设备，它能够根据存储在内存中的指令序列（程序）自动执行各种算术和逻辑运算。计算机的核心特征是**存储程序**和**自动控制**，这一概念由冯·诺依曼（John von Neumann）在1945年提出，被称为**冯·诺依曼体系结构**。

### 计算机的硬件和软件

计算机系统由两大部分组成：

- **硬件（Hardware）**：计算机的物理部件，是看得见、摸得着的实体设备
  - 中央处理器（CPU）
  - 内存（RAM）
  - 存储设备（硬盘、SSD等）
  - 输入设备（键盘、鼠标等）
  - 输出设备（显示器、打印机等）
  - 主板、电源、显卡等

- **软件（Software）**：运行在硬件上的程序、数据和相关文档的集合
  - **系统软件**：操作系统、驱动程序、编译器等
  - **应用软件**：文字处理软件、浏览器、游戏等
  - **编程语言**：用于编写程序的工具和语言

### 计算机的工作原理

计算机的工作基于**存储程序控制**原理，其基本工作过程如下：

1. **取指令（Fetch）**：从内存中取出下一条要执行的指令
2. **译码（Decode）**：控制器对指令进行分析，确定需要执行的操作
3. **执行（Execute）**：运算器执行指令规定的操作
4. **存储（Store）**：将结果保存到内存或寄存器中
5. **重复**：程序计数器指向下一条指令，重复上述过程

这一过程被称为**指令周期**，是计算机最基本的工作方式。

## 计算机的基本组成

### 1. 中央处理器（CPU）

CPU（Central Processing Unit）是计算机的大脑，负责执行指令和处理数据。它由两个主要部分组成：

#### 运算器（ALU）
算术逻辑单元（Arithmetic Logic Unit），负责执行算术运算（加、减、乘、除）和逻辑运算（与、或、非、异或等）。

#### 控制器（CU）
控制单元（Control Unit），负责从内存中取出指令、译码并发出控制信号，协调计算机各部件的工作。

#### 寄存器
寄存器是CPU内部的高速存储单元，用于临时存放指令、数据和地址信息。常见的寄存器包括：

- **程序计数器（PC）**：存放下一条指令的地址
- **指令寄存器（IR）**：存放当前正在执行的指令
- **累加器（ACC）**：存放运算结果
- **状态寄存器（PSW）**：存放运算状态标志（如零标志、进位标志等）

#### CPU的性能指标

- **主频（Clock Speed）**：CPU每秒钟发出的脉冲数，单位为GHz
- **字长（Word Size）**：CPU一次能处理的数据位数，如32位、64位
- **核心数（Core Count）**：CPU中独立处理核心的数量
- **缓存（Cache）**：CPU内部的高速缓存，分为L1、L2、L3三级
- **IPC（每时钟周期指令数）**：衡量CPU架构效率的指标

### 2. 内存（RAM）

内存（Random Access Memory）是计算机的临时存储设备，用于存放正在运行的程序和数据。

#### 内存的特点

- **易失性**：断电后数据会丢失
- **随机访问**：可以快速访问任意地址的数据
- **读写速度快**：比硬盘快得多
- **容量有限**：相比硬盘，内存容量通常较小

#### 内存的分类

- **SRAM（静态随机存取存储器）**：速度快，功耗高，用于CPU缓存
- **DRAM（动态随机存取存储器）**：速度较慢，容量大，用于主内存
  - **DDR SDRAM**：双倍数据率同步动态随机存取存储器
  - **DDR4**：当前主流的内存标准
  - **DDR5**：最新的内存标准，提供更高的带宽和容量

#### 内存地址

每个内存单元都有一个唯一的地址，CPU通过地址来访问内存中的数据。32位系统最多支持4GB内存（2^32），64位系统理论上可以支持16EB（2^64）内存。

### 3. 存储设备

存储设备用于长期保存数据和程序，即使断电后数据也不会丢失。

#### 硬盘驱动器（HDD）
- 使用磁性盘片存储数据
- 读写速度较慢，但容量大、价格低
- 机械结构，存在寻道时间

#### 固态硬盘（SSD）
- 使用闪存芯片存储数据
- 读写速度远快于HDD
- 无机械部件，抗震性好
- 价格相对较高

#### 其他存储介质
- **U盘/闪存盘**：便携式存储设备
- **光盘（CD/DVD/Blu-ray）**：光学存储介质
- **存储卡（SD卡、TF卡）**：用于相机、手机等设备
- **网络存储（NAS、云存储）**：通过网络访问的远程存储

#### 存储容量单位

| 单位 | 换算关系 |
|------|----------|
| 字节（Byte） | 基本单位 |
| 千字节（KB） | 1 KB = 1024 Bytes |
| 兆字节（MB） | 1 MB = 1024 KB |
| 吉字节（GB） | 1 GB = 1024 MB |
| 太字节（TB） | 1 TB = 1024 GB |
| 拍字节（PB） | 1 PB = 1024 TB |

### 4. 输入/输出设备

输入/输出设备（I/O设备）是计算机与外界交互的桥梁。

#### 输入设备
- **键盘**：最常用的输入设备，用于输入文字和命令
- **鼠标**：用于指向和选择屏幕上的对象
- **触摸屏**：通过触摸进行输入，广泛用于手机和平板
- **扫描仪**：将纸质文档转换为数字图像
- **麦克风**：输入声音信号
- **摄像头**：输入视频和图像
- **传感器**：温度、压力、光照等物理量传感器

#### 输出设备
- **显示器**：将计算机处理的结果以图像形式显示出来
- **打印机**：将数字信息打印到纸张上
- **音箱**：输出声音
- **投影仪**：将图像投射到屏幕上

#### I/O接口
- **USB（通用串行总线）**：最常用的外部设备接口
- **HDMI**：高清视频和音频传输接口
- **VGA**：模拟视频传输接口
- **网口（RJ-45）**：网络连接接口
- **音频接口**：耳机、麦克风接口

### 5. 主板（Motherboard）

主板是计算机的核心电路板，连接并协调所有硬件部件的工作。主板上包含：

- **CPU插槽**：安装CPU的接口
- **内存插槽**：安装内存条的接口
- **扩展插槽**：PCIe插槽，用于安装显卡、网卡等扩展卡
- **芯片组**：管理主板上的数据流和I/O操作
- **BIOS/UEFI固件**：计算机启动时运行的底层程序
- **电源接口**：为主板和其他部件供电

### 6. 总线（Bus）

总线是计算机内部各部件之间传输数据的通道。总线分为三类：

- **数据总线（Data Bus）**：传输数据，宽度决定了一次传输的数据量
- **地址总线（Address Bus）**：传输地址信息，宽度决定了可寻址的内存空间
- **控制总线（Control Bus）**：传输控制信号，如读/写信号、中断信号等

## 什么是编程？

编程（Programming）是指使用特定的编程语言编写指令序列（程序），让计算机按照预定的逻辑执行特定任务的过程。编程是人与计算机之间沟通的桥梁。

### 编程的基本概念

#### 算法（Algorithm）
算法是解决特定问题的一系列明确、有限的步骤。它是程序的核心，决定了程序的逻辑和效率。

算法的特性：
1. **有穷性**：算法必须在有限步骤后结束
2. **确定性**：每一步骤必须有明确的定义
3. **输入**：有零个或多个输入
4. **输出**：至少有一个输出
5. **可行性**：每一步都必须是可执行的

#### 数据结构（Data Structure）
数据结构是数据的组织、存储和管理方式。常见的数据结构包括：

- **数组（Array）**：连续内存中存储相同类型的数据
- **链表（Linked List）**：通过指针连接的节点序列
- **栈（Stack）**：后进先出（LIFO）的数据结构
- **队列（Queue）**：先进先出（FIFO）的数据结构
- **树（Tree）**：层次化的数据结构，如二叉树、AVL树
- **图（Graph）**：由节点和边组成的复杂结构
- **哈希表（Hash Table）**：通过哈希函数实现快速查找

#### 程序 = 算法 + 数据结构

瑞士计算机科学家尼古拉斯·沃思（Niklaus Wirth）在其经典著作中提出了著名的公式：

> **程序 = 算法 + 数据结构**

- **算法** 解决"怎么做"的问题，规定了解决问题的步骤和逻辑；
- **数据结构** 解决"怎么存"的问题，规定了数据的组织、存储方式；
- 两者相辅相成：选择高效的算法往往依赖于合适的数据结构，反过来数据结构的选取也会影响算法的效率。

这也是谭浩强《C程序设计》开篇强调的核心思想：**学习程序设计，既要会设计算法，也要会选取和构造数据结构**。

#### 结构化程序设计

结构化程序设计（Structured Programming）由荷兰计算机科学家迪杰斯特拉（E. W. Dijkstra）等人在20世纪60年代提出，是C语言等高级语言普遍采用的设计思想，其核心是：

1. **仅用三种基本控制结构**：
   - **顺序结构**：按代码的书写顺序依次执行
   - **选择结构**：根据条件选择执行不同的分支（if、switch）
   - **循环结构**：在满足条件时重复执行某段代码（while、for、do-while）
   
   任何复杂的程序都可以只用这三种结构组合实现，而不必使用 `goto` 语句，从而保证程序结构清晰、易读、易验证。

2. **自顶向下（Top-Down）**：从问题整体出发，先将大问题分解为若干小问题，规划好总框架，再逐层向下细化。

3. **逐步求精（Stepwise Refinement）**：对每个子问题逐步细化，每一步都比上一步更具体，直到可以直接用C语句实现为止。

**示例：打印成绩单的"自顶向下、逐步求精"过程**

1. 总任务：打印一张成绩单
2. 分解为子任务：输入成绩 → 统计并计算 → 输出成绩单
3. 进一步细化"统计并计算"：累加总分 → 统计人数 → 计算平均分
4. 细化到可编程：用 `scanf` 输入、用循环累加、用 `printf` 输出

结构化程序设计使程序逻辑清晰、易于阅读、调试和维护，C语言正是为支持这种设计方法而设计的。

#### 变量与数据类型
变量是程序中存储数据的命名容器。每个变量都有一个数据类型，决定了它可以存储什么类型的值以及可以执行哪些操作。

常见的数据类型：
- **整型（int）**：整数，如 `42`, `-10`
- **浮点型（float/double）**：小数，如 `3.14`, `-0.5`
- **字符型（char）**：单个字符，如 `'A'`, `'z'`
- **布尔型（bool）**：真或假，`true` 或 `false`
- **字符串（string）**：字符序列，如 `"Hello"`

### 编程语言的发展历程

#### 第一代：机器语言（Machine Language）
- 由二进制代码（0和1）组成
- 直接由CPU执行，无需翻译
- 难以编写和阅读，容易出错
- 每种CPU架构有不同的机器语言指令集

#### 第二代：汇编语言（Assembly Language）
- 使用助记符（Mnemonic）代替二进制代码
- 如 `MOV`, `ADD`, `JMP` 等指令
- 需要通过**汇编器（Assembler）**翻译成机器语言
- 与硬件紧密相关，可移植性差
- 但比机器语言更易读和编写

#### 第三代：高级语言（High-Level Language）
- 接近人类自然语言和数学表达式
- 与硬件无关，具有良好的可移植性
- 需要通过编译器或解释器翻译成机器语言
- 代表语言：C、C++、Java、Python、Pascal、Fortran等

#### 第四代：面向对象语言（4GL/OO Language）
- 支持面向对象编程（OOP）特性
- 封装、继承、多态
- 代表语言：C++、Java、C#、Python等

#### 第五代：脚本语言和现代语言
- 强调开发效率和简洁性
- 代表语言：Python、JavaScript、Ruby、Go、Rust等

### 编程范式

编程范式（Programming Paradigm）是编写程序的风格和方法论：

1. **过程式编程（Procedural Programming）**
   - 以过程/函数为组织单位
   - 强调步骤和顺序执行
   - 代表语言：C、Pascal、Fortran

2. **面向对象编程（Object-Oriented Programming, OOP）**
   - 以对象为基本单位
   - 封装、继承、多态
   - 代表语言：C++、Java、C#、Python

3. **函数式编程（Functional Programming）**
   - 将计算视为数学函数的求值
   - 强调不可变性和纯函数
   - 代表语言：Haskell、Erlang、Scala

4. **泛型编程（Generic Programming）**
   - 编写与类型无关的通用代码
   - 代表语言：C++（模板）、Java（泛型）

5. **声明式编程（Declarative Programming）**
   - 描述"做什么"而非"怎么做"
   - 代表：SQL、正则表达式、HTML/CSS

## C语言简介

### C语言的历史

C语言由**Dennis Ritchie**于1972年在贝尔实验室（Bell Labs）开发。它的诞生与UNIX操作系统的发展密切相关：

- **1969年**：Ken Thompson和Dennis Ritchie开始开发UNIX操作系统，最初使用汇编语言
- **1970年**：Thompson开发了B语言，作为BCPL语言的简化版
- **1972年**：Ritchie在B语言的基础上开发了C语言
- **1973年**：UNIX操作系统的大部分代码用C语言重写
- **1978年**：Brian Kernighan和Dennis Ritchie出版了《The C Programming Language》（K&R），成为C语言的经典教材
- **1989年**：ANSI发布了C语言标准（ANSI C / C89）
- **1999年**：ISO发布了C99标准，增加了许多新特性
- **2011年**：ISO发布了C11标准
- **2018年**：ISO发布了C17标准（主要是C11的缺陷修复）
- **2023年**：ISO发布了C23标准

### C语言的特点

C语言之所以经久不衰，是因为它具有许多独特的优势：

#### 1. 高效性
C语言编译后的程序直接运行在硬件上，没有虚拟机的开销，执行效率非常高。C语言允许程序员进行底层优化，如手动管理内存、使用指针直接操作内存地址等。

#### 2. 灵活性
C语言提供了丰富的操作符和灵活的控制结构，允许程序员以多种方式实现同一功能。它既可以进行高级抽象，也可以进行底层硬件操作。

#### 3. 可移植性
C语言程序可以在不同的平台上编译运行，只要目标平台有对应的C编译器。虽然不同平台的编译器和库可能有一些差异，但C语言标准保证了核心语言的可移植性。

#### 4. 结构化编程支持
C语言支持结构化编程的三大基本结构：
- **顺序结构**：按代码的书写顺序依次执行
- **选择结构**：根据条件选择执行不同的分支（if、switch）
- **循环结构**：重复执行某段代码（for、while、do-while）

#### 5. 丰富的操作符
C语言提供了34个操作符，涵盖算术、关系、逻辑、位运算、赋值、条件、逗号等多种类型。

#### 6. 指针
指针是C语言最强大的特性之一，也是最容易被误用的特性。指针允许直接操作内存地址，提供了高效的数据访问和灵活的内存管理方式。

#### 7. 模块化
C语言支持通过函数将程序分解为多个模块，每个模块完成特定的功能，有利于代码的组织、复用和维护。

#### 8. 静态类型
C语言是静态类型语言，变量类型在编译时确定，这有助于在编译阶段发现类型错误，提高程序的可靠性。

### C语言的局限性

- **没有内置的字符串类型**：字符串以字符数组形式处理
- **没有面向对象特性**：不支持类、继承等OOP特性（C++弥补了这一缺陷）
- **手动内存管理**：需要程序员手动分配和释放内存，容易出现内存泄漏和越界访问
- **没有垃圾回收机制**：增加了内存管理的复杂性
- **数组不进行边界检查**：可能导致缓冲区溢出等安全问题

### C语言的应用领域

C语言的应用范围非常广泛，几乎渗透到计算机科学的各个领域：

#### 操作系统
- **Linux内核**：完全用C语言编写
- **Windows内核**：大部分用C语言编写
- **macOS内核（XNU）**：包含大量C语言代码

#### 嵌入式系统
- 单片机编程（如AVR、ARM Cortex-M）
- 汽车电子系统
- 工业控制系统
- 家用电器固件

#### 系统软件
- 编译器（如GCC、Clang）
- 解释器（如Python解释器）
- 数据库系统（如MySQL、PostgreSQL）
- 网络协议栈

#### 游戏开发
- 游戏引擎底层（如Unity的底层、Unreal Engine的部分模块）
- 游戏逻辑的高性能部分

#### 图形与多媒体
- 图像处理库（如OpenCV）
- 音频处理库
- 视频编解码库

#### 科学计算与高性能计算
- 数值计算库（如BLAS、LAPACK）
- 物理模拟软件
- 天气预报模型

#### 编程语言与工具
- 许多编程语言的运行时和标准库用C编写
- 开发工具（如Git、Vim）

## 第一个C程序详解

### 完整的C程序结构

```c
#include <stdio.h>      // 预处理指令：包含标准输入输出头文件

/* 
 * 这是一个多行注释
 * 用于描述程序的功能
 */

// 这是一个单行注释

#define PI 3.14159265    // 宏定义

int main(void) {          // 主函数，程序的入口点
    int radius = 5;       // 声明并初始化一个整型变量
    double area;          // 声明一个双精度浮点型变量
    
    area = PI * radius * radius;  // 计算圆的面积
    
    printf("圆的半径: %d\n", radius);    // 输出半径
    printf("圆的面积: %.2f\n", area);    // 输出面积，保留两位小数
    
    return 0;             // 返回0，表示程序正常结束
}
```

### 代码逐行解释

#### `#include <stdio.h>`
预处理指令，告诉编译器在编译前将标准输入输出头文件的内容包含到当前文件中。`stdio.h`（Standard Input Output Header）定义了输入输出函数的声明，如 `printf`、`scanf`、`fprintf` 等。

头文件的包含方式有两种：
- `#include <stdio.h>`：从系统标准路径搜索，适用于标准库头文件
- `#include "myheader.h"`：先从当前目录搜索，适用于用户自定义头文件

#### `/* ... */` 和 `//`
C语言支持两种注释方式：
- **多行注释**：以 `/*` 开始，以 `*/` 结束，可以跨越多行
- **单行注释**：以 `//` 开始，到行末结束（C99标准引入）

注释在编译时会被忽略，不生成任何代码。

#### `#define PI 3.14159265`
预处理指令，定义一个宏常量。在编译预处理阶段，所有出现的 `PI` 都会被替换为 `3.14159265`。

#### `int main(void)`
主函数，每个C程序有且仅有一个主函数。`main` 是程序的入口点，操作系统从 `main` 函数开始执行程序。

- `int`：主函数的返回类型是整数
- `main`：函数名，固定为 `main`
- `void`：参数列表为空，表示主函数不接受任何参数
- 在C语言中，`main` 也可以写成 `int main(int argc, char *argv[])` 来接收命令行参数

#### `int radius = 5;`
变量声明和初始化。`int` 是数据类型，表示整数；`radius` 是变量名；`= 5` 是初始化，将变量赋值为5。

#### `double area;`
声明一个双精度浮点型变量 `area`。在C语言中，未初始化的局部变量的值是不确定的（垃圾值）。

#### `area = PI * radius * radius;`
赋值语句，计算圆的面积并将结果存入 `area` 变量。

#### `printf("圆的半径: %d\n", radius);`
格式化输出函数。`printf` 的参数：
- 第一个参数是格式字符串，`%d` 是整型占位符，`\n` 是换行符
- 后续参数依次替换格式字符串中的占位符

常用格式说明符：
| 格式符 | 对应类型 |
|------|----------|
| `%d` 或 `%i` | 十进制整数（int） |
| `%f` | 浮点数（float/double） |
| `%lf` | 双精度浮点数（double） |
| `%c` | 单个字符（char） |
| `%s` | 字符串（char*） |
| `%u` | 无符号整数（unsigned int） |
| `%x` 或 `%X` | 十六进制整数 |
| `%p` | 指针地址 |
| `%%` | 输出百分号本身 |

#### `return 0;`
`return` 语句结束函数的执行并返回值。`main` 函数返回0表示程序正常结束。返回非零值通常表示程序异常终止。

### 编译和链接过程

C程序的编译过程分为四个阶段：

1. **预处理（Preprocessing）**
   - 处理 `#include`、`#define` 等预处理指令
   - 展开宏定义
   - 条件编译（`#ifdef`、`#ifndef`、`#if` 等）
   - 删除注释
   - 生成 `.i` 文件

2. **编译（Compilation）**
   - 将预处理后的C代码翻译成汇编语言
   - 进行词法分析、语法分析、语义分析
   - 进行优化
   - 生成 `.s` 文件（汇编代码）

3. **汇编（Assembly）**
   - 将汇编代码翻译成机器语言（二进制指令）
   - 生成 `.o` 文件（目标文件）

4. **链接（Linking）**
   - 将目标文件与所需的库文件链接在一起
   - 解析外部符号引用
   - 生成可执行文件

```bash
# 完整编译过程（分步）
gcc -E hello.c -o hello.i    # 预处理
gcc -S hello.i -o hello.s    # 编译
gcc -c hello.s -o hello.o    # 汇编
gcc hello.o -o hello         # 链接

# 一步完成所有阶段
gcc hello.c -o hello
```

## 指针基础

### 什么是指针？

指针是一个变量，它的值是另一个变量的内存地址。指针是C语言最强大也最复杂的特性之一。

```c
int num = 42;
int *ptr = &num;    // ptr存储num的地址

printf("num的值: %d\n", num);        // 输出 42
printf("num的地址: %p\n", &num);     // 输出内存地址
printf("ptr的值: %p\n", ptr);        // 输出num的地址
printf("ptr指向的值: %d\n", *ptr);   // 输出 42（解引用）
```

### 指针的基本操作

- **取地址运算符 `&`**：获取变量的内存地址
- **解引用运算符 `*`**：通过指针访问它指向的值

### 指针与数组

数组名本质上是一个指向数组第一个元素的指针常量。

```c
int arr[5] = {10, 20, 30, 40, 50};
int *p = arr;    // p指向数组的第一个元素

printf("%d\n", *p);       // 输出 10
printf("%d\n", *(p + 1)); // 输出 20（指针算术）
printf("%d\n", p[2]);     // 输出 30（等价于 *(p + 2)）
```

### 指针与函数

指针可以作为函数参数，实现"按引用传递"，使函数能够修改调用者的变量。

```c
void swap(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

int main() {
    int x = 10, y = 20;
    printf("交换前: x=%d, y=%d\n", x, y);
    swap(&x, &y);
    printf("交换后: x=%d, y=%d\n", x, y);
    return 0;
}
```

### 空指针和野指针

- **空指针（NULL pointer）**：指向地址0的指针，表示不指向任何有效内存
  ```c
  int *ptr = NULL;
  if (ptr != NULL) {
      // 安全地使用ptr
  }
  ```

- **野指针（Dangling pointer）**：指向已释放或无效内存的指针
  ```c
  int *ptr = (int *)malloc(sizeof(int));
  free(ptr);
  // ptr现在是野指针，不应再使用
  ptr = NULL;  // 释放后将指针设为NULL是好习惯
  ```

## 内存管理

### 静态内存分配

在编译时分配内存，变量在程序的整个生命周期内都存在。

```c
int globalVar = 100;    // 全局变量，静态存储区

void func() {
    int localVar = 50;  // 局部变量，栈上分配
}
```

### 动态内存分配

在程序运行时动态分配和释放内存，使用标准库函数 `malloc`、`calloc`、`realloc` 和 `free`。

```c
#include <stdlib.h>

// malloc：分配指定字节数的未初始化内存
int *arr = (int *)malloc(10 * sizeof(int));
if (arr == NULL) {
    printf("内存分配失败\n");
    return 1;
}

// 使用数组
for (int i = 0; i < 10; i++) {
    arr[i] = i * 10;
}

// calloc：分配并初始化为0
int *arr2 = (int *)calloc(10, sizeof(int));

// realloc：重新分配内存大小
arr = (int *)realloc(arr, 20 * sizeof(int));

// free：释放动态分配的内存
free(arr);
arr = NULL;  // 避免野指针
free(arr2);
arr2 = NULL;
```

### 内存区域

C程序在内存中分为以下几个区域：

1. **代码区（Text Segment）**：存放编译后的机器指令
2. **数据区（Data Segment）**：
   - **全局/静态初始化区**：存放已初始化的全局变量和静态变量
   - **BSS段**：存放未初始化的全局变量和静态变量（由系统初始化为0）
3. **栈（Stack）**：存放局部变量、函数参数、返回地址等，自动管理
4. **堆（Heap）**：动态分配的内存，由程序员手动管理

## 结构体与联合体

### 结构体（Struct）

结构体允许将不同类型的数据组合成一个自定义类型。

#### 结构体数组

