# 指针基础

## 指针的概念

指针是 C 语言中最重要、最强大的特性之一。指针变量存储的是另一个变量的内存地址。

### 什么是"直接访问"与"间接访问"

谭浩强教材中将变量的访问方式分为两种：

- **直接访问**：通过变量名直接读写变量的值。
- **间接访问**：先取出变量的地址，再通过地址去访问变量的值，即"通过指针访问"。

```c
int x = 10;

// 直接访问：通过变量名 x
printf("直接访问 x = %d\n", x);

// 间接访问：通过指针 p
int *p = &x;
printf("间接访问 x = %d\n", *p);  // 通过 p 中保存的地址找到 x
```

## 指针变量的定义

### 基本语法

```c
类型名 *指针变量名;
```

```c
int *p;        // 指向 int 类型的指针
double *dp;    // 指向 double 类型的指针
char *cp;      // 指向 char 类型的指针
```

#### 定义指针的 `*` 与解引用的 `*` 含义不同

定义指针时出现的 `*` 只是**声明**"这是一个指针变量"，并不是解引用；而使用指针时（如 `*p`）的 `*` 才是**取内容（解引用）**运算符。两者含义完全不同。

```c
int *p;        // 这里的 * 是声明的一部分，表示 p 是指针变量
*p = 10;       // 这里的 * 是解引用运算符，表示访问 p 指向的内存
```

> **注意**：指针变量本身也有地址（可以取 `&p`）。指针只存放地址，它**自身存储在哪儿**由定义位置决定（局部指针在栈上，全局指针在数据段）。

### 指针类型决定步长（`*` 前的类型很重要）

指针的类型不仅决定它能指向的数据类型，还决定了指针加 1（`p+1`）时实际移动的字节数（步长）。

```c
char *cp;      // cp+1 移动 1 字节（sizeof(char)）
int *ip;       // ip+1 移动 4 字节（sizeof(int)）
double *dp;    // dp+1 移动 8 字节（sizeof(double)）
```

## 取地址符（`&`）

`&` 运算符用于获取变量的内存地址。

```c
int x = 10;
int *p = &x;  // p 存储 x 的地址

printf("x 的值 = %d\n", x);      // 输出 10
printf("x 的地址 = %p\n", &x);   // 输出 x 的内存地址
printf("p 的值 = %p\n", p);      // 输出 x 的地址（与 &x 相同）
printf("p 指向的值 = %d\n", *p); // 输出 10
```

## 解引用符（`*`）

`*` 运算符用于访问指针指向的内存地址中的值。

```c
int x = 10;
int *p = &x;

printf("*p = %d\n", *p);  // 输出 10，通过指针访问 x 的值

*p = 20;  // 通过指针修改 x 的值
printf("x = %d\n", x);    // 输出 20
```

### 解引用的本质

```
x 的内存布局：
地址：0x1000  内容：10

p 的内存布局：
地址：0x2000  内容：0x1000（x 的地址）

*p 的含义：访问地址 0x1000 处的值
```

## 指针与普通变量的对比

| 特性 | 普通变量 | 指针变量 |
|------|----------|----------|
| 存储内容 | 实际数据 | 数据的地址 |
| 大小 | 取决于类型 | 在 32 位系统为 4 字节，64 位系统为 8 字节 |
| 运算符 | `=` 赋值 | `&` 取地址，`*` 解引用 |
| 初始化 | 直接赋值 | 必须指向有效地址 |

## 指针的初始化

### 正确初始化

```c
int x = 10;
int *p = &x;  // 指向已存在的变量

int *p = NULL;  // 初始化为空指针
```

### 错误初始化

```c
int *p;       // 未初始化，指向随机地址（野指针）
*p = 10;      // 错误！向随机地址写入数据
```

## 空指针（NULL）

`NULL` 是一个特殊的指针值，表示指针不指向任何有效的内存地址。

```c
int *p = NULL;

if (p != NULL) {
    printf("*p = %d\n", *p);
} else {
    printf("p 是空指针\n");
}
```

### 空指针解引用

```c
int *p = NULL;
// *p = 10;  // 错误！空指针解引用会导致段错误
```

### 空指针与野指针的区别

| 对比项 | 空指针（NULL） | 野指针 |
|--------|----------------|--------|
| 值 | 确定的特殊值 `NULL`（通常为 0） | 不确定的随机地址 |
| 指向 | 明确不指向任何有效对象 | 指向了未知/无效的内存 |
| 能否判断 | 可以 `if (p == NULL)` 判断 | 无法通过判断得知 |
| 解引用后果 | 必然段错误 | 未定义行为，可能崩溃或静默出错 |

> **注意**：空指针**可以判断**，因此是安全可控的；野指针无法预知，比空指针更危险。编程时应尽量把指针初始化为 `NULL`，杜绝野指针。

## 指针与 const 的结合

```c
int x = 10;
const int *p = &x;  // 指向常量的指针，不能通过 p 修改 x
// *p = 20;  // 错误

int *const p2 = &x;  // 常量指针，p2 不能指向其他地址
*p2 = 20;  // 正确，可以修改 x 的值
// p2 = &y;  // 错误

const int *const p3 = &x;  // 指向常量的常量指针，都不能修改
```

## 指针的大小

在 32 位系统中，指针大小为 4 字节；在 64 位系统中，指针大小为 8 字节。

```c
#include <stdio.h>

int main(void) {
    printf("sizeof(int*) = %zu\n", sizeof(int *));
    printf("sizeof(char*) = %zu\n", sizeof(char *));
    printf("sizeof(double*) = %zu\n", sizeof(double *));
    // 所有类型的指针大小相同
    return 0;
}
```

## 指针运算

### 指针与整数的加减

```c
int arr[] = {10, 20, 30, 40, 50};
int *p = arr;  // p 指向 arr[0]

p + 1;  // 指向下一个 int 元素（地址增加 sizeof(int) 字节）
p + 2;  // 指向 arr[2]
p - 1;  // 指向前一个 int 元素
```

### 指针相减

两个指向同一数组的指针相减，结果是它们之间元素的个数。

```c
int arr[] = {10, 20, 30, 40, 50};
int *p1 = &arr[1];
int *p2 = &arr[3];

ptrdiff_t diff = p2 - p1;  // 结果为 2
```

### 指针比较

可以比较两个指针的大小关系（指向同一数组时）。

```c
int arr[] = {10, 20, 30, 40, 50};
int *p1 = &arr[1];
int *p2 = &arr[3];

if (p1 < p2) {
    printf("p1 指向的元素在 p2 之前\n");
}
```

## 指针与数组的关系

数组名在大多数情况下会退化为指向首元素的指针。

```c
int arr[5] = {10, 20, 30, 40, 50};

arr == &arr[0];     // true
*arr == arr[0];     // true
*(arr + 1) == arr[1];  // true
```

## 野指针

野指针是指指向无效内存地址的指针。

### 野指针的常见原因

1. **未初始化的指针**
   ```c
   int *p;  // 野指针，指向随机地址
   *p = 10; // 危险！
   ```

2. **已释放的内存**
   ```c
   int *p = (int *)malloc(sizeof(int));
   free(p);
   // p 现在是野指针
   *p = 10;  // 危险！
   ```

3. **指针越界**
   ```c
   int arr[5];
   int *p = arr + 10;  // 越界指针
   ```

### 避免野指针

1. 始终初始化指针
2. 释放内存后将指针设为 NULL
3. 避免指针越界访问

```c
int *p = NULL;
p = (int *)malloc(sizeof(int));
if (p != NULL) {
    *p = 10;
    free(p);
    p = NULL;  // 释放后设为 NULL
}
```

## 指针的指针（二级指针）

```c
int x = 10;
int *p = &x;
int **pp = &p;  // pp 是指向指针的指针

printf("x = %d\n", x);       // 输出 10
printf("*p = %d\n", *p);     // 输出 10
printf("**pp = %d\n", **pp); // 输出 10
```

## 指针数组

```c
int *arr[5];  // 指针数组：包含 5 个指针的数组
```

## 数组指针

```c
int (*p)[5];  // 指向包含 5 个 int 的数组的指针
```

## 指针与函数参数

通过指针参数，函数可以修改调用者的变量。

```c
void swap(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

int main(void) {
    int x = 1, y = 2;
    swap(&x, &y);
    // x = 2, y = 1
    return 0;
}
```

## 指针与动态内存

```c
#include <stdlib.h>

int *arr = (int *)malloc(10 * sizeof(int));
if (arr != NULL) {
    arr[0] = 1;
    arr[1] = 2;
    // ...
    free(arr);
    arr = NULL;
}
```

## 指针的最佳实践

1. **始终初始化指针**
2. **释放内存后将指针设为 NULL**
3. **使用 `const` 保护不修改的数据**
4. **避免返回局部变量的指针**
5. **使用断言检查指针有效性**
6. **使用 `void*` 时注意类型安全
