# 指针与字符串

## 字符指针与字符数组的区别

### 字符数组

```c
char str1[] = "Hello";
```

内存布局：
```
str1: ['H', 'e', 'l', 'l', 'o', '\0']
      可读写
```

- `str1` 是一个数组，存储在栈上
- 内容可以修改
- `sizeof(str1)` = 6（包含 `'\0'`）

### 字符指针

```c
char *str2 = "Hello";
```

内存布局：
```
str2: 0x4000 → "Hello\0"（存储在只读数据段）
      指针本身可读写，但指向的内容不可修改
```

- `str2` 是一个指针，存储在栈上
- 指向的字符串常量存储在只读内存中
- `sizeof(str2)` = 8（指针大小）

### 修改内容的区别

```c
char arr[] = "Hello";
char *ptr = "Hello";

arr[0] = 'h';   // 正确：修改字符数组的内容
// ptr[0] = 'h';  // 错误！未定义行为，可能导致段错误
```

## 字符指针的常见用法

### 字符串遍历

```c
char *str = "Hello";

// 方法 1：使用数组下标
for (int i = 0; str[i] != '\0'; i++) {
    printf("%c", str[i]);
}

// 方法 2：使用指针递增
for (char *p = str; *p != '\0'; p++) {
    printf("%c", *p);
}

// 方法 3：使用指针比较
char *start = str;
while (*start != '\0') {
    printf("%c", *start++);
}
```

### 字符串查找

```c
char *strchr(const char *s, int c);
char *strrchr(const char *s, int c);
char *strstr(const char *haystack, const char *needle);
```

### 字符串分割

```c
char str[] = "apple,banana,cherry";
char *token = strtok(str, ",");

while (token != NULL) {
    printf("%s\n", token);
    token = strtok(NULL, ",");
}
```

## 字符串常量

### 字符串常量的本质

字符串常量（如 `"Hello"`）在内存中是**以 `'\0'` 结尾的字符数组**，存储在只读数据段。它也有地址，`"Hello"` 这个表达式本身的值就是该字符串首字符的地址。

```c
printf("%c\n", *"Hello");   // 输出 H，字符串常量可直接解引用
```

### 字符串常量的存储位置

字符串常量存储在程序的**只读数据段**（`.rodata` 段）中。

```c
char *str = "Hello";  // "Hello" 存储在只读数据段
```

### 字符串常量的合并

编译器可能会将相同的字符串常量合并为一份。

```c
char *s1 = "Hello";
char *s2 = "Hello";

// s1 和 s2 可能指向同一块内存
printf("%d\n", s1 == s2);  // 可能输出 1
```

## `char *str` 与 `char str[]` 的区别

| 对比项 | `char *str = "Hello"` | `char str[] = "Hello"` |
|--------|----------------------|------------------------|
| 本质 | 指针变量，指向字符串常量 | 字符数组 |
| 存储 | 指针在栈上，常量在只读段 | 数组在栈上（可写） |
| 能否修改内容 | 不能（常量只读） | 可以 |
| `sizeof(str)` | 指针大小（4/8 字节） | 数组大小（6 字节） |
| `strlen(str)` | 5 | 5 |

```c
char *s1 = "Hello";
char s2[] = "Hello";

// s1 = s2;   // 正确：指针可以重新指向
// s2 = s1;   // 错误：数组名是常量，不能赋值
// s1[0] = 'h';  // 危险！s1 指向只读常量
s2[0] = 'h';     // 正确：s2 是数组，内容可修改
```

> **注意**：是否**可修改**是二者的关键区别。需要修改字符串内容时用字符数组；只需要读取字符串常量时用字符指针。

## 字符串数组（`char *str[N]`）

用"指针数组"可以存放多个字符串，每个指针指向一个字符串常量（或字符串的首地址）：

```c
char *days[] = {"Monday", "Tuesday", "Wednesday",
                "Thursday", "Friday", "Saturday", "Sunday"};

for (int i = 0; i < 7; i++) {
    printf("%s\n", days[i]);   // 输出第 i 个字符串
}
```

与二维字符数组 `char names[7][20]` 相比，指针数组更节省空间（只存指针，不存固定大小的行），且字符串长短可以不同。

## 字符指针作函数参数

字符指针最常见的用途是作为函数参数，处理字符串。实参可以是字符数组名、字符串常量或字符指针。

```c
#include <stdio.h>

// 形参用 const char *，只读字符串
void print_upper(const char *str) {
    for (; *str != '\0'; str++) {
        putchar(*str - 'a' + 'A');
    }
    putchar('\n');
}

int main(void) {
    char name[] = "hello";   // 字符数组实参
    print_upper(name);       // 输出 HELLO

    print_upper("world");    // 字符串常量实参，输出 WORLD
    return 0;
}
```

**注意事项**：

- 若函数只读字符串，形参应写成 `const char *`，可同时接受字符数组和字符串常量。
- 若函数要修改字符串内容，实参必须是字符数组（或动态分配的、可写的内存），不能传字符串常量。

## 指针与字符串函数

### `strlen` 的实现

```c
size_t my_strlen(const char *s) {
    const char *p = s;
    while (*p != '\0') {
        p++;
    }
    return p - s;
}
```

### `strcpy` 的实现

```c
char *my_strcpy(char *dest, const char *src) {
    char *original = dest;
    while ((*dest++ = *src++) != '\0') {
        // 复制每个字符
    }
    return original;
}
```

### `strcmp` 的实现

```c
int my_strcmp(const char *s1, const char *s2) {
    while (*s1 && (*s1 == *s2)) {
        s1++;
        s2++;
    }
    return *(unsigned char *)s1 - *(unsigned char *)s2;
}
```

## 字符串与指针的常见陷阱

### 陷阱 1：修改字符串常量

```c
char *str = "Hello";
str[0] = 'h';  // 未定义行为！可能导致段错误
```

### 陷阱 2：未初始化的字符指针

```c
char *str;
// *str = 'H';  // 错误！str 是野指针
```

### 陷阱 3：忘记字符串结束符

```c
char str[5];
strcpy(str, "Hello");  // 错误！"Hello" 需要 6 个字节（包含 '\0'）
```

### 陷阱 4：指针算术与字符串长度

```c
char *str = "Hello";
printf("%zu\n", sizeof(str));  // 输出 8（指针大小），不是 5
printf("%zu\n", strlen(str));  // 输出 5（字符串长度）
```

## 字符串与指针的最佳实践

1. **使用 `const char*` 接收字符串常量**
2. **使用字符数组存储可修改的字符串**
3. **始终确保目标缓冲区足够大**
4. **使用 `fgets` 替代 `gets`**
5. **使用 `strncpy` 替代 `strcpy`**
6. **检查指针是否为 NULL**

## 字符串与指针的综合示例

```c
#include <stdio.h>
#include <string.h>

// 字符串反转（使用指针）
void reverse_string(char *str) {
    if (str == NULL) {
        return;
    }

    char *start = str;
    char *end = str + strlen(str) - 1;

    while (start < end) {
        char temp = *start;
        *start = *end;
        *end = temp;
        start++;
        end--;
    }
}

// 字符串查找（使用指针）
char *my_strstr(const char *haystack, const char *needle) {
    if (needle == NULL || *needle == '\0') {
        return (char *)haystack;
    }

    for (const char *h = haystack; *h != '\0'; h++) {
        const char *h_ptr = h;
        const char *n_ptr = needle;

        while (*h_ptr && *n_ptr && *h_ptr == *n_ptr) {
            h_ptr++;
            n_ptr++;
        }

        if (*n_ptr == '\0') {
            return (char *)h;
        }
    }

    return NULL;
}

int main(void) {
    char str[] = "Hello, World!";
    printf("原字符串：%s\n", str);

    reverse_string(str);
    printf("反转后：%s\n", str);

    char *pos = my_strstr(str, "World");
    if (pos != NULL) {
        printf("找到 'World'，位置：%ld\n", pos - str);
    }

    return 0;
}
```
