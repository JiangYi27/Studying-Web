# 指针运算

## 指针与整数的加减

### 基本概念

指针与整数相加减时，实际移动的字节数取决于指针指向的类型大小。

```c
int arr[] = {10, 20, 30, 40, 50};
int *p = arr;  // p 指向 arr[0]

// p + 1 移动的字节数 = sizeof(int) = 4 字节
// p + 2 移动的字节数 = 2 * sizeof(int) = 8 字节
```

### 地址计算

```c
int arr[] = {10, 20, 30, 40, 50};
int *p = arr;

printf("p = %p\n", p);          // 指向 arr[0]
printf("p + 1 = %p\n", p + 1);  // 指向 arr[1]，地址增加 4 字节
printf("p + 2 = %p\n", p + 2);  // 指向 arr[2]，地址增加 8 字节
printf("p - 1 = %p\n", p - 1);  // 指向 arr[-1]（越界！）
```

### 指针加减的步长规则

`p + n` 指向的是"从 p 开始往后数第 n 个元素"，而不是简单地加 n 个字节：

```
p + n 的地址 = p 的地址 + n × sizeof(*p)
p - n 的地址 = p 的地址 - n × sizeof(*p)
```

因此**指针类型决定了步长**：`int *` 的 `p+1` 移动 4 字节，`char *` 的 `p+1` 只移动 1 字节。

### 不同类型指针的加减差异

```c
int *pi;
char *pc;
double *pd;

// pi + 1 移动 sizeof(int) = 4 字节
// pc + 1 移动 sizeof(char) = 1 字节
// pd + 1 移动 sizeof(double) = 8 字节
```

## 指针相减

### 基本概念

两个指向同一数组的指针相减，结果是它们之间元素的个数。

```c
int arr[] = {10, 20, 30, 40, 50};
int *p1 = &arr[1];  // 指向 arr[1]
int *p2 = &arr[3];  // 指向 arr[3]

ptrdiff_t diff = p2 - p1;  // 结果为 2
```

### 指针相减的实现原理

```
p2 - p1 = (地址2 - 地址1) / sizeof(元素类型)
```

### 示例：计算数组长度

```c
int arr[] = {10, 20, 30, 40, 50};
int length = &arr[5] - arr;  // 结果为 5
```

## 指针比较

### 比较规则

可以比较两个指针的大小关系，但前提是它们指向同一数组或同一对象。

```c
int arr[] = {10, 20, 30, 40, 50};
int *p1 = &arr[1];
int *p2 = &arr[3];

if (p1 < p2) {
    printf("p1 在 p2 之前\n");
}

if (p1 <= p2) {
    printf("p1 在 p2 之前或相同位置\n");
}

if (p1 != p2) {
    printf("p1 和 p2 指向不同位置\n");
}
```

### 与 NULL 比较

```c
int *p = NULL;

if (p == NULL) {
    printf("p 是空指针\n");
}

if (p != NULL) {
    printf("p 不是空指针\n");
}
```

## 指针运算的常见应用

### 遍历数组

```c
int arr[] = {10, 20, 30, 40, 50};
int *p = arr;
int length = sizeof(arr) / sizeof(arr[0]);

// 方法 1：使用指针算术
for (int i = 0; i < length; i++) {
    printf("arr[%d] = %d\n", i, *(p + i));
}

// 方法 2：使用指针递增
for (int *q = arr; q < arr + length; q++) {
    printf("*q = %d\n", *q);
}
```

### 字符串遍历

```c
char *str = "Hello";

// 方法 1：使用指针算术
for (int i = 0; str[i] != '\0'; i++) {
    printf("%c", str[i]);
}

// 方法 2：使用指针递增
for (char *p = str; *p != '\0'; p++) {
    printf("%c", *p);
}

// 方法 3：使用指针比较
char *start = str;
char *end = str + strlen(str);
while (start < end) {
    printf("%c", *start++);
}
```

### 数组反转（使用指针）

```c
void reverse(int *arr, int length) {
    int *start = arr;
    int *end = arr + length - 1;

    while (start < end) {
        int temp = *start;
        *start = *end;
        *end = temp;
        start++;
        end--;
    }
}
```

## 指针运算的陷阱

### 陷阱 1：越界指针运算

```c
int arr[5] = {10, 20, 30, 40, 50};
int *p = arr + 10;  // 越界指针

// 虽然 p 本身可能不导致错误，但解引用会导致未定义行为
// *p = 100;  // 危险！
```

### 指针越界的危险

- **指针运算越界**：对数组越界位置的指针进行算术运算是未定义行为，但**比较**同一数组内的指针是允许的。
- **解引用越界指针**：访问越界位置的内存，可能读取到其他变量、破坏数据，甚至导致段错误崩溃。
- **循环越界**：遍历数组时循环条件写错（如 `p <= arr + 5` 而非 `p < arr + 5`），会在数组最后一个元素之外再访问一次，属于典型越界。

```c
// 错误示范：越界访问
void bad_loop(int arr[], int n) {
    for (int *p = arr; p <= arr + n; p++) {  // 多访问了一次！
        printf("%d\n", *p);
    }
}

// 正确写法：p < arr + n
void good_loop(int arr[], int n) {
    for (int *p = arr; p < arr + n; p++) {
        printf("%d\n", *p);
    }
}
```

### 陷阱 2：指向不同类型对象的指针相减

```c
int arr[5];
char *pc = (char *)arr;
int *pi = arr;

// pc - pi 是未定义行为！
// ptrdiff_t diff = pc - pi;  // 错误！
```

### 陷阱 3：指向不同数组的指针比较

```c
int arr1[5], arr2[5];
int *p1 = arr1;
int *p2 = arr2;

// p1 < p2 的结果是未定义行为！
```

## 指针与 `size_t` / `ptrdiff_t`

### `size_t`

`size_t` 是无符号整数类型，用于表示对象的大小。

```c
#include <stdio.h>

int main(void) {
    int arr[5];
    size_t size = sizeof(arr);  // size_t 类型
    printf("数组大小 = %zu 字节\n", size);
    return 0;
}
```

### `ptrdiff_t`

`ptrdiff_t` 是有符号整数类型，用于表示两个指针之间的差值。

```c
#include <stddef.h>

int arr[5];
int *p1 = &arr[1];
int *p2 = &arr[3];

ptrdiff_t diff = p2 - p1;  // ptrdiff_t 类型
printf("差值 = %td\n", diff);
```

## 指针运算的实用技巧

### 技巧 1：遍历字符串

```c
void print_string(const char *str) {
    while (*str != '\0') {
        putchar(*str++);
    }
    putchar('\n');
}
```

### 技巧 2：字符串复制

```c
char *my_strcpy(char *dest, const char *src) {
    char *original = dest;
    while ((*dest++ = *src++) != '\0') {
        // 复制每个字符，包括 '\0'
    }
    return original;
}
```

### 技巧 3：字符串比较

```c
int my_strcmp(const char *s1, const char *s2) {
    while (*s1 && (*s1 == *s2)) {
        s1++;
        s2++;
    }
    return *(unsigned char *)s1 - *(unsigned char *)s2;
}
```

### 技巧 4：内存设置

```c
void *my_memset(void *dest, int c, size_t n) {
    unsigned char *p = (unsigned char *)dest;
    for (size_t i = 0; i < n; i++) {
        p[i] = (unsigned char)c;
    }
    return dest;
}
```

## 指针运算总结

| 运算 | 含义 | 示例 |
|------|------|------|
| `p + n` | 指向后 n 个元素 | `p + 3` |
| `p - n` | 指向前 n 个元素 | `p - 2` |
| `p - q` | 两个指针之间的元素个数 | `p2 - p1` |
| `p++` | 指向下一个元素 | `p++` |
| `p--` | 指向前一个元素 | `p--` |
| `*p` | 解引用，访问指向的值 | `*p = 10` |
| `p == q` | 比较是否指向同一位置 | `p == q` |
| `p != q` | 比较是否指向不同位置 | `p != q` |
| `p < q` | 比较位置先后 | `p < q` |

## 注意事项

1. **指针运算只在同一数组内有效**
2. **不同类型指针的运算步长不同**
3. **指向不同数组的指针不能相减**
4. **越界指针运算可能导致未定义行为**
5. **使用 `size_t` 和 `ptrdiff_t` 确保可移植性**
