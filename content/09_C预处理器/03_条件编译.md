# 条件编译

## 基本概念

条件编译指令允许在预处理阶段根据条件决定是否包含某段代码，常用于跨平台兼容和调试。

## 条件编译指令

### `#if`

```c
#if 常量表达式
    // 条件为真时编译
#endif
```

### `#ifdef`

```c
#ifdef 宏名
    // 宏已定义时编译
#endif
```

等价于：
```c
#if defined(宏名)
    // 宏已定义时编译
#endif
```

### `#ifndef`

```c
#ifndef 宏名
    // 宏未定义时编译
#endif
```

等价于：
```c
#if !defined(宏名)
    // 宏未定义时编译
#endif
```

### `#elif`

```c
#if 条件1
    // 条件1为真时编译
#elif 条件2
    // 条件1为假且条件2为真时编译
#elif 条件3
    // 条件1和条件2都为假且条件3为真时编译
#else
    // 所有条件都为假时编译
#endif
```

### `#else`

```c
#if 条件
    // 条件为真时编译
#else
    // 条件为假时编译
#endif
```

## 条件编译的应用场景

### 1. 跨平台兼容

```c
#ifdef _WIN32
    #include <windows.h>
    #define PATH_SEPARATOR '\\'
#elif defined(__APPLE__)
    #include <TargetConditionals.h>
    #define PATH_SEPARATOR '/'
#elif defined(__linux__)
    #include <unistd.h>
    #define PATH_SEPARATOR '/'
#else
    #error "Unsupported platform"
#endif
```

### 2. 调试模式

```c
#ifdef DEBUG
    #define LOG(msg) printf("DEBUG: %s\n", msg)
    #define LOG_VAR(x) printf("DEBUG: %s = %d\n", #x, x)
#else
    #define LOG(msg)
    #define LOG_VAR(x)
#endif
```

### 3. 功能开关

```c
#define ENABLE_FEATURE_A 1
#define ENABLE_FEATURE_B 0

#if ENABLE_FEATURE_A
    void feature_a(void);
#endif

#if ENABLE_FEATURE_B
    void feature_b(void);
#endif
```

### 4. 版本控制

```c
#if __STDC_VERSION__ >= 201112L
    // C11 或更高版本
    #include <stdatomic.h>
#elif __STDC_VERSION__ >= 199901L
    // C99
    #include <stdbool.h>
#else
    // C89/C90
#endif
```

### 5. 头文件守卫

```c
#ifndef MY_HEADER_H
#define MY_HEADER_H

// 头文件内容

#endif
```

## 条件编译的嵌套

```c
#if defined(_WIN32)
    #if defined(_WIN64)
        printf("Windows 64-bit\n");
    #else
        printf("Windows 32-bit\n");
    #endif
#elif defined(__APPLE__)
    printf("macOS\n");
#elif defined(__linux__)
    printf("Linux\n");
#else
    printf("Unknown platform\n");
#endif
```

## 预定义宏

C 编译器提供了一些预定义宏，可用于条件编译。

| 宏名 | 说明 |
|------|------|
| `__FILE__` | 当前文件名 |
| `__LINE__` | 当前行号 |
| `__DATE__` | 编译日期 |
| `__TIME__` | 编译时间 |
| `__STDC__` | 编译器是否符合 C 标准 |
| `__STDC_VERSION__` | C 标准版本号 |
| `__func__` | 当前函数名（C99） |

### 示例

```c
printf("File: %s, Line: %d\n", __FILE__, __LINE__);
printf("Date: %s, Time: %s\n", __DATE__, __TIME__);
```

## 条件编译与运行时的对比

| 特性 | 条件编译 | 运行时条件 |
|------|----------|-----------|
| 处理阶段 | 预处理阶段 | 运行阶段 |
| 生成代码 | 只包含符合条件的代码 | 包含所有代码 |
| 可执行文件大小 | 更小 | 更大 |
| 灵活性 | 低（编译时确定） | 高（运行时确定） |
| 适用场景 | 平台适配、调试开关 | 用户输入、配置选项 |

## 条件编译的最佳实践

1. **使用头文件守卫**（`#ifndef...#endif` 或 `#pragma once`）
2. **使用有意义的宏名**（如 `DEBUG`、`RELEASE`）
3. **避免过度使用条件编译**（增加代码复杂度）
4. **使用 `#error` 提示不支持的配置**
5. **使用 `#warning` 输出警告信息**
6. **将平台相关代码隔离到单独的文件中**

## 条件编译的常见错误

### 1. 忘记 #endif

```c
#ifdef DEBUG
    printf("Debug mode\n");
// 忘记 #endif
```

### 2. 误用 #if 判断宏是否定义

```c
#if DEBUG  // DEBUG 未定义时按 0 处理，条件恒为假，不会报错
```

未定义的宏在 `#if` 表达式中一律按 `0` 处理，因此 `#if DEBUG` 并不会报错。若想判断"宏是否已定义"，应使用 `#ifdef` 或 `#if defined(DEBUG)`，而不是 `#if DEBUG`；否则当 `DEBUG` 被定义为 `0` 时也会被误判为未定义。

### 3. 宏名拼写错误

```c
#ifdef DEUBG  // 拼写错误，应该是 DEBUG
```

### 4. 条件编译嵌套过深

```c
#if defined(_WIN32)
    #if defined(_WIN64)
        #if defined(_MSC_VER)
            // ...
        #endif
    #endif
#endif
```

建议将平台相关代码分离到单独的文件中。
