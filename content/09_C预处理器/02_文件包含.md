# 文件包含（#include）

## 基本语法

```c
#include <header.h>    // 从系统标准路径搜索
#include "header.h"    // 先从当前目录搜索，再从系统路径搜索
```

注意：`#include` 指令的本质是**文本插入**——预处理程序将被包含文件的全部内容原样复制到该指令所在位置，再与当前文件一起编译。被包含的可以是任意文本文件（最常见的是头文件 `.h`），从语法上讲也可以包含 `.c` 源文件，但实际开发中应避免包含 `.c` 文件，以免产生重复定义等问题。

## 头文件的作用

头文件用于声明函数原型、宏定义、类型定义和全局变量声明，实现代码的模块化。

### 头文件示例

```c
// math_utils.h
#ifndef MATH_UTILS_H
#define MATH_UTILS_H

// 函数声明
int add(int a, int b);
int subtract(int a, int b);

// 宏定义
#define PI 3.14159265
#define MAX_SIZE 100

// 类型定义
typedef struct {
    int x;
    int y;
} Point;

#endif
```

## 头文件守卫

### 使用 #ifndef...#define...#endif

这是最传统的头文件守卫方式，防止头文件被重复包含。

```c
#ifndef MY_HEADER_H
#define MY_HEADER_H

// 头文件内容

#endif
```

### 使用 #pragma once

`#pragma once` 是非标准但广泛支持的替代方式。

```c
#pragma once

// 头文件内容
```

### 两种方式的对比

| 特性 | #ifndef...#endif | #pragma once |
|------|------------------|--------------|
| 标准 | C 标准 | 非标准（但广泛支持） |
| 可靠性 | 完全可靠 | 可靠（现代编译器支持） |
| 符号命名 | 需要唯一符号名 | 无需命名 |
| 性能 | 每次都检查 | 编译器优化 |

## 包含路径

### 系统路径

`#include <header.h>` 从系统标准路径搜索头文件。

```c
#include <stdio.h>    // 标准库头文件
#include <stdlib.h>
#include <string.h>
```

### 用户路径

`#include "header.h"` 先从当前目录搜索，再从系统路径搜索。

```c
#include "myheader.h"  // 用户自定义头文件
#include "utils/math.h" // 相对路径
```

### 指定包含路径

使用 `-I` 选项指定额外的包含路径。

```bash
gcc -I./include -I../lib/main program.c -o program
```

## 循环包含问题

### 循环包含的原因

当两个头文件互相包含时，会导致循环包含问题。

```c
// a.h
#include "b.h"
// ...

// b.h
#include "a.h"
// ...
```

### 解决方法

1. **使用头文件守卫**（推荐）
2. **使用前置声明**
3. **重构代码，消除循环依赖**

### 前置声明

```c
// a.h
struct B;  // 前置声明

struct A {
    struct B *b;
};

// a.c
#include "b.h"
```

## 包含最佳实践

1. **始终使用头文件守卫**
2. **使用 `#pragma once` 或 `#ifndef...#endif`**
3. **头文件中只放声明，不放定义**（内联函数和模板除外）
4. **避免在头文件中定义全局变量**（使用 `extern` 声明）
5. **使用 `-I` 选项管理包含路径**
6. **避免循环包含**
7. **头文件按字母顺序排列**

## 条件编译与头文件

```c
#ifndef MY_HEADER_H
#define MY_HEADER_H

#ifdef __cplusplus
extern "C" {
#endif

// C 头文件内容

#ifdef __cplusplus
}
#endif

#endif
```

## 包含顺序

推荐的包含顺序：

1. 当前头文件（如果对应 .c 文件）
2. 系统头文件（`<>`）
3. 用户头文件（`""`）

```c
#include "myheader.h"  // 当前头文件

#include <stdio.h>     // 系统头文件
#include <stdlib.h>

#include "utils.h"     // 用户头文件
#include "config.h"
```
