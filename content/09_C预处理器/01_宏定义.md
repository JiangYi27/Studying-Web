# 宏定义（#define）

## 无参宏

### 基本语法

```c
#define 宏名 替换文本
```

### 示例

```c
#define PI 3.14159265
#define MAX_SIZE 100
#define GREETING "Hello, World!"
```

### 替换规则

预处理阶段，预处理程序将源代码中所有出现的宏名替换为替换文本。

```c
#define PI 3.14159265

double area = PI * r * r;  // 替换后：double area = 3.14159265 * r * r;
```

注意：宏替换发生在**预处理阶段**，只做纯文本替换，不做任何计算和类型检查。另外，出现在**字符串字面量**中的宏名不会被替换，例如 `printf("PI = %f", PI);` 中字符串里的 `"PI"` 保持不变，只有字符串外的 `PI` 被替换为 `3.14159265`。

### 宏定义的注意事项

1. **宏名通常使用大写字母**
2. **宏定义不以分号结尾**
3. **宏定义不分配内存**
4. **宏定义没有类型检查**
5. **宏定义从定义处到文件结束有效**

### 取消宏定义

使用 `#undef` 取消宏定义。

```c
#define MAX_SIZE 100
// ... 使用 MAX_SIZE ...
#undef MAX_SIZE  // 取消 MAX_SIZE 的定义
```

## 带参宏

### 基本语法

```c
#define 宏名(参数列表) 替换文本
```

### 示例

```c
#define MAX(a, b) ((a) > (b) ? (a) : (b))
#define MIN(a, b) ((a) < (b) ? (a) : (b))
#define SQUARE(x) ((x) * (x))
```

### 替换过程

```c
#define SQUARE(x) ((x) * (x))

int result = SQUARE(5);  // 替换后：int result = ((5) * (5));
```

### 括号问题

带参宏中必须使用括号，否则可能导致意外结果。

```c
// 错误示例：缺少括号
#define SQUARE_BAD(x) x * x

int a = 5;
int result = SQUARE_BAD(a + 1);  // 替换后：a + 1 * a + 1 = 5 + 1 * 5 + 1 = 11（不是 36）

// 正确示例：使用括号
#define SQUARE_GOOD(x) ((x) * (x))

int result2 = SQUARE_GOOD(a + 1);  // 替换后：((a + 1) * (a + 1)) = 36
```

### 副作用问题

带参宏的参数可能被多次求值，导致副作用问题。

```c
#define MAX(a, b) ((a) > (b) ? (a) : (b))

int x = 5, y = 3;
int result = MAX(x++, y++);  // x++ 和 y++ 可能被多次求值！
// x 可能自增 1 或 2 次，y 同理
```

### 宏与函数的对比

| 特性 | 宏 | 函数 |
|------|-----|------|
| 处理阶段 | 预处理阶段 | 编译阶段 |
| 类型检查 | 无 | 有 |
| 参数求值 | 可能多次求值 | 只求值一次 |
| 代码膨胀 | 每次调用展开代码 | 只有一份代码 |
| 调试 | 难以调试 | 易于调试 |
| 性能 | 无调用开销 | 有调用开销 |

## `#` 和 `##` 运算符

### `#` 运算符（字符串化）

将宏参数转换为字符串字面量。

```c
#define STRINGIFY(x) #x

printf("%s\n", STRINGIFY(Hello));  // 输出 "Hello"
printf("%s\n", STRINGIFY(123));    // 输出 "123"
```

### `##` 运算符（标记粘贴）

将两个标记拼接为一个标记。

```c
#define CONCAT(a, b) a##b

int xy = 10;
printf("%d\n", CONCAT(x, y));  // 输出 10（等价于 xy）

#define MAKE_VAR(name, num) var_##name##_##num
int MAKE_VAR(foo, 1) = 42;  // 等价于 int var_foo_1 = 42;
```

### `#` 和 `##` 的组合使用

```c
#define REGISTER(name, id) \
    printf("Register: " #name " (ID: " #id ")\n")

REGISTER(Alice, 1001);  // 输出：Register: Alice (ID: 1001)
```

## 宏定义的最佳实践

1. **始终使用括号保护参数**
2. **避免宏的副作用**（参数可能被多次求值）
3. **使用大写字母命名宏**
4. **使用 `#undef` 取消不需要的宏定义**
5. **优先使用内联函数替代简单宏**
6. **使用 `do { ... } while (0)` 包裹多语句宏**

### 多语句宏的陷阱

```c
// 错误示例
#define SWAP(a, b) { int temp = a; a = b; b = temp; }

if (x > y)
    SWAP(x, y);  // 展开后：if (x > y) { ... }  // else 会绑定到 if
else
    // ...

// 正确示例：使用 do-while
#define SWAP(a, b) do { int temp = a; a = b; b = temp; } while (0)

if (x > y)
    SWAP(x, y);  // 展开后：if (x > y) do { ... } while (0);
else
    // ...
```

## 条件宏

### 调试宏

```c
#ifdef DEBUG
    #define LOG(msg) printf("DEBUG: %s\n", msg)
    #define LOG_VAR(x) printf("DEBUG: %s = %d\n", #x, x)
#else
    #define LOG(msg)
    #define LOG_VAR(x)
#endif
```

### 平台相关宏

```c
#ifdef _WIN32
    #define PLATFORM "Windows"
#elif defined(__APPLE__)
    #define PLATFORM "macOS"
#elif defined(__linux__)
    #define PLATFORM "Linux"
#else
    #define PLATFORM "Unknown"
#endif
```

## 宏定义的常见错误

1. **忘记括号**：导致运算符优先级错误
2. **参数多次求值**：导致副作用问题
3. **宏名与变量名冲突**：意外替换
4. **忘记 #undef**：导致宏定义污染
5. **多语句宏缺少 do-while**：导致 if-else 绑定错误
