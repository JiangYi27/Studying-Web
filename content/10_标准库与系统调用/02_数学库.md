# 数学库（math.h）

## 概述

`math.h` 提供了常用的数学函数，需要在编译时链接数学库（`-lm` 选项）。

## 编译链接

```bash
gcc program.c -o program -lm
```

## 常用数学函数

### 三角函数

| 函数 | 说明 |
|------|------|
| `sin(x)` | 正弦 |
| `cos(x)` | 余弦 |
| `tan(x)` | 正切 |
| `asin(x)` | 反正弦 |
| `acos(x)` | 反余弦 |
| `atan(x)` | 反正切 |
| `atan2(y, x)` | 两参数反正切 |

> **注意**：所有三角函数使用**弧度**而非角度。角度换算公式：弧度 = 角度 × π / 180。

```c
#define DEG_TO_RAD(x) ((x) * M_PI / 180.0)   // 角度转弧度宏

printf("%.4f\n", sin(DEG_TO_RAD(90)));  // 输出 1.0000
printf("%.4f\n", cos(0.0));             // 输出 1.0000
```

### 双曲函数

| 函数 | 说明 |
|------|------|
| `sinh(x)` | 双曲正弦 |
| `cosh(x)` | 双曲余弦 |
| `tanh(x)` | 双曲正切 |

### 指数与对数

| 函数 | 说明 |
|------|------|
| `exp(x)` | e^x |
| `exp2(x)` | 2^x |
| `log(x)` | 自然对数 ln(x) |
| `log10(x)` | 常用对数 log10(x) |
| `log2(x)` | 以 2 为底的对数 |
| `pow(x, y)` | x^y |
| `sqrt(x)` | √x |
| `cbrt(x)` | ³√x |

### 舍入函数

| 函数 | 说明 |
|------|------|
| `ceil(x)` | 向上取整 |
| `floor(x)` | 向下取整 |
| `round(x)` | 四舍五入 |
| `trunc(x)` | 截断取整 |
| `rint(x)` | 四舍五入到最近整数 |

### 绝对值

| 函数 | 说明 |
|------|------|
| `fabs(x)` | 浮点数绝对值 |
| `fabsf(x)` | float 绝对值 |
| `fabsl(x)` | long double 绝对值 |

### 其他函数

| 函数 | 说明 |
|------|------|
| `fmod(x, y)` | 浮点数取模 |
| `remainder(x, y)` | 余数 |
| `hypot(x, y)` | √(x² + y²) |
| `frexp(x, &exp)` | 分解为尾数和指数 |
| `ldexp(x, exp)` | x × 2^exp |
| `modf(x, &intpart)` | 分解为整数和小数部分 |

## 示例

```c
#include <stdio.h>
#include <math.h>

int main(void) {
    double x = 3.14159265;

    printf("sin(π/2) = %f\n", sin(M_PI / 2));
    printf("cos(π) = %f\n", cos(M_PI));
    printf("exp(1) = %f\n", exp(1.0));
    printf("log(e) = %f\n", log(M_E));
    printf("sqrt(2) = %f\n", sqrt(2.0));
    printf("pow(2, 10) = %f\n", pow(2, 10));
    printf("ceil(3.14) = %f\n", ceil(3.14));
    printf("floor(3.14) = %f\n", floor(3.14));
    printf("fabs(-3.14) = %f\n", fabs(-3.14));

    return 0;
}
```

## 编译错误

忘记链接数学库会导致链接错误：

```bash
gcc program.c -o program  # 错误！缺少 -lm
gcc program.c -o program -lm  # 正确
```

## 数学常量

```c
#define M_E        2.71828182845904523536   // e
#define M_LOG2E    1.44269504088896340736   // log2(e)
#define M_LOG10E   0.43429448190325182765   // log10(e)
#define M_LN2      0.69314718055994530942   // ln(2)
#define M_LN10     2.30258509299404568402   // ln(10)
#define M_PI       3.14159265358979323846   // π
#define M_PI_2     1.57079632679489661923   // π/2
#define M_PI_4     0.78539816339744830962   // π/4
#define M_1_PI     0.31830988618379067154   // 1/π
#define M_2_PI     0.63661977236758134308   // 2/π
#define M_2_SQRTPI 1.12837916709551257390   // 2/√π
#define M_SQRT2    1.41421356237309504880   // √2
#define M_SQRT1_2  0.70710678118654752440   // 1/√2
```

> **注意**：这些常量不是 C 标准的一部分，但被广泛支持。在某些编译器上可能需要定义 `_USE_MATH_DEFINES`。
