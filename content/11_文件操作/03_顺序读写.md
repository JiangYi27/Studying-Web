# 顺序读写

## 字符级 I/O

### fputc — 写字符

```c
int fputc(int character, FILE *stream);
```

将单个字符写入文件流。

```c
FILE *fp = fopen("output.txt", "w");
if (fp != NULL) {
    fputc('H', fp);
    fputc('e', fp);
    fputc('l', fp);
    fputc('l', fp);
    fputc('o', fp);
    fputc('\n', fp);
    fclose(fp);
}
```

### fgetc — 读字符

```c
int fgetc(FILE *stream);
```

从文件流读取单个字符。返回 `EOF` 表示文件结束或出错。

```c
FILE *fp = fopen("input.txt", "r");
if (fp != NULL) {
    int ch;
    while ((ch = fgetc(fp)) != EOF) {
        putchar(ch);
    }
    fclose(fp);
}
```

### 注意事项

- `fgetc` 返回 `int` 类型（不是 `char`），因为 `EOF` 需要用 `int` 表示
- `EOF` 的值通常为 `-1`

## 字符串级 I/O

### fputs — 写字符串

```c
int fputs(const char *str, FILE *stream);
```

将字符串写入文件流（不自动添加换行符）。

```c
FILE *fp = fopen("output.txt", "w");
if (fp != NULL) {
    fputs("Hello, World!\n", fp);
    fputs("This is a test.\n", fp);
    fclose(fp);
}
```

### fgets — 读字符串

```c
char *fgets(char *str, int n, FILE *stream);
```

从文件流读取一行（最多 `n-1` 个字符），自动添加 `'\0'`。

```c
FILE *fp = fopen("input.txt", "r");
if (fp != NULL) {
    char buf[100];
    while (fgets(buf, sizeof(buf), fp) != NULL) {
        printf("%s", buf);
    }
    fclose(fp);
}
```

### fgets 的特点

1. **保留换行符**：如果读取的行包含换行符，`fgets` 会将其保留在字符串中
2. **读取长度限制**：最多读取 `n-1` 个字符
3. **返回值**：成功返回 `str`，文件结束或出错返回 `NULL`

### 去除 fgets 读取的换行符

```c
char *fgets(char *str, int n, FILE *stream);

// 去除换行符
size_t len = strlen(str);
if (len > 0 && str[len - 1] == '\n') {
    str[len - 1] = '\0';
}
```

## 格式化 I/O

### fprintf — 格式化写

```c
int fprintf(FILE *stream, const char *format, ...);
```

类似于 `printf`，但输出到文件流。

```c
FILE *fp = fopen("output.txt", "w");
if (fp != NULL) {
    fprintf(fp, "Name: %s, Age: %d, Score: %.2f\n", "Alice", 20, 95.5);
    fclose(fp);
}
```

### fscanf — 格式化读

```c
int fscanf(FILE *stream, const char *format, ...);
```

类似于 `scanf`，但从文件流读取。

```c
FILE *fp = fopen("input.txt", "r");
if (fp != NULL) {
    char name[50];
    int age;
    float score;

    while (fscanf(fp, "%s %d %f", name, &age, &score) == 3) {
        printf("Name: %s, Age: %d, Score: %.2f\n", name, age, score);
    }
    fclose(fp);
}
```

### fscanf 的返回值

`fscanf` 返回成功读取并赋值的参数个数。

```c
int result = fscanf(fp, "%d %s", &num, str);
if (result == 2) {
    // 成功读取两个值
} else if (result == EOF) {
    // 文件结束
} else {
    // 读取错误
}
```

## 二进制 I/O

### fwrite — 写二进制数据

```c
size_t fwrite(const void *ptr, size_t size, size_t nmemb, FILE *stream);
```

将 `nmemb` 个大小为 `size` 的元素写入文件流。

```c
int arr[] = {1, 2, 3, 4, 5};
FILE *fp = fopen("data.bin", "wb");
if (fp != NULL) {
    size_t written = fwrite(arr, sizeof(int), 5, fp);
    printf("写入 %zu 个元素\n", written);
    fclose(fp);
}
```

### fread — 读二进制数据

```c
size_t fread(void *ptr, size_t size, size_t nmemb, FILE *stream);
```

从文件流读取 `nmemb` 个大小为 `size` 的元素。

```c
int arr[5];
FILE *fp = fopen("data.bin", "rb");
if (fp != NULL) {
    size_t count = fread(arr, sizeof(int), 5, fp);
    printf("读取了 %zu 个元素\n", count);
    for (int i = 0; i < count; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");
    fclose(fp);
}
```

### fwrite/fread 的返回值

- 返回实际读写到的元素个数
- 可能小于 `nmemb`（文件结束或出错）

## 顺序读写示例

### 复制文件

```c
#include <stdio.h>

int main(void) {
    FILE *src = fopen("source.txt", "r");
    FILE *dst = fopen("destination.txt", "w");

    if (src == NULL || dst == NULL) {
        perror("fopen");
        if (src) fclose(src);
        if (dst) fclose(dst);
        return 1;
    }

    int ch;
    while ((ch = fgetc(src)) != EOF) {
        fputc(ch, dst);
    }

    fclose(src);
    fclose(dst);

    return 0;
}
```

### 写入结构化数据

```c
#include <stdio.h>

struct Student {
    char name[50];
    int age;
    float score;
};

int main(void) {
    struct Student students[] = {
        {"Alice", 20, 95.5},
        {"Bob", 21, 88.0},
        {"Charlie", 19, 92.5}
    };

    // 写入
    FILE *fp = fopen("students.dat", "wb");
    if (fp != NULL) {
        fwrite(students, sizeof(struct Student), 3, fp);
        fclose(fp);
    }

    // 读取
    struct Student read_students[3];
    fp = fopen("students.dat", "rb");
    if (fp != NULL) {
        size_t count = fread(read_students, sizeof(struct Student), 3, fp);
        for (size_t i = 0; i < count; i++) {
            printf("Name: %s, Age: %d, Score: %.1f\n",
                   read_students[i].name,
                   read_students[i].age,
                   read_students[i].score);
        }
        fclose(fp);
    }

    return 0;
}
```

## 顺序读写的注意事项

1. **使用二进制模式读写二进制数据**
2. **检查 fread/fwrite 的返回值**
3. **使用 fgets 替代 fscanf 读取字符串**
4. **注意 fscanf 的格式字符串中的空白字符**
5. **使用 feof 和 ferror 区分文件结束和错误**
