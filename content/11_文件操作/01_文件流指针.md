# 文件流指针（FILE*）

## 基本概念

`FILE` 是 `stdio.h` 中定义的结构体类型，用于表示文件流。每个打开的文件都对应一个 `FILE*` 指针。

## 文本文件与二进制文件

### 文本文件

文本文件以字符形式存储数据，每个字符对应一个字节。

- 换行符 `\n` 在不同平台上可能有不同的表示
- Windows 上 `\n` 被转换为 `\r\n`（回车+换行）
- 读取时 `\r\n` 被转换回 `\n`

### 二进制文件

二进制文件以原始字节形式存储数据，不进行任何转换。

- 适合存储图片、音频、视频等非文本数据
- 读写效率更高
- 数据保持原始格式

### 对比

| 特性 | 文本文件 | 二进制文件 |
|------|----------|-----------|
| 存储方式 | 字符形式 | 原始字节 |
| 换行处理 | 自动转换 | 不转换 |
| 可读性 | 可读 | 不可读 |
| 适用场景 | 文本数据 | 二进制数据 |
| 效率 | 较低 | 较高 |

## 文件流指针的生命周期

### 创建

通过 `fopen()` 创建文件流指针。

```c
FILE *fp = fopen("test.txt", "r");
```

### 使用

通过文件流指针进行读写操作。

```c
fprintf(fp, "Hello, World!\n");
```

### 销毁

通过 `fclose()` 销毁文件流指针。

```c
fclose(fp);
fp = NULL;
```

## 标准流

C 程序启动时自动打开三个标准流：

| 流 | 指针 | 默认设备 |
|------|------|----------|
| 标准输入 | `stdin` | 键盘 |
| 标准输出 | `stdout` | 终端 |
| 标准错误 | `stderr` | 终端 |

### 标准流与 I/O 函数的关系

标准流就是三个预先打开的 `FILE*`，因此文件读写函数同样适用于标准流，也可以与 `printf`/`scanf` 相互转换：

| 文件函数 | 等价的标准 I/O 函数 |
|----------|---------------------|
| `fgetc(stdin)` | `getchar()` |
| `fputc(c, stdout)` | `putchar(c)` |
| `fgets(buf, n, stdin)` | `gets()`（但 `gets` 不安全，不推荐） |
| `fprintf(stdout, ...)` | `printf(...)` |
| `fscanf(stdin, ...)` | `scanf(...)` |
| `fputs(str, stdout)` | `puts(str)` |

```c
fprintf(stderr, "错误：文件打开失败\n");  // 错误信息输出到标准错误
printf("正常输出\n");                       // 等价于 fprintf(stdout, ...)
```

### 重定向

```bash
# 标准输出重定向到文件
./program > output.txt

# 标准输入重定向从文件读取
./program < input.txt

# 标准错误重定向到文件
./program 2> error.txt

# 同时重定向
./program < input.txt > output.txt 2> error.txt
```

## FILE 结构体

`FILE` 结构体的内部实现因编译器而异，通常包含以下信息：

- 文件描述符
- 缓冲区指针
- 缓冲区状态
- 文件位置指示器
- 错误标志
- 文件结束标志

## 文件流指针的最佳实践

1. **始终检查 fopen 的返回值**
2. **使用后关闭文件**
3. **关闭后将指针设为 NULL**
4. **使用 stderr 输出错误信息**
5. **避免返回局部 FILE* 指针**
