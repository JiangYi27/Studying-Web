# 文件打开与关闭

## fopen() — 打开文件

### 基本语法

```c
FILE *fopen(const char *filename, const char *mode);
```

### 打开模式详解

| 模式 | 说明 | 文件不存在 | 文件已存在 |
|------|------|-----------|-----------|
| `"r"` | 只读（文本） | 失败返回 NULL | 从头读取 |
| `"w"` | 只写（文本） | 创建新文件 | 清空内容 |
| `"a"` | 追加（文本） | 创建新文件 | 在末尾追加 |
| `"r+"` | 读写（文本） | 失败返回 NULL | 从头读写 |
| `"w+"` | 读写（文本） | 创建新文件 | 清空内容 |
| `"a+"` | 读写（文本） | 创建新文件 | 读取+追加 |
| `"rb"` | 只读（二进制） | 失败返回 NULL | 从头读取 |
| `"wb"` | 只写（二进制） | 创建新文件 | 清空内容 |
| `"ab"` | 追加（二进制） | 创建新文件 | 在末尾追加 |
| `"rb+"` | 读写（二进制） | 失败返回 NULL | 从头读写 |
| `"wb+"` | 读写（二进制） | 创建新文件 | 清空内容 |
| `"ab+"` | 读写（二进制） | 创建新文件 | 读取+追加 |

### 示例

```c
#include <stdio.h>

int main(void) {
    // 只读模式打开文件
    FILE *fp1 = fopen("input.txt", "r");
    if (fp1 == NULL) {
        perror("fopen");
        return 1;
    }

    // 只写模式打开文件（会清空已有内容）
    FILE *fp2 = fopen("output.txt", "w");
    if (fp2 == NULL) {
        perror("fopen");
        fclose(fp1);
        return 1;
    }

    // 追加模式打开文件
    FILE *fp3 = fopen("log.txt", "a");
    if (fp3 == NULL) {
        perror("fopen");
        fclose(fp1);
        fclose(fp2);
        return 1;
    }

    // 使用文件...

    // 关闭文件
    fclose(fp1);
    fclose(fp2);
    fclose(fp3);

    return 0;
}
```

## fclose() — 关闭文件

### 基本语法

```c
int fclose(FILE *fp);
```

### 功能

1. 刷新输出缓冲区
2. 关闭文件
3. 释放文件流指针占用的资源

### 返回值

- 成功返回 `0`
- 失败返回 `EOF`

### 示例

```c
FILE *fp = fopen("test.txt", "w");
if (fp != NULL) {
    fprintf(fp, "Hello, World!\n");
    if (fclose(fp) != 0) {
        perror("fclose");
    }
}
```

## fopen 常见错误

### 1. 文件不存在

```c
FILE *fp = fopen("nonexistent.txt", "r");
if (fp == NULL) {
    perror("fopen");  // 输出 "fopen: No such file or directory"
}
```

### 2. 权限不足

```c
FILE *fp = fopen("/etc/shadow", "r");
if (fp == NULL) {
    perror("fopen");  // 输出 "fopen: Permission denied"
}
```

### 3. 忘记检查返回值

```c
FILE *fp = fopen("test.txt", "r");
// 未检查 fp 是否为 NULL
fprintf(fp, "Hello");  // 如果 fp 为 NULL，会导致段错误
```

### 4. 忘记关闭文件

```c
FILE *fp = fopen("test.txt", "w");
fprintf(fp, "Hello");
// 忘记 fclose(fp);
// 可能导致数据丢失（缓冲区未刷新）
```

## 文件路径

### 绝对路径

```c
FILE *fp = fopen("/home/user/file.txt", "r");  // Linux/macOS
FILE *fp = fopen("C:\\Users\\user\\file.txt", "r");  // Windows
```

### 相对路径

```c
FILE *fp = fopen("data/file.txt", "r");  // 相对于当前目录
FILE *fp = fopen("../file.txt", "r");    // 相对于上级目录
FILE *fp = fopen("./file.txt", "r");     // 当前目录
```

## 文件操作的安全实践

1. **始终检查 fopen 的返回值**
2. **使用 perror 输出错误信息**
3. **使用 fclose 关闭文件**
4. **关闭后将指针设为 NULL**
5. **使用二进制模式读写二进制数据**
6. **避免使用相对路径（除非确定当前目录）**
7. **使用临时文件时注意原子操作**
