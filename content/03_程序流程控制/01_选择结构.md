# 选择结构

## `if...else if...else` 语句

### 基本语法

```c
if (条件表达式) {
    // 条件为真时执行
} else {
    // 条件为假时执行
}
```

### 多分支选择

```c
if (条件1) {
    // 条件1为真时执行
} else if (条件2) {
    // 条件1为假且条件2为真时执行
} else if (条件3) {
    // 条件1和条件2都为假且条件3为真时执行
} else {
    // 所有条件都为假时执行
}
```

### 示例：成绩等级判断

```c
#include <stdio.h>

int main(void) {
    int score;
    printf("请输入成绩：");
    scanf("%d", &score);

    if (score >= 90) {
        printf("等级：A\n");
    } else if (score >= 80) {
        printf("等级：B\n");
    } else if (score >= 70) {
        printf("等级：C\n");
    } else if (score >= 60) {
        printf("等级：D\n");
    } else {
        printf("等级：F\n");
    }

    return 0;
}
```

### `if` 语句的常见陷阱

#### 陷阱 1：悬空 else（就近配对）

```c
int a = 1, b = 2, c = 3;

if (a > 0)
    if (b > 0)
        printf("b > 0\n");
    else
        printf("b <= 0\n");  // 这个 else 与 if (b > 0) 配对，不是 if (a > 0)
```

**配对规则**：C 语言规定，`else` 总是与它**前面最近的、还没有配对的 `if`** 配对（就近配对原则），而不是与书写缩进对齐的那个 `if` 配对。

上面的代码中 `else` 与 `if (b > 0)` 配对，`a > 0` 成立但不满足 `b > 0` 时，会输出 `"b <= 0"`。

**正确做法**：书写嵌套 `if` 时尽量使用大括号明确结构，避免歧义：

```c
if (a > 0) {
    if (b > 0) {
        printf("b > 0\n");
    } else {
        printf("b <= 0\n");
    }
}
```

#### 陷阱 2：赋值与比较混淆

```c
// 错误：赋值而非比较
if (a = 5) {
    // 这会将 5 赋值给 a，然后判断 a 是否为非零（永远为真）
}

// 正确：比较
if (a == 5) {
    // 判断 a 是否等于 5
}

// 建议：使用 Yoda 条件（常量在左边）
if (5 == a) {
    // 如果误写为 =，编译器会报错
}
```

#### 陷阱 3：布尔表达式错误

```c
// 错误：C 语言中没有 true/false 关键字（除非包含 stdbool.h）
if (a = true) {  // true 在 C 中通常是 1
    // 这实际上是赋值，不是比较
}

// 正确
#include <stdbool.h>
if (a == true) {
    // 比较
}

// 更好的做法：直接使用条件
if (a) {
    // a 非零时为真
}
```

## `switch...case` 语句

### 基本语法

```c
switch (表达式) {
    case 常量1:
        // 表达式等于常量1时执行
        break;
    case 常量2:
        // 表达式等于常量2时执行
        break;
    // ...
    default:
        // 表达式不匹配任何 case 时执行
        break;
}
```

### 示例：菜单选择

```c
#include <stdio.h>

int main(void) {
    int choice;
    printf("请选择操作：\n");
    printf("1. 新建\n");
    printf("2. 打开\n");
    printf("3. 保存\n");
    printf("4. 退出\n");
    printf("请输入选项：");
    scanf("%d", &choice);

    switch (choice) {
        case 1:
            printf("新建文件\n");
            break;
        case 2:
            printf("打开文件\n");
            break;
        case 3:
            printf("保存文件\n");
            break;
        case 4:
            printf("退出程序\n");
            break;
        default:
            printf("无效选项\n");
            break;
    }

    return 0;
}
```

### 穿透效果（Fall-through）

`switch` 语句中，如果 `case` 分支没有 `break`，程序会继续执行下一个 `case` 分支的代码，这就是穿透效果。

#### 穿透的用途

```c
switch (day) {
    case 1:
    case 3:
    case 5:
        printf("工作日\n");
        break;
    case 2:
    case 4:
        printf("工作日\n");
        break;
    case 6:
    case 7:
        printf("周末\n");
        break;
    default:
        printf("无效日期\n");
        break;
}
```

#### 穿透的陷阱

```c
int x = 1;
switch (x) {
    case 1:
        printf("one\n");  // 会执行
    case 2:
        printf("two\n");  // 也会执行！因为 case 1 没有 break
        break;
    case 3:
        printf("three\n");
        break;
}
// 输出：one\ntwo\n
```

### `switch` 的注意事项

**`switch` 的表达式类型有限制**：`switch` 后的表达式只能是**整型或字符型**（包括 `char`、`int`、`enum` 等），不能是浮点数或字符串。

```c
double x = 3.5;
switch (x) { ... }   // 错误！switch 表达式不能是浮点数

char ch = 'A';
switch (ch) { ... }  // 正确：字符型可以（本质是 ASCII 码整数）
```

1. **`case` 后的常量表达式必须是整型或字符型**
   ```c
   switch (x) {
       case 1:     // 正确
       case 'A':   // 正确（字符的 ASCII 码值）
       // case 1.5:  // 错误！浮点数不能用作 case
   }
   ```

2. **`case` 常量值不能重复**
   ```c
   switch (x) {
       case 1: break;
       case 1: break;  // 错误！重复的 case 常量
   }
   ```

3. **`default` 分支可以放在任意位置**
   ```c
   switch (x) {
       case 1: break;
       default: break;  // 可以放在中间
       case 2: break;
   }
   ```

4. **`switch` 表达式可以是任意整型或枚举类型**
   ```c
   enum Color { RED, GREEN, BLUE };
   enum Color c = GREEN;

   switch (c) {
       case RED: printf("红色\n"); break;
       case GREEN: printf("绿色\n"); break;
       case BLUE: printf("蓝色\n"); break;
   }
   ```

## `if` 与 `switch` 的对比

| 特性 | `if...else if...else` | `switch...case` |
|------|----------------------|-----------------|
| 适用条件 | 范围判断、浮点数比较 | 等值判断（整型/字符型） |
| 表达式类型 | 任意类型 | 整型或枚举型 |
| 效率 | 顺序判断 | 跳转表（编译器优化） |
| 穿透效果 | 无 | 有（需用 `break` 控制） |
| 代码可读性 | 适合少量分支 | 适合大量等值分支 |

### 选择建议

- **少量分支**：使用 `if...else if...else`
- **大量等值判断**：使用 `switch...case`
- **范围判断**：只能使用 `if...else if...else`
- **浮点数比较**：只能使用 `if`（`switch` 不支持浮点数）

## 嵌套选择结构

```c
#include <stdio.h>

int main(void) {
    int score;
    char grade;

    printf("请输入成绩：");
    scanf("%d", &score);

    if (score >= 0 && score <= 100) {
        if (score >= 90) {
            grade = 'A';
        } else if (score >= 80) {
            grade = 'B';
        } else if (score >= 70) {
            grade = 'C';
        } else if (score >= 60) {
            grade = 'D';
        } else {
            grade = 'F';
        }
        printf("成绩等级：%c\n", grade);
    } else {
        printf("成绩无效！\n");
    }

    return 0;
}
```

## 条件编译与选择结构

条件编译指令也可以实现类似选择结构的效果（编译时决定）：

```c
#define DEBUG 1

#if DEBUG
    printf("Debug mode\n");
#else
    printf("Release mode\n");
#endif
```

## 常见编程练习

### 判断闰年

闰年的判断规则：能被 4 整除但不能被 100 整除，**或者**能被 400 整除。用逻辑表达式表示：

```
(year % 4 == 0 && year % 100 != 0) || year % 400 == 0
```

```c
#include <stdio.h>

int main(void) {
    int year;
    printf("请输入年份：");
    scanf("%d", &year);

    if ((year % 4 == 0 && year % 100 != 0) || year % 400 == 0) {
        printf("%d 年是闰年\n", year);
    } else {
        printf("%d 年不是闰年\n", year);
    }

    return 0;
}
```

> 例如：2000 是闰年（能被 400 整除），1900 不是闰年（能被 100 整除但不能被 400 整除），2004 是闰年，2023 不是闰年。

### 判断素数

```c
int is_prime(int n) {
    if (n <= 1) return 0;
    if (n <= 3) return 1;
    if (n % 2 == 0 || n % 3 == 0) return 0;

    for (int i = 5; i * i <= n; i += 6) {
        if (n % i == 0 || n % (i + 2) == 0) {
            return 0;
        }
    }
    return 1;
}
```

### 简单计算器

```c
#include <stdio.h>

int main(void) {
    double a, b;
    char op;

    printf("请输入表达式 (如 3 + 4)：");
    scanf("%lf %c %lf", &a, &op, &b);

    switch (op) {
        case '+':
            printf("%.2f + %.2f = %.2f\n", a, b, a + b);
            break;
        case '-':
            printf("%.2f - %.2f = %.2f\n", a, b, a - b);
            break;
        case '*':
            printf("%.2f * %.2f = %.2f\n", a, b, a * b);
            break;
        case '/':
            if (b != 0) {
                printf("%.2f / %.2f = %.2f\n", a, b, a / b);
            } else {
                printf("除数不能为零！\n");
            }
            break;
        default:
            printf("无效运算符\n");
            break;
    }

    return 0;
}
```
