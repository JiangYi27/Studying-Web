# 跳转语句

C 语言提供了多种跳转语句，用于改变程序的执行流程。

## `break` 语句

### 在循环中使用

`break` 用于立即退出当前循环，不再执行循环的剩余部分。

```c
#include <stdio.h>

int main(void) {
    for (int i = 1; i <= 10; i++) {
        if (i == 5) {
            break;  // 当 i 等于 5 时退出循环
        }
        printf("%d ", i);
    }
    // 输出：1 2 3 4

    return 0;
}
```

### 在 `switch` 中使用

`break` 用于终止 `switch` 语句，防止穿透到下一个 `case`。

```c
int choice = 2;
switch (choice) {
    case 1:
        printf("选项 1\n");
        break;
    case 2:
        printf("选项 2\n");
        break;
    default:
        printf("其他选项\n");
        break;
}
```

### 在嵌套循环中使用

`break` 只退出它所在的最内层循环。

```c
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 3; j++) {
        if (j == 2) {
            break;  // 只退出内层循环
        }
        printf("i=%d, j=%d\n", i, j);
    }
}
// 输出：
// i=0, j=0
// i=0, j=1
// i=1, j=0
// i=1, j=1
// i=2, j=0
// i=2, j=1
```

## `continue` 语句

### 在循环中使用

`continue` 用于跳过当前循环的剩余部分，直接进入下一次循环的条件判断。

```c
#include <stdio.h>

int main(void) {
    for (int i = 1; i <= 10; i++) {
        if (i % 2 == 0) {
            continue;  // 跳过偶数
        }
        printf("%d ", i);
    }
    // 输出：1 3 5 7 9

    return 0;
}
```

### 在嵌套循环中使用

`continue` 只影响它所在的最内层循环。

```c
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 3; j++) {
        if (j == 1) {
            continue;  // 跳过 j=1 的情况
        }
        printf("i=%d, j=%d\n", i, j);
    }
}
// 输出：
// i=0, j=0
// i=0, j=2
// i=1, j=0
// i=1, j=2
// i=2, j=0
// i=2, j=2
```

## `goto` 语句

### 基本语法

```c
goto 标签;
// ...
标签:
    // 跳转到的位置
```

### 示例

```c
#include <stdio.h>

int main(void) {
    int x = 1;

    start:
    printf("x = %d\n", x);
    x++;
    if (x <= 5) {
        goto start;
    }

    return 0;
}
```

### `goto` 的争议

`goto` 是 C 语言中最具争议的语句之一。

#### 反对使用 `goto` 的理由

1. **破坏结构化编程**：`goto` 使程序流程变得难以追踪
2. **降低可读性**：跳转会使代码逻辑混乱
3. **难以维护**：修改代码时容易引入错误
4. **"面条代码"**：过度使用 `goto` 会产生难以理解的代码

#### 支持使用 `goto` 的场景

1. **错误处理和资源清理**：在 C 语言中，`goto` 是实现 RAII 风格的常见方式
2. **跳出多层嵌套循环**：C 语言没有标签化的 `break`，`goto` 是唯一方式
3. **内核开发**：Linux 内核中广泛使用 `goto` 进行错误处理

### `goto` 的最佳实践

```c
// 推荐：用于错误处理和资源清理
int function(void) {
    FILE *fp = NULL;
    int *buffer = NULL;
    int result = -1;

    fp = fopen("file.txt", "r");
    if (fp == NULL) {
        goto cleanup;
    }

    buffer = (int *)malloc(100 * sizeof(int));
    if (buffer == NULL) {
        goto cleanup;
    }

    // 处理文件...
    result = 0;

cleanup:
    if (fp != NULL) {
        fclose(fp);
    }
    if (buffer != NULL) {
        free(buffer);
    }
    return result;
}
```

## `return` 语句

### 基本用法

`return` 语句用于从函数中返回，并可以返回一个值。

```c
// 返回整数值
int add(int a, int b) {
    return a + b;
}

// 返回 void（无返回值）
void print_hello(void) {
    printf("Hello\n");
    return;  // 可以省略
}
```

### 在循环中使用 `return`

`return` 可以立即退出整个函数，包括所有循环。

```c
int find(int arr[], int size, int target) {
    for (int i = 0; i < size; i++) {
        if (arr[i] == target) {
            return i;  // 找到目标，立即返回索引
        }
    }
    return -1;  // 未找到
}
```

### `return` 与 `break`/`continue` 的区别

| 语句 | 作用范围 |
|------|----------|
| `break` | 退出当前循环或 `switch` |
| `continue` | 跳过当前循环的剩余部分 |
| `return` | 退出整个函数 |

## `return` 与 `exit()` 的区别

`return` 只能结束当前所在的**函数**，而标准库函数 `exit()`（在 `<stdlib.h>` 中声明）可以**终止整个程序**，无论它在哪个函数中调用。

```c
#include <stdio.h>
#include <stdlib.h>

void check(int n) {
    if (n < 0) {
        printf("输入无效，程序终止\n");
        exit(1);  // 立即终止整个程序，并返回状态码 1
    }
    printf("n = %d\n", n);
}

int main(void) {
    check(-5);
    // 这里的代码不会执行，因为程序已经在 check 中退出
    printf("这行不会输出\n");
    return 0;
}
```

| 对比项 | `return` | `exit()` |
|--------|----------|----------|
| 作用范围 | 结束当前函数，返回调用处 | 结束整个进程 |
| 返回值 | 返回给调用者 | 返回状态码给操作系统 |
| 头文件 | 无需头文件 | `<stdlib.h>` |
| 0 的含义 | 函数正常返回 | 程序正常退出（通常 0 表示成功） |

> **注意**：`exit(0)` 表示正常退出，非 0 状态码（如 `exit(1)`）一般表示出错。`main` 函数中的 `return 0;` 等价于 `exit(0);`。

## `abort()`

`abort()`（在 `<stdlib.h>` 中声明）用于**异常终止**程序，不执行任何清理工作，也不刷新缓冲区：

```c
#include <stdio.h>
#include <stdlib.h>

int main(void) {
    printf("开始...\n");
    // 检测到严重错误
    abort();   // 程序立即异常终止
    printf("这行不会输出\n");
    return 0;
}
```

| 函数 | 行为 |
|------|------|
| `exit(0)` | 正常退出，刷新缓冲区，状态码 0 |
| `exit(1)` | 正常退出，刷新缓冲区，状态码非 0（表示出错） |
| `abort()` | 异常终止，不清理资源，通常返回非 0 状态码 |

## 跳转语句对比总结

| 语句 | 作用 | 适用场景 |
|------|------|----------|
| `break` | 退出当前循环或 `switch` | 提前终止循环、防止 `switch` 穿透 |
| `continue` | 跳过当前迭代，进入下一次循环 | 跳过特定条件的处理 |
| `goto` | 跳转到同一函数内的标签 | 错误处理、跳出多层循环（慎用） |
| `return` | 退出函数并返回值 | 提前返回函数结果 |

## 结构化编程原则

### 三种基本结构

1. **顺序结构**：按代码书写顺序依次执行
2. **选择结构**：根据条件选择执行不同的分支
3. **循环结构**：重复执行某段代码

### 结构化编程的好处

- **提高可读性**：代码逻辑清晰易懂
- **提高可维护性**：易于修改和扩展
- **减少错误**：避免无序跳转导致的逻辑错误
- **便于调试**：执行路径可预测

### 避免 `goto` 的替代方案

#### 替代方案 1：使用标志变量

```c
// 不推荐使用 goto
int found = 0;
for (int i = 0; i < n && !found; i++) {
    for (int j = 0; j < m && !found; j++) {
        if (arr[i][j] == target) {
            found = 1;
        }
    }
}
```

#### 替代方案 2：使用函数封装

```c
int find_in_matrix(int arr[][COL], int rows, int cols, int target) {
    for (int i = 0; i < rows; i++) {
        for (int j = 0; j < cols; j++) {
            if (arr[i][j] == target) {
                return i * cols + j;  // 返回一维索引
            }
        }
    }
    return -1;  // 未找到
}
```
