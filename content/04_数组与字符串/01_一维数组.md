# 一维数组

## 定义与声明

### 基本语法

```c
类型名 数组名[数组长度];
```

```c
int arr[10];           // 声明一个包含 10 个整数的数组
float scores[50];      // 声明一个包含 50 个浮点数的数组
char name[100];        // 声明一个包含 100 个字符的数组
```

- **类型名**：数组元素的类型，如 `int`、`float`、`char`
- **数组名**：标识符，代表数组首元素的地址（即数组的起始地址）
- **数组长度**：整型常量表达式，表示元素的个数（注意不是字节数）

> **注意**：数组一旦定义，其元素个数在编译时就已经确定，不能动态增减（动态内存分配见后文）。数组下标从 0 开始，最大有效下标是"长度 - 1"。

### 数组长度

数组长度必须是**常量表达式**，不能是变量（C99 之前）。

```c
#define N 10
int arr[N];            // 正确：使用宏常量

const int n = 10;
int arr2[n];           // C99 支持变长数组（VLA），但不是所有编译器都支持

int size = 10;
int arr3[size];        // C99 VLA，部分编译器不支持
```

## 初始化

### 完全初始化

```c
int arr[5] = {1, 2, 3, 4, 5};
```

### 部分初始化

未初始化的元素自动初始化为 0。

```c
int arr[5] = {1, 2};  // arr = {1, 2, 0, 0, 0}
```

### 全部初始化为 0

```c
int arr[5] = {0};     // arr = {0, 0, 0, 0, 0}
```

### 自动推断长度

```c
int arr[] = {1, 2, 3, 4, 5};  // 数组长度为 5
```

### 指定位置初始化（C99）

```c
int arr[5] = {[0] = 1, [3] = 10};  // arr = {1, 0, 0, 10, 0}
```

## 访问数组元素

### 通过下标访问

数组下标从 **0** 开始。

```c
int arr[5] = {10, 20, 30, 40, 50};

printf("%d\n", arr[0]);  // 输出 10
printf("%d\n", arr[1]);  // 输出 20
printf("%d\n", arr[4]);  // 输出 50
```

### 数组越界

访问超出数组范围的下标会导致未定义行为。

```c
int arr[5] = {1, 2, 3, 4, 5};

// 错误：arr[5] 超出范围，有效下标是 0-4
printf("%d\n", arr[5]);  // 未定义行为！
```

## 内存布局

数组元素在内存中**连续存储**，每个元素占用相同大小的内存。

```c
int arr[5] = {10, 20, 30, 40, 50};
```

内存布局（假设 `int` 占 4 字节，起始地址为 1000）：

```
地址    内容
1000    10
1004    20
1008    30
1012    40
1016    50
```

### 数组名与地址

数组名代表数组首元素的地址。

```c
int arr[5] = {10, 20, 30, 40, 50};

printf("%p\n", arr);        // 数组首地址
printf("%p\n", &arr[0]);    // 首元素地址，与 arr 相同
printf("%p\n", &arr[1]);    // 第二个元素地址
```

### `sizeof` 运算符与数组

```c
int arr[5];

printf("sizeof(arr) = %zu\n", sizeof(arr));      // 整个数组的大小（20 字节）
printf("sizeof(arr[0]) = %zu\n", sizeof(arr[0])); // 单个元素的大小（4 字节）
printf("数组长度 = %zu\n", sizeof(arr) / sizeof(arr[0]));  // 5
```

## 遍历数组

### 使用下标遍历

```c
int arr[5] = {1, 2, 3, 4, 5};

for (int i = 0; i < 5; i++) {
    printf("arr[%d] = %d\n", i, arr[i]);
}
```

### 使用指针遍历

```c
int arr[5] = {1, 2, 3, 4, 5};

for (int *p = arr; p < arr + 5; p++) {
    printf("*p = %d\n", *p);
}
```

## 数组作为函数参数

### 数组名作为指针传递

数组作为函数参数时，会退化为指针，函数无法知道数组的实际长度。

```c
#include <stdio.h>

void print_array(int arr[], int size) {
    for (int i = 0; i < size; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");
}

int main(void) {
    int arr[] = {1, 2, 3, 4, 5};
    int size = sizeof(arr) / sizeof(arr[0]);

    print_array(arr, size);  // 数组名 arr 退化为指针

    return 0;
}
```

### 传递数组长度

```c
void process_array(int arr[], int size) {
    // 必须传入数组长度
    for (int i = 0; i < size; i++) {
        arr[i] *= 2;
    }
}
```

### 使用指针参数

```c
void process_array(int *arr, int size) {
    for (int i = 0; i < size; i++) {
        arr[i] *= 2;
    }
}
```

## 数组的常见操作

### 查找元素

```c
int find(int arr[], int size, int target) {
    for (int i = 0; i < size; i++) {
        if (arr[i] == target) {
            return i;  // 返回索引
        }
    }
    return -1;  // 未找到
}
```

### 数组反转

```c
void reverse(int arr[], int size) {
    for (int i = 0; i < size / 2; i++) {
        int temp = arr[i];
        arr[i] = arr[size - 1 - i];
        arr[size - 1 - i] = temp;
    }
}
```

### 数组排序（冒泡排序）

```c
void bubble_sort(int arr[], int size) {
    for (int i = 0; i < size - 1; i++) {
        for (int j = 0; j < size - 1 - i; j++) {
            if (arr[j] > arr[j + 1]) {
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
            }
        }
    }
}
```

## 动态数组（使用 malloc）

```c
#include <stdio.h>
#include <stdlib.h>

int main(void) {
    int n;
    printf("请输入数组长度：");
    scanf("%d", &n);

    // 在堆上动态分配内存
    int *arr = (int *)malloc(n * sizeof(int));
    if (arr == NULL) {
        printf("内存分配失败\n");
        return 1;
    }

    // 使用数组
    for (int i = 0; i < n; i++) {
        arr[i] = i * 10;
    }

    // 释放内存
    free(arr);
    arr = NULL;

    return 0;
}
```

## 二维数组的引用（一维数组的扩展）

```c
// 二维数组可以看作"数组的数组"
int matrix[3][4];  // 3 行 4 列的二维数组

// 访问元素
matrix[0][0] = 1;
matrix[1][2] = 5;
```

## 数组常见错误

1. **数组越界访问**：访问超出数组范围的下标
2. **未初始化就使用**：未初始化的数组元素值不确定
3. **数组长度不足**：存储的数据超出数组容量
4. **忘记数组名退化为指针**：在函数中无法通过 `sizeof` 获取数组长度
