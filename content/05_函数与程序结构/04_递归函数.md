# 递归函数

## 递归的基本概念

递归是指函数在其定义或实现中调用自身的编程技巧。递归函数通常用于将复杂问题分解为更小的、相同类型的子问题。

## 递归的三要素

### 1. 终止条件（基准情况）

递归必须有一个明确的终止条件，否则会无限递归导致栈溢出。

```c
// 正确的递归：有终止条件
int factorial(int n) {
    if (n <= 1) {
        return 1;  // 终止条件
    }
    return n * factorial(n - 1);  // 递归调用
}
```

### 2. 递推公式（递归步骤）

递归步骤将问题分解为更小的子问题。

```c
// 递推公式：n! = n * (n-1)!
int factorial(int n) {
    if (n <= 1) {
        return 1;  // 终止条件
    }
    return n * factorial(n - 1);  // 递推公式
}
```

### 3. 递归调用

函数调用自身来解决更小的子问题。

## 递归的两个要素

递归的实现必须同时满足两个要素：

1. **边界条件（基准情况）**：递归终止的条件，保证递归能停下来。
2. **递归式（递推公式）**：将问题规模逐步缩小的规律。

以阶乘为例：`n! = n * (n-1)!` 是递归式，`n <= 1 时 n! = 1` 是边界条件。缺少任何一个要素都会导致错误（无限递归或算不出结果）。

```c
int factorial(int n) {
    if (n <= 1) {
        return 1;   // 要素 1：边界条件
    }
    return n * factorial(n - 1);  // 要素 2：递归式（规模减一）
}
```

## 递归示例

### 阶乘

```c
#include <stdio.h>

int factorial(int n) {
    if (n <= 1) {
        return 1;
    }
    return n * factorial(n - 1);
}

int main(void) {
    printf("5! = %d\n", factorial(5));  // 输出 120
    return 0;
}
```

### 递归调用过程图解

以 `factorial(4)` 为例，调用过程分为"递推"（不断压栈）和"回归"（逐层返回）两个阶段：

```
递推阶段（一路压栈）：
factorial(4) = 4 * factorial(3)
            = 4 * (3 * factorial(2))
            = 4 * (3 * (2 * factorial(1)))
            = 4 * (3 * (2 * 1))          ← 遇到边界条件 factorial(1)=1，停止递推

回归阶段（逐层返回）：
factorial(1) = 1
factorial(2) = 2 * 1 = 2
factorial(3) = 3 * 2 = 6
factorial(4) = 4 * 6 = 24
```

每次递归调用都会在栈上开辟一块新的空间（存放本次调用的参数、局部变量和返回地址），递归深度越大，栈开销越大。

### 逆序输出字符串（谭浩强经典例题）

用递归实现"逆序打印一个字符串"：每次取字符串首字符放到最后打印，等价于先递归处理除首字符外的子串，再输出首字符。

```c
#include <stdio.h>

// 递归实现：逆序输出字符串
void reverse_print(char *str) {
    if (*str == '\0') {
        return;              // 边界条件：遇到字符串结束符
    }
    reverse_print(str + 1);  // 递归式：先处理去掉首字符的子串
    putchar(*str);           // 回归阶段才输出首字符
}

int main(void) {
    reverse_print("Hello");
    putchar('\n');  // 输出 olleH
    return 0;
}
```

> **注意**：递归函数中"递推阶段"和"回归阶段"的代码执行时机不同。上例把输出放在递归调用**之后**，所以是逆序；如果放在递归调用**之前**，则是顺序输出。

### 斐波那契数列

```c
#include <stdio.h>

int fibonacci(int n) {
    if (n <= 0) {
        return 0;
    }
    if (n == 1) {
        return 1;
    }
    return fibonacci(n - 1) + fibonacci(n - 2);
}

int main(void) {
    for (int i = 0; i < 10; i++) {
        printf("fib(%d) = %d\n", i, fibonacci(i));
    }
    return 0;
}
```

### 汉诺塔问题

```c
#include <stdio.h>

void hanoi(int n, char from, char to, char aux) {
    if (n == 1) {
        printf("将盘子 1 从 %c 移动到 %c\n", from, to);
        return;
    }
    hanoi(n - 1, from, aux, to);    // 将 n-1 个盘子从 from 移到 aux
    printf("将盘子 %d 从 %c 移动到 %c\n", n, from, to);
    hanoi(n - 1, aux, to, from);    // 将 n-1 个盘子从 aux 移到 to
}

int main(void) {
    hanoi(3, 'A', 'C', 'B');
    return 0;
}
```

### 递归遍历数组

```c
#include <stdio.h>

void print_array(int arr[], int size, int index) {
    if (index >= size) {
        return;  // 终止条件
    }
    printf("%d ", arr[index]);
    print_array(arr, size, index + 1);  // 递归调用
}

int main(void) {
    int arr[] = {1, 2, 3, 4, 5};
    print_array(arr, 5, 0);
    printf("\n");
    return 0;
}
```

## 递归与迭代的对比

### 阶乘：递归 vs 迭代

#### 递归实现

```c
int factorial_recursive(int n) {
    if (n <= 1) {
        return 1;
    }
    return n * factorial_recursive(n - 1);
}
```

#### 迭代实现

```c
int factorial_iterative(int n) {
    int result = 1;
    for (int i = 2; i <= n; i++) {
        result *= i;
    }
    return result;
}
```

### 对比分析

| 特性 | 递归 | 迭代 |
|------|------|------|
| 代码简洁性 | 通常更简洁 | 通常更冗长 |
| 可读性 | 更接近数学定义 | 更直观 |
| 性能 | 函数调用开销大 | 无额外开销 |
| 内存使用 | 使用栈空间，可能栈溢出 | 使用常数额外空间 |
| 调试难度 | 较难跟踪调用栈 | 较易调试 |
| 适用场景 | 问题天然递归时 | 循环次数已知时 |

### 斐波那契数列：递归 vs 迭代

#### 递归实现（低效）

```c
int fib_recursive(int n) {
    if (n <= 1) {
        return n;
    }
    return fib_recursive(n - 1) + fib_recursive(n - 2);
}
// 时间复杂度：O(2^n)，存在大量重复计算
```

#### 迭代实现（高效）

```c
int fib_iterative(int n) {
    if (n <= 1) {
        return n;
    }
    int a = 0, b = 1;
    for (int i = 2; i <= n; i++) {
        int temp = a + b;
        a = b;
        b = temp;
    }
    return b;
}
// 时间复杂度：O(n)，无重复计算
```

#### 记忆化递归（高效）

```c
#include <string.h>

int memo[1000];

int fib_memo(int n) {
    if (n <= 1) {
        return n;
    }
    if (memo[n] != -1) {
        return memo[n];  // 已计算过，直接返回
    }
    memo[n] = fib_memo(n - 1) + fib_memo(n - 2);
    return memo[n];
}

int main(void) {
    memset(memo, -1, sizeof(memo));
    printf("fib(50) = %d\n", fib_memo(50));
    return 0;
}
```

## 递归的常见错误

### 1. 缺少终止条件

```c
// 错误：无限递归
int bad_func(int n) {
    return n + bad_func(n - 1);  // 没有终止条件！
}
```

### 2. 终止条件永远无法满足

```c
// 错误：n 永远大于 0
int bad_func(int n) {
    if (n == 0) {  // 但 n 始终大于 0
        return 1;
    }
    return bad_func(n + 1);  // n 越来越大，永远不会等于 0
}
```

### 3. 栈溢出

递归深度过大时会导致栈溢出。

```c
// 危险：递归深度过大
void deep_recursion(int n) {
    int arr[1000];  // 每次递归都分配 1000 个 int
    if (n == 0) {
        return;
    }
    deep_recursion(n - 1);
}

int main(void) {
    deep_recursion(10000);  // 可能导致栈溢出
    return 0;
}
```

## 递归的最佳实践

1. **始终确保有终止条件**
2. **确保每次递归调用都向终止条件靠近**
3. **避免重复计算**（使用记忆化）
4. **注意栈空间限制**（递归深度不宜过大）
5. **优先考虑迭代**，除非递归更自然
6. **使用尾递归优化**（如果编译器支持）

## 递归的内存开销

每次递归调用都会在**栈区**分配一块新的活动记录（栈帧），存放本次调用的形参、局部变量和返回地址，递归结束后栈帧再依次出栈。

```c
// 递推阶段：每调用一次就压栈一次，栈深度不断增加
// 回归阶段：每返回一次就弹栈一次，栈深度逐渐减少
void f(int n) {
    int local;          // 每个栈帧都有一份独立的 local
    if (n > 0) {
        f(n - 1);       // 栈深度增加一层
    }
    // 返回时栈深度减少一层
}
```

- 递归深度越大，栈占用越多，深度过大容易**栈溢出**（stack overflow）。
- 相比迭代（只用固定的额外空间），递归的空间复杂度通常更高。
- 对于已知深度很大或栈空间有限的场景，优先考虑用迭代改写。

## 尾递归

尾递归是指递归调用是函数的最后一步操作。某些编译器可以优化尾递归，避免栈空间增长。

```c
// 非尾递归
int factorial(int n) {
    if (n <= 1) {
        return 1;
    }
    return n * factorial(n - 1);  // 递归调用后还要乘以 n
}

// 尾递归
int factorial_tail(int n, int acc) {
    if (n <= 1) {
        return acc;
    }
    return factorial_tail(n - 1, n * acc);  // 递归调用是最后一步
}

int factorial(int n) {
    return factorial_tail(n, 1);
}
```

## 递归的应用场景

1. **树形结构遍历**：二叉树的前序、中序、后序遍历
2. **分治算法**：归并排序、快速排序
3. **回溯算法**：八皇后、数独求解
4. **数学问题**：阶乘、斐波那契数列、汉诺塔
5. **文件系统遍历**：递归遍历目录树
