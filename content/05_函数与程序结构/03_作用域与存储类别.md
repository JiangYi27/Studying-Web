# 作用域与存储类别

## 局部变量

### 定义与特性

局部变量是在函数内部或代码块内部声明的变量。

```c
void func(void) {
    int localVar = 10;  // 局部变量
}
```

### 特性

1. **作用域**：仅在声明它的函数或代码块内可见
2. **生命周期**：进入作用域时创建，离开作用域时销毁
3. **存储位置**：栈区
4. **默认值**：未初始化的局部变量值不确定（垃圾值）

### 代码块作用域

在 `{}` 内部声明的变量只在该代码块内有效。

```c
#include <stdio.h>

int main(void) {
    int x = 10;

    {
        int x = 20;  // 新的 x，屏蔽了外部的 x
        printf("内部 x = %d\n", x);  // 输出 20
    }

    printf("外部 x = %d\n", x);  // 输出 10

    return 0;
}
```

## 全局变量

### 定义与特性

全局变量是在所有函数外部声明的变量。

```c
int globalVar = 100;  // 全局变量

void func(void) {
    printf("globalVar = %d\n", globalVar);  // 可以访问全局变量
}
```

### 特性

1. **作用域**：从声明位置到文件末尾
2. **生命周期**：程序启动时创建，程序结束时销毁
3. **存储位置**：数据区（全局/静态区）
4. **默认值**：未初始化的全局变量自动初始化为 0

### 全局变量的使用

```c
#include <stdio.h>

int global_count = 0;  // 全局变量

void increment(void) {
    global_count++;  // 在函数中修改全局变量
}

int main(void) {
    printf("count = %d\n", global_count);  // 输出 0
    increment();
    printf("count = %d\n", global_count);  // 输出 1
    return 0;
}
```

### 全局变量的缺点

1. **命名冲突**：不同文件中可能使用相同的全局变量名
2. **难以调试**：任何函数都可以修改全局变量
3. **耦合度高**：函数之间过度依赖全局变量
4. **线程不安全**：多线程环境下需要同步机制

## 存储类别

C 语言提供了四种存储类别关键字：`auto`、`static`、`register`、`extern`。

### `auto`（自动变量）

`auto` 是局部变量的默认存储类别，通常省略不写。

```c
void func(void) {
    auto int x = 10;  // 等价于 int x = 10;
}
```

#### 特性

- **作用域**：局部作用域
- **生命周期**：进入作用域时创建，离开作用域时销毁
- **存储位置**：栈区
- **初始化**：未初始化时值不确定

### `static`（静态变量）

`static` 有两种用途：静态局部变量和静态全局变量。

#### 静态局部变量

```c
void func(void) {
    static int count = 0;  // 静态局部变量
    count++;
    printf("count = %d\n", count);
}

int main(void) {
    func();  // 输出 1
    func();  // 输出 2
    func();  // 输出 3
    return 0;
}
```

##### 特性

- **作用域**：局部作用域（只在函数内可见）
- **生命周期**：程序整个运行期间都存在
- **存储位置**：数据区（全局/静态区）
- **初始化**：只在第一次执行时初始化，之后保留上次的值
- **默认值**：未初始化时自动初始化为 0

#### 静态全局变量

```c
static int internal_var = 42;  // 静态全局变量

void func1(void) {
    printf("internal_var = %d\n", internal_var);  // 可以访问
}

// 其他文件中无法访问 internal_var
```

##### 特性

- **作用域**：仅限于定义它的源文件
- **生命周期**：程序整个运行期间都存在
- **链接属性**：内部链接（其他文件无法访问）

### `register`（寄存器变量）

`register` 建议编译器将变量存储在 CPU 寄存器中，以加快访问速度。

```c
void func(void) {
    register int i;  // 建议将 i 存储在寄存器中
    for (i = 0; i < 1000000; i++) {
        // ...
    }
}
```

#### 特性

- **作用域**：局部作用域
- **生命周期**：进入作用域时创建，离开作用域时销毁
- **存储位置**：CPU 寄存器（如果可用）
- **限制**：不能对寄存器变量取地址（`&`）
- **现代编译器**：通常忽略 `register` 关键字，自行优化

### `extern`（外部声明）

`extern` 用于声明在其他文件中定义的全局变量或函数。

#### 声明外部变量

```c
// file1.c
int global_var = 100;  // 定义全局变量

// file2.c
extern int global_var;  // 声明外部变量（不分配内存）

void func(void) {
    printf("global_var = %d\n", global_var);  // 可以访问
}
```

#### 声明外部函数

```c
// file1.c
void helper(void) {
    printf("Helper function\n");
}

// file2.c
extern void helper(void);  // 声明外部函数

int main(void) {
    helper();  // 调用 file1.c 中定义的函数
    return 0;
}
```

#### 头文件中的 extern 声明

通常将 `extern` 声明放在头文件中：

```c
// globals.h
#ifndef GLOBALS_H
#define GLOBALS_H

extern int global_var;

#endif
```

```c
// file1.c
#include "globals.h"
int global_var = 100;  // 定义

// file2.c
#include "globals.h"
// 可以使用 global_var
```

## 四种存储类别对比

| 存储类别 | 关键字 | 作用域 | 生命周期 | 存储位置 | 默认初始化 |
|----------|--------|--------|----------|----------|-----------|
| 自动变量 | `auto` | 局部 | 进入/离开作用域 | 栈区 | 不确定 |
| 静态局部变量 | `static` | 局部 | 程序运行期间 | 数据区 | 0 |
| 静态全局变量 | `static` | 文件 | 程序运行期间 | 数据区 | 0 |
| 寄存器变量 | `register` | 局部 | 进入/离开作用域 | 寄存器 | 不确定 |
| 外部变量 | `extern` | 全局 | 程序运行期间 | 数据区 | 0 |

## 作用域规则总结

### 作用域层次

```
文件作用域（全局变量）
  └── 函数作用域（goto 标签）
      └── 代码块作用域（局部变量）
```

### 变量遮蔽

内部作用域的变量可以遮蔽外部作用域的同名变量。

```c
int x = 10;  // 全局变量

void func(void) {
    int x = 20;  // 局部变量，遮蔽全局变量
    printf("内部 x = %d\n", x);  // 输出 20
}

int main(void) {
    printf("外部 x = %d\n", x);  // 输出 10
    func();
    return 0;
}
```

## 静态函数

使用 `static` 修饰的函数只能在定义它的源文件中访问。

```c
// file1.c
static void helper(void) {
    // 只能在 file1.c 中访问
}

void public_func(void) {
    helper();  // 正确：同一文件内可访问
}
```

## 内部函数与外部函数

### 内部函数（静态函数）

用 `static` 修饰的函数称为内部函数，只在本源文件中有效，其他文件即使声明也无法调用。好处是：不同文件中的同名内部函数互不干扰。

```c
// file1.c
static int square(int x) {   // 内部函数
    return x * x;
}

// file2.c 中即使写 extern int square(int x); 也无法调用
```

### 外部函数

默认情况下（不加 `static`），函数都是外部函数，可以被其他源文件调用。谭浩强教材中"函数是全局的"正是指这一点。

```c
// file1.c
int add(int a, int b) {      // 外部函数（默认）
    return a + b;
}

// file2.c
extern int add(int a, int b);  // 声明后即可调用
int main(void) {
    printf("%d\n", add(2, 3));
    return 0;
}
```

### 内部函数 vs 外部函数

| 对比项 | 内部函数（static） | 外部函数（默认） |
|--------|-------------------|-----------------|
| 关键字 | `static` | 无（或 `extern`） |
| 作用域 | 仅本源文件 | 整个程序 |
| 链接属性 | 内部链接 | 外部链接 |
| 同名冲突 | 不同文件可同名 | 全程序只能有一个定义 |

## 链接属性

| 链接属性 | 说明 | 实现方式 |
|----------|------|----------|
| 外部链接 | 其他文件可访问 | 默认（全局变量/函数） |
| 内部链接 | 仅当前文件可访问 | `static` 关键字 |
| 无链接 | 仅当前作用域可访问 | 局部变量 |

## 最佳实践

1. **优先使用局部变量**，减少全局变量的使用
2. **使用 `static` 限制作用域**，避免命名冲突
3. **使用 `const` 保护不修改的数据**
4. **通过头文件声明外部变量**，避免重复定义
5. **避免使用 `register`**，现代编译器会自动优化
