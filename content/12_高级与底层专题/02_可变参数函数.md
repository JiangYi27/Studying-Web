# 可变参数函数

## stdarg.h 概述

`stdarg.h` 是 C 语言标准库头文件，提供了处理可变参数列表的宏和类型。

## 基本类型和宏

### va_list

`va_list` 是用于遍历可变参数列表的类型。

```c
va_list args;
```

### va_start

初始化 `va_list`，使其指向第一个可变参数。

```c
void va_start(va_list ap, last_fixed_param);
```

- `ap`：`va_list` 变量
- `last_fixed_param`：最后一个固定参数的名称

### va_arg

获取下一个可变参数。

```c
type va_arg(va_list ap, type);
```

- `ap`：`va_list` 变量
- `type`：要获取的参数类型

### va_end

清理 `va_list`。

```c
void va_end(va_list ap);
```

## 可变参数函数示例

### 计算平均值

```c
#include <stdio.h>
#include <stdarg.h>

double average(int count, ...) {
    va_list args;
    va_start(args, count);

    double sum = 0;
    for (int i = 0; i < count; i++) {
        sum += va_arg(args, double);
    }

    va_end(args);
    return sum / count;
}

int main(void) {
    printf("平均值: %.2f\n", average(3, 1.0, 2.0, 3.0));  // 输出 2.00
    printf("平均值: %.2f\n", average(5, 10.0, 20.0, 30.0, 40.0, 50.0));  // 输出 30.00
    return 0;
}
```

### 求最大值

```c
#include <stdio.h>
#include <stdarg.h>

int max(int count, ...) {
    va_list args;
    va_start(args, count);

    int maximum = va_arg(args, int);
    for (int i = 1; i < count; i++) {
        int value = va_arg(args, int);
        if (value > maximum) {
            maximum = value;
        }
    }

    va_end(args);
    return maximum;
}

int main(void) {
    printf("最大值: %d\n", max(4, 3, 7, 1, 9));  // 输出 9
    return 0;
}
```

### 字符串拼接

```c
#include <stdio.h>
#include <stdarg.h>
#include <string.h>

char *concat(int count, ...) {
    va_list args;
    va_start(args, count);

    static char buffer[1024];
    buffer[0] = '\0';

    for (int i = 0; i < count; i++) {
        const char *str = va_arg(args, const char *);
        strcat(buffer, str);
    }

    va_end(args);
    return buffer;
}

int main(void) {
    printf("%s\n", concat(3, "Hello, ", "World", "!"));  // 输出 "Hello, World!"
    return 0;
}
```

## 模拟 printf

### 实现原理

`printf` 是一个可变参数函数，它根据格式字符串解析参数。

### 简化版实现

```c
#include <stdio.h>
#include <stdarg.h>

int my_printf(const char *format, ...) {
    va_list args;
    va_start(args, format);

    int count = 0;
    while (*format) {
        if (*format == '%') {
            format++;
            switch (*format) {
                case 'd': {
                    int i = va_arg(args, int);
                    count += printf("%d", i);
                    break;
                }
                case 'f': {
                    double d = va_arg(args, double);
                    count += printf("%f", d);
                    break;
                }
                case 's': {
                    char *s = va_arg(args, char *);
                    count += printf("%s", s);
                    break;
                }
                case 'c': {
                    int c = va_arg(args, int);
                    count += printf("%c", c);
                    break;
                }
                case '%': {
                    putchar('%');
                    count++;
                    break;
                }
                default:
                    putchar('%');
                    putchar(*format);
                    count += 2;
                    break;
            }
        } else {
            putchar(*format);
            count++;
        }
        format++;
    }

    va_end(args);
    return count;
}

int main(void) {
    my_printf("Name: %s, Age: %d, Score: %.2f\n", "Alice", 20, 95.5);
    return 0;
}
```

## 可变参数的限制

### 1. 无法自动确定参数类型和数量

```c
// 错误：无法自动判断参数类型
void bad_func(int count, ...) {
    va_list args;
    va_start(args, count);

    // 无法知道每个参数的类型
    // 必须通过格式字符串或其他方式指定
}
```

### 2. 参数提升规则

C 语言中，可变参数会经历默认参数提升：

- `char` 和 `short` 提升为 `int`
- `float` 提升为 `double`

```c
// 正确：使用 int 而不是 char
void func(int count, ...) {
    va_list args;
    va_start(args, count);
    char c = (char)va_arg(args, int);  // char 提升为 int，需要强制转换
    va_end(args);
}
```

### 3. 必须至少有一个固定参数

```c
// 错误：没有固定参数
// void bad_func(...) {  // 错误！
//     va_list args;
//     va_start(args);  // 错误！需要最后一个固定参数
// }
```

## 可变参数的最佳实践

1. **始终使用格式字符串或标记指定参数类型**
2. **检查参数数量是否足够**
3. **使用 `va_end` 清理 `va_list`**
4. **注意参数提升规则**
5. **使用 `va_copy` 复制 `va_list`（C99）**

### va_copy 的使用

```c
#include <stdarg.h>

void func(int count, ...) {
    va_list args1, args2;
    va_start(args1, count);
    va_copy(args2, args1);  // 复制 args1 到 args2

    // 使用 args1 和 args2 分别遍历
    // ...

    va_end(args1);
    va_end(args2);
}
```

## 实际应用

### 日志函数

```c
#include <stdio.h>
#include <stdarg.h>
#include <time.h>

void log_message(const char *level, const char *format, ...) {
    va_list args;
    va_start(args, format);

    time_t now = time(NULL);
    struct tm *local = localtime(&now);

    char time_buf[64];
    strftime(time_buf, sizeof(time_buf), "%Y-%m-%d %H:%M:%S", local);

    printf("[%s] [%s] ", time_buf, level);
    vprintf(format, args);  // 使用 vprintf 处理可变参数
    printf("\n");

    va_end(args);
}

int main(void) {
    log_message("INFO", "程序启动");
    log_message("ERROR", "文件 %s 未找到", "config.txt");
    return 0;
}
```

### vprintf 系列函数

`stdarg.h` 还提供了 `v` 前缀的函数，用于接受 `va_list` 而不是可变参数。

| 函数 | 说明 |
|------|------|
| `vprintf` | 格式化输出到 stdout |
| `vfprintf` | 格式化输出到文件流 |
| `vsprintf` | 格式化输出到字符串 |
| `vsnprintf` | 格式化输出到字符串（带长度限制） |

```c
#include <stdio.h>
#include <stdarg.h>

int my_vprintf(const char *format, va_list args) {
    return vprintf(format, args);
}
```

## 如何获知可变参数的个数与类型

可变参数列表**没有内建的长度或类型信息**，调用者与函数之间必须自行约定，常见的有两种方式：

### 方式一：用第一个固定参数传递个数

```c
// average 的第一个参数 count 告诉函数有多少个数字
double average(int count, ...);
average(3, 1.0, 2.0, 3.0);   // count = 3
```

### 方式二：用格式字符串或标记指定类型

```c
// printf 通过格式串中 %d、%f、%s 等来判断参数的个数与类型
printf("姓名 %s，年龄 %d，分数 %.2f\n", "小明", 20, 98.5);
```

一旦约定被破坏（比如数量或类型对不上），`va_arg` 读取到的就是垃圾值，甚至导致段错误。这与 printf 传入错误格式时产生未定义行为的原理一致。

## 可变参数的类型提升陷阱

调用可变参数函数时，实参会经历**默认实参提升（default argument promotions）**：

- `float` 一律提升为 `double`
- `char`、`unsigned char`、`short` 一律提升为 `int`（或 `unsigned int`）

因此函数内部**必须按提升后的类型读取**：

```c
#include <stdio.h>
#include <stdarg.h>

void show(int count, ...) {
    va_list args;
    va_start(args, count);

    // 即使传入 char，也要用 int 读取；传入 float，要用 double 读取
    int    a = va_arg(args, int);      // 传入 'A'（char 提升为 int）
    double b = va_arg(args, double);   // 传入 1.5f（float 提升为 double）

    printf("a = %d, b = %.1f\n", a, b);
    va_end(args);
}

int main(void) {
    show(2, 'A', 1.5f);   // 实参分别是被提升的 int 与 double
    return 0;
}
```

> **注意**：如果函数内用 `va_arg(args, float)` 读取，而实参已被提升为 `double`，得到的结果是不确定的——这是可变参数最常见的错误之一。

## 可变参数与 printf 格式串不匹配

```c
// 错误：%d 期望 int，但实参是 double
printf("%d", 3.14);   // 未定义行为

// 错误：%f 期望 double，但实参是 float 传递的 int
printf("%f", 42);     // 未定义行为

// 正确：格式串与实参类型一致
printf("%d", 42);
printf("%f", 3.14);
```

编译器**无法**检查可变参数的类型是否与格式串匹配（不过在 GCC/Clang 中用 `__attribute__((format(printf,...)))` 可以请编译器帮你检查，见下文）。因此调用 `printf` 等可变参数函数时，务必保证格式串与实参完全对应。

### 用编译器格式属性检查 printf 类函数

```c
#include <stdio.h>
#include <stdarg.h>

// 声明：第 2 个参数是格式串，可变参数从第 3 个开始
void my_log(const char *tag, const char *fmt, ...)
    __attribute__((format(printf, 2, 3)));

void my_log(const char *tag, const char *fmt, ...) {
    va_list args;
    va_start(args, fmt);
    printf("[%s] ", tag);
    vprintf(fmt, args);
    va_end(args);
}

int main(void) {
    my_log("INFO", "a=%d", 42);   // 编译期会检查 %d 与实参类型
    // my_log("INFO", "a=%d", "xx"); // 错误：gcc 会告警格式不匹配
    return 0;
}
```
