# 运算符与表达式

## 算术运算符

| 运算符 | 含义 | 示例 | 结果 |
|--------|------|------|------|
| `+` | 加法 | `5 + 3` | `8` |
| `-` | 减法 | `5 - 3` | `2` |
| `*` | 乘法 | `5 * 3` | `15` |
| `/` | 除法 | `10 / 3` | `3`（整数除法） |
| `%` | 取模（余数） | `10 % 3` | `1` |

### 整数除法与取模

```c
int a = 10 / 3;   // a = 3（整数除法，截断小数部分）
int b = 10 % 3;   // b = 1（取模运算）

double c = 10.0 / 3.0;  // c = 3.333...（浮点数除法）
```

### 自增与自减运算符

自增（`++`）和自减（`--`）运算符分为前置和后置两种形式。

#### 前置形式（先运算，后使用）

```c
int a = 5;
int b = ++a;  // a 先自增为 6，然后赋值给 b
// a = 6, b = 6
```

#### 后置形式（先使用，后运算）

```c
int a = 5;
int b = a++;  // a 的值先赋给 b，然后 a 自增
// a = 6, b = 5
```

#### 深入理解

```c
int a = 5;
int b = a++;  // b = 5, a = 6
int c = ++a;  // a = 7, c = 7
int d = a--;  // d = 7, a = 6
int e = --a;  // a = 5, e = 5
```

#### 常见陷阱

```c
// 错误示例：在同一个表达式中多次修改同一变量
int a = 5;
int b = a++ + ++a;  // 未定义行为，不要这样写！

// 正确做法：分开写
int a = 5;
a++;
int b = a;
++a;
```

## 关系运算符

| 运算符 | 含义 | 示例 | 结果 |
|--------|------|------|------|
| `==` | 等于 | `5 == 3` | `0`（假） |
| `!=` | 不等于 | `5 != 3` | `1`（真） |
| `>` | 大于 | `5 > 3` | `1`（真） |
| `<` | 小于 | `5 < 3` | `0`（假） |
| `>=` | 大于等于 | `5 >= 5` | `1`（真） |
| `<=` | 小于等于 | `3 <= 5` | `1`（真） |

> **注意**：关系运算的结果是 `int` 类型，`1` 表示真，`0` 表示假。

## 逻辑运算符

| 运算符 | 含义 | 示例 | 结果 |
|--------|------|------|------|
| `&&` | 逻辑与 | `1 && 0` | `0`（假） |
| `\|\|` | 逻辑或 | `1 \|\| 0` | `1`（真） |
| `!` | 逻辑非 | `!1` | `0`（假） |

### 短路求值

逻辑运算符具有短路特性：

```c
int a = 0, b = 5;

// 短路与：如果左边为假，右边不再计算
if (a != 0 && b / a > 1) {
    // a 为 0 时，b / a 不会被计算，避免了除零错误
}

// 短路或：如果左边为真，右边不再计算
if (a != 0 || b / a > 1) {
    // a 为 0 时，条件已经为真，b / a 不会被计算
}
```

## 位运算符

| 运算符 | 含义 | 示例 | 结果 |
|--------|------|------|------|
| `&` | 按位与 | `5 & 3` | `1` |
| `\|` | 按位或 | `5 \| 3` | `7` |
| `^` | 按位异或 | `5 ^ 3` | `6` |
| `~` | 按位取反 | `~5` | `-6` |
| `<<` | 左移 | `5 << 1` | `10` |
| `>>` | 右移 | `5 >> 1` | `2` |

### 位运算详解

```
5 的二进制：0000 0101
3 的二进制：0000 0011

按位与（&）：0000 0001 = 1
按位或（|）：0000 0111 = 7
按位异或（^）：0000 0110 = 6
左移（<<）：0000 1010 = 10（相当于乘以 2）
右移（>>）：0000 0010 = 2（相当于除以 2）
```

### 位运算的应用

```c
// 判断奇偶性
if (n & 1) {
    printf("奇数\n");
} else {
    printf("偶数\n");
}

// 交换两个变量（不使用临时变量）
a = a ^ b;
b = a ^ b;
a = a ^ b;

// 设置第 n 位
value |= (1 << n);

// 清除第 n 位
value &= ~(1 << n);

// 翻转第 n 位
value ^= (1 << n);

// 检查第 n 位是否为 1
if (value & (1 << n)) {
    // 第 n 位为 1
}
```

## 赋值运算符与复合赋值

### 基本赋值

```c
int a = 10;
a = 20;
```

### 复合赋值运算符

| 运算符 | 等价形式 | 示例 |
|--------|----------|------|
| `+=` | `a = a + b` | `a += 5` |
| `-=` | `a = a - b` | `a -= 3` |
| `*=` | `a = a * b` | `a *= 2` |
| `/=` | `a = a / b` | `a /= 4` |
| `%=` | `a = a % b` | `a %= 3` |
| `&=` | `a = a & b` | `a &= 0xFF` |
| `\|=` | `a = a \| b` | `a \|= 0x01` |
| `^=` | `a = a ^ b` | `a ^= 0xFF` |
| `<<=` | `a = a << b` | `a <<= 2` |
| `>>=` | `a = a >> b` | `a >>= 1` |

```c
int a = 10;
a += 5;   // 等价于 a = a + 5;  a = 15
a *= 2;   // 等价于 a = a * 2;  a = 30
a >>= 1;  // 等价于 a = a >> 1; a = 15
```

## 条件运算符（三元运算符）

```c
条件表达式 ? 表达式1 : 表达式2
```

如果条件为真，返回表达式1的值；否则返回表达式2的值。

```c
int a = 10, b = 20;
int max = (a > b) ? a : b;  // max = 20

int abs_value = (x >= 0) ? x : -x;

// 嵌套使用
int result = (a > b) ? ((a > c) ? a : c) : ((b > c) ? b : c);
```

## 逗号运算符

逗号运算符将多个表达式串联，从左到右依次计算，整个表达式的值是最后一个表达式的值。

```c
int a = (1, 2, 3);  // a = 3

for (int i = 0, j = 10; i < j; i++, j--) {
    printf("i = %d, j = %d\n", i, j);
}
```

> **注意**：逗号运算符的优先级是最低的，且低于赋值运算符。`a = 3, 4` 等价于 `(a = 3), 4`，整个表达式的值是 4，而 a 的值是 3；只有加括号的 `a = (3, 4)` 才会让 a 等于 4。

## 运算符优先级与结合性

### 优先级表（从高到低）

| 优先级 | 运算符 | 结合性 |
|--------|--------|--------|
| 1 | `()` `[]` `->` `.` 后缀自增/自减 | 左到右 |
| 2 | `++` `--` 前缀自增/自减 `+` `-` `!` `~` `(类型)` `*` `&` `sizeof` | 右到左 |
| 3 | `*` `/` `%` | 左到右 |
| 4 | `+` `-` | 左到右 |
| 5 | `<<` `>>` | 左到右 |
| 6 | `<` `<=` `>` `>=` | 左到右 |
| 7 | `==` `!=` | 左到右 |
| 8 | `&` | 左到右 |
| 9 | `^` | 左到右 |
| 10 | `\|` | 左到右 |
| 11 | `&&` | 左到右 |
| 12 | `\|\|` | 左到右 |
| 13 | `?:` | 右到左 |
| 14 | `=` `+=` `-=` 等复合赋值 | 右到左 |
| 15 | `,` | 左到右 |

### 优先级记忆技巧

1. **括号 `()` 优先级最高**，使用括号可以明确表达意图
2. **单目运算符**优先级高于双目运算符
3. **赋值运算符**优先级最低
4. **逗号运算符**优先级最低

### 常见陷阱

```c
// 错误：混淆优先级
int a = 1 + 2 * 3;  // a = 7，不是 9

// 正确：使用括号明确意图
int a = (1 + 2) * 3;  // a = 9

// 错误：赋值与比较混淆
if (a = 5) {  // 这是赋值，不是比较！
    // 永远为真
}

// 正确
if (a == 5) {  // 比较
    // ...
}

// 建议：Yoda 条件（常量在左边）
if (5 == a) {  // 如果误写为 =，编译器会报错
    // ...
}
```

## 表达式求值顺序

### 副作用与顺序点

C 语言中，表达式的求值顺序在某些情况下是未定义的。

```c
// 未定义行为：i 在同一表达式中被修改两次
int i = 5;
int result = i++ + ++i;  // 不要这样写！

// 未定义行为：i 在同一表达式中被修改并读取
int arr[] = {1, 2, 3};
int i = 0;
printf("%d %d\n", arr[i], i++);  // 不要这样写！
```

### 序列点

序列点是程序执行中的特定点，在序列点之前的所有副作用都已确定。

序列点包括：
- `;`（分号）
- `&&` 和 `\|\|`（短路求值）
- `?:`（条件运算符）
- 逗号运算符
- 函数调用（参数求值顺序未定义，但参数之间是序列点）

## sizeof 运算符

`sizeof` 是一个单目运算符，用于计算类型或变量在内存中占用的字节数。

```c
sizeof(int)      // 通常为 4
sizeof(double)   // 通常为 8
sizeof(char)     // 始终为 1
sizeof(int[10])  // 40（10 个 int 的大小）

char str[] = "Hello";
sizeof(str)      // 6（5 个字符 + 1 个 '\0'）
strlen(str)      // 5（不计算 '\0'）
```

> **注意**：`sizeof` 是运算符，不是函数，可以不加括号。

## 类型转换

### 隐式转换（自动类型提升）

```c
int a = 5;
double b = 2.0;
double result = a / b;  // a 自动转换为 double
```

### 算术转换

当不同类型的操作数进行运算时，较低优先级的类型会自动转换为较高优先级的类型：

```
char → short → int → unsigned int → long → unsigned long → float → double → long double
```

### 整型提升

在表达式中，所有 `char` 和 `short` 类型的操作数在进行运算前，都会先自动提升（promote）为 `int` 类型，这就是**整型提升**。

```c
char c1 = 'A';   // ASCII 码 65
char c2 = 'B';   // ASCII 码 66

// c1 + c2 运算前，c1、c2 先提升为 int，结果是 int
int sum = c1 + c2;   // sum = 65 + 66 = 131，类型是 int
```

> **注意**：在大多数 32 位平台上 `char`、`short` 比 `int` 短，提升不会损失信息；但在 16 位平台上，`unsigned short` 提升后可能变成 `unsigned int`。理解整型提升有助于避免一些隐蔽的类型错误。

### 强制类型转换

```c
int a = 7, b = 2;
double result = (double)a / b;  // 结果为 3.5

int x = (int)3.14;  // x = 3（截断）
```

## 表达式练习

```c
#include <stdio.h>

int main(void) {
    int a = 10, b = 3;

    printf("a + b = %d\n", a + b);
    printf("a - b = %d\n", a - b);
    printf("a * b = %d\n", a * b);
    printf("a / b = %d\n", a / b);
    printf("a %% b = %d\n", a % b);

    printf("a++ = %d, a = %d\n", a++, a);
    printf("++b = %d, b = %d\n", ++b, b);

    printf("a > b = %d\n", a > b);
    printf("a == b = %d\n", a == b);
    printf("a && b = %d\n", a && b);
    printf("a || b = %d\n", a || b);
    printf("!a = %d\n", !a);

    printf("a & b = %d\n", a & b);
    printf("a | b = %d\n", a | b);
    printf("a ^ b = %d\n", a ^ b);
    printf("a << 1 = %d\n", a << 1);
    printf("a >> 1 = %d\n", a >> 1);

    int max = (a > b) ? a : b;
    printf("max = %d\n", max);

    return 0;
}
```
