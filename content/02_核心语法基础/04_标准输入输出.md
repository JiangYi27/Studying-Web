# 标准输入输出

## `printf()` 格式化输出

### 基本用法

`printf` 是 C 语言的标准输出函数，用于将格式化的数据输出到标准输出（通常是终端）。

```c
#include <stdio.h>

int main(void) {
    printf("Hello, World!\n");
    return 0;
}
```

### 格式说明符

| 格式符 | 对应类型 | 示例 | 输出 |
|--------|----------|------|------|
| `%d` 或 `%i` | 十进制整数 | `printf("%d", 42)` | `42` |
| `%u` | 无符号整数 | `printf("%u", 42U)` | `42` |
| `%o` | 八进制整数 | `printf("%o", 10)` | `12` |
| `%x` 或 `%X` | 十六进制整数 | `printf("%x", 255)` | `ff` |
| `%f` | 浮点数（float/double） | `printf("%f", 3.14)` | `3.140000` |
| `%lf` | 双精度浮点数 | `printf("%lf", 3.14159)` | `3.141590` |
| `%e` | 科学计数法 | `printf("%e", 123456)` | `1.234560e+05` |
| `%g` | 自动选择 %f 或 %e | `printf("%g", 0.0001)` | `0.0001` |
| `%c` | 单个字符 | `printf("%c", 'A')` | `A` |
| `%s` | 字符串 | `printf("%s", "Hello")` | `Hello` |
| `%p` | 指针地址 | `printf("%p", &x)` | `0x7ffd...` |
| `%%` | 输出百分号本身 | `printf("%%")` | `%` |

### 格式控制选项

#### 宽度控制

```c
printf("%5d\n", 42);      // 右对齐，宽度为 5：输出 "   42"
printf("%-5d\n", 42);     // 左对齐，宽度为 5：输出 "42   "
printf("%5s\n", "Hi");    // 右对齐，宽度为 5：输出 "   Hi"
printf("%-5s\n", "Hi");   // 左对齐，宽度为 5：输出 "Hi   "
```

#### 精度控制

```c
printf("%.2f\n", 3.14159);   // 输出 "3.14"（保留2位小数）
printf("%.5f\n", 3.14159);   // 输出 "3.14159"（保留5位小数）
printf("%.3s\n", "Hello");   // 输出 "Hel"（最多3个字符）
printf("%10.2f\n", 3.14);    // 宽度10，精度2：输出 "      3.14"
```

#### 标志位

| 标志 | 含义 | 示例 |
|------|------|------|
| `-` | 左对齐 | `%-10d` |
| `+` | 显示正负号 | `%+d` |
| ` `（空格） | 正数前加空格 | `% d` |
| `#` |  alternate form | `%#x`, `%#o` |
| `0` | 用零填充 | `%05d` |

```c
printf("%+d\n", 42);       // 输出 "+42"
printf("%+d\n", -42);      // 输出 "-42"
printf("%05d\n", 42);      // 输出 "00042"
printf("%#x\n", 255);      // 输出 "0xff"
printf("%#o\n", 8);        // 输出 "010"
```

### printf 的陷阱

#### 1. 格式说明符与参数类型不匹配

```c
int a = 10;
printf("%f\n", a);  // 错误！%f 期望 double，但传了 int
printf("%d\n", 3.14);  // 错误！%d 期望 int，但传了 double
```

#### 2. 忘记传递参数

```c
printf("Value: %d\n");  // 错误！缺少对应的参数，未定义行为
```

#### 3. 字符串格式符用于非字符串

```c
int num = 42;
printf("%s\n", num);  // 错误！%s 期望 char*，但传了 int
```

## `scanf()` 格式控制与陷阱

### 基本用法

`scanf` 是 C 语言的标准输入函数，用于从标准输入读取格式化的数据。

```c
#include <stdio.h>

int main(void) {
    int age;
    printf("请输入年龄：");
    scanf("%d", &age);
    printf("你的年龄是：%d\n", age);
    return 0;
}
```

### 常见格式说明符

| 格式符 | 对应类型 | 说明 |
|--------|----------|------|
| `%d` | `int*` | 读取十进制整数 |
| `%u` | `unsigned int*` | 读取无符号整数 |
| `%f` | `float*` | 读取浮点数 |
| `%lf` | `double*` | 读取双精度浮点数 |
| `%c` | `char*` | 读取单个字符 |
| `%s` | `char*` | 读取字符串（遇空白字符停止） |
| `%x` | `int*` | 读取十六进制整数 |
| `%o` | `int*` | 读取八进制整数 |

### `scanf` 的重要陷阱

#### 陷阱 1：忘记取地址符 `&`

```c
int age;
scanf("%d", age);  // 错误！应该用 &age
scanf("%d", &age); // 正确
```

#### 陷阱 2：`%d` 后的空白字符会吸收换行符

```c
int a, b;
scanf("%d", &a);
scanf("%d", &b);  // 第一个 scanf 后的换行符会被第二个 scanf 的 %d 吸收
```

#### 陷阱 3：`%c` 读取换行符

```c
char ch;
int num;

scanf("%d", &num);
scanf("%c", &ch);  // 会读取到 num 后面的换行符 '\n'

// 解决方法：在 %c 前加空格
scanf(" %c", &ch);  // 空格会跳过所有空白字符
```

#### 陷阱 4：`%s` 不能读取带空格的字符串

```c
char name[50];
scanf("%s", name);  // 只能读取到第一个空格之前的部分

// 例如输入 "John Doe"，name 只会包含 "John"
```

#### 陷阱 5：缓冲区溢出

```c
char name[10];
scanf("%s", name);  // 如果输入超过 9 个字符，会导致缓冲区溢出

// 解决方法：限制读取长度
scanf("%9s", name);  // 最多读取 9 个字符（留一个给 '\0'）
```

### `%c` 与 `%s` 的差异

| 对比项 | `%c` | `%s` |
|--------|------|------|
| 读取内容 | 单个字符（包括空格、换行） | 一段字符串，遇到空白字符（空格、制表、换行）停止 |
| 目标 | `char*`（字符变量地址） | `char*`（字符数组名） |
| 空白字符 | 不会跳过，会读入 | 自动跳过前导空白 |
| 结束标志 | 读一个字符即返回 | 自动在末尾加 `'\0'` |

```c
char ch;
char str[50];

scanf("%c", &ch);   // 连空格、换行都会读入
scanf("%s", str);   // 前导空白被跳过，读到空白停止，自动加 '\0'
```

## 输入缓冲区

`scanf`、`getchar` 等输入函数读取的数据并不是直接来自键盘，而是来自**输入缓冲区**。用户从键盘输入的内容会先存入缓冲区，输入函数再从缓冲区中按格式取走数据。

- 按回车键后，键盘输入连同换行符 `'\n'` 一起进入缓冲区
- `scanf("%d", &a)` 只取走缓冲区中的数字，**换行符仍留在缓冲区中**
- 下一次调用 `scanf("%c", &ch)` 时，会直接读走这个残留的 `'\n'`，导致"跳过输入"的怪异现象

```c
int num;
char ch;

scanf("%d", &num);  // 输入 10 回车，缓冲区中剩下 '\n'
scanf("%c", &ch);   // ch 直接读到了 '\n'，程序看起来"跳过了"
```

> **解决方法**：在 `%c` 前加一个空格（`" %c"`）让 `scanf` 先跳过缓冲区中的空白字符，或调用 `getchar()` 吃掉残留的换行符。

### 安全的输入方式

#### 使用 `fgets` 读取字符串

```c
char name[50];
printf("请输入姓名：");
fgets(name, sizeof(name), stdin);

// fgets 会保留换行符，需要手动去除
size_t len = strlen(name);
if (len > 0 && name[len - 1] == '\n') {
    name[len - 1] = '\0';
}
```

#### 使用 `fgets` + `sscanf` 读取数值

```c
char buffer[100];
int num;

printf("请输入一个整数：");
fgets(buffer, sizeof(buffer), stdin);
sscanf(buffer, "%d", &num);
```

### `scanf` 的返回值

`scanf` 返回**成功读取并赋值的变量个数**，可用于判断输入是否成功。

```c
int num;
int result = scanf("%d", &num);

if (result == 1) {
    printf("成功读取整数：%d\n", num);
} else if (result == EOF) {
    printf("输入结束\n");
} else {
    printf("输入无效\n");
}
```

> **注意**：`scanf` 的返回值有几个用途：
> 1. 判断本次读取是否成功（返回 0 说明类型不匹配、读取失败）
> 2. 返回 `EOF`（值为 -1）表示到达文件末尾或输入结束
> 3. 多个格式符时返回成功赋值的个数，如 `scanf("%d %d", &a, &b)` 成功返回 2，部分成功返回 1

### 地址列表（&）说明

`scanf` 需要把读到的数据写入变量的地址，因此除了数组名（本身就是地址）外，**普通变量必须加取地址符 `&`**：

```c
int age;
double height;
char name[50];

scanf("%d", &age);      // 普通变量必须加 &
scanf("%lf", &height);  // 注意 double 用 %lf
scanf("%s", name);      // 数组名本身就是地址，不能加 &
```

## `getchar()` 和 `putchar()`

### `getchar()`

从标准输入读取一个字符。

```c
int ch = getchar();  // 读取一个字符，返回 int 类型（EOF 表示结束）
putchar(ch);         // 输出一个字符
```

### 读取一行字符

```c
int ch;
while ((ch = getchar()) != '\n' && ch != EOF) {
    putchar(ch);
}
```

## `gets` 和 `fgets` 对比

### `gets`（已废弃，不应使用）

```c
char buf[100];
gets(buf);  // 不检查缓冲区大小，存在缓冲区溢出风险
```

`gets` 已被 C11 标准移除，不应在任何代码中使用。

### `fgets`（推荐）

```c
char buf[100];
fgets(buf, sizeof(buf), stdin);  // 安全，最多读取 sizeof(buf)-1 个字符
```

## `puts` 和 `fputs` 对比

### `puts`

```c
puts("Hello");  // 输出字符串并自动添加换行
```

### `fputs`

```c
fputs("Hello", stdout);  // 输出字符串，不自动添加换行
fputs("Hello\n", stdout);  // 手动添加换行
```

## 格式化输入输出的完整示例

```c
#include <stdio.h>

int main(void) {
    int age;
    float height;
    char name[50];

    printf("请输入姓名、年龄和身高：");
    scanf("%49s %d %f", name, &age, &height);

    printf("姓名：%s\n", name);
    printf("年龄：%d\n", age);
    printf("身高：%.2f\n", height);

    return 0;
}
```

## 输入输出最佳实践

1. **优先使用 `fgets` 而非 `scanf` 读取字符串**
2. **始终检查 `scanf` 的返回值**
3. **使用宽度限制防止缓冲区溢出**
4. **`%c` 前加空格跳过空白字符**
5. **使用 `fputs` 替代 `puts` 以获得更多控制**
6. **避免使用 `gets`**
