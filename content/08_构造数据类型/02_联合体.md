# 联合体（union）

## 基本概念

联合体是一种特殊的数据类型，允许在**同一块内存**中存储不同的数据类型，但**同一时间只能存储其中一个成员**的值。

## 定义与声明

### 基本语法

```c
union 联合体名 {
    成员1类型 成员1;
    成员2类型 成员2;
    // ...
};
```

### 示例

```c
union Data {
    int i;
    float f;
    char str[20];
};
```

## 内存布局

联合体的大小等于其**最大成员**的大小。

```c
union Data {
    int i;        // 4 字节
    float f;      // 4 字节
    char str[20]; // 20 字节
};
// sizeof(union Data) = 20 字节
```

内存布局：所有成员都从**同一个起始地址**开始，占用的内存互相重叠。

```
地址    成员              占用的字节范围
0x1000  int i             字节 0 ~ 3
0x1000  float f           字节 0 ~ 3
0x1000  char str[20]      字节 0 ~ 19
```

所有成员共享同一块内存，修改一个成员会影响其他成员的字节内容。

## 联合体变量的定义与初始化

### 定义

```c
union Data data;
```

### 初始化

```c
union Data data = {.i = 42};  // C99 指定成员初始化
```

## 联合体与结构体的对比

| 特性 | 结构体（struct） | 联合体（union） |
|------|------------------|-----------------|
| 内存分配 | 每个成员独立分配 | 所有成员共享同一块内存 |
| 大小 | 各成员大小之和（考虑对齐） | 最大成员的大小 |
| 成员访问 | 所有成员可同时访问 | 同一时间只能访问一个成员 |
| 用途 | 组合不同类型的数据 | 节省内存，类型转换 |

## 联合体的应用场景

### 1. 类型转换（联合体技巧）

```c
union IntFloat {
    int i;
    float f;
};

// 将 int 的位模式解释为 float
union IntFloat converter;
converter.i = 0x40490FDB;  // π 的 IEEE 754 表示
printf("float value: %f\n", converter.f);  // 输出 3.141593
```

### 2. 大小端检测

**字节序（大小端）**：多字节数据在内存中的存放顺序。**小端序**（Little-Endian）低字节存低地址（x86 常用），**大端序**（Big-Endian）高字节存低地址（网络字节序）。用联合体可以检测当前机器的字节序。

```c
union EndianCheck {
    int i;
    char c[sizeof(int)];
};

int is_little_endian(void) {
    union EndianCheck ec;
    ec.i = 1;
    return ec.c[0] == 1;  // 小端序：低字节 0x01 存在低地址，返回 1；大端序返回 0
}
```

### 3. 协议解析

```c
union IPAddress {
    uint32_t addr;       // 32 位整数形式
    uint8_t bytes[4];    // 4 字节数组形式
    struct {
        uint8_t a;
        uint8_t b;
        uint8_t c;
        uint8_t d;
    } octets;
};

int main(void) {
    union IPAddress ip;
    ip.addr = 0x0100A8C0;  // 192.168.0.1 (小端序)

    printf("IP: %d.%d.%d.%d\n", ip.octets.a, ip.octets.b, ip.octets.c, ip.octets.d);
    return 0;
}
```

### 4. 节省内存

当不同时间点只需要存储不同类型的数据时，联合体可以节省内存。

```c
union Message {
    int int_msg;
    float float_msg;
    char char_msg;
};

// 如果只需要存储一种类型，联合体比结构体更节省内存
```

## 谭浩强经典例题：学生与教师信息

《C程序设计》的经典共用体例题：一个班有学生和教师，学生的信息包括姓名、编号、性别、职业、**班级**；教师的信息包括姓名、编号、性别、职业、**职务**。用共用体让"班级"和"职务"共用同一块内存。

```c
#include <stdio.h>
#include <string.h>

struct Person {
    int num;                  // 编号
    char name[20];            // 姓名
    char sex;                 // 性别：'M' 男，'F' 女
    char job;                 // 职业：'s' 学生，'t' 教师
    union {
        int class_num;        // 学生的班级（int）
        char position[20];    // 教师的职务（字符串）
    } category;               // 两种信息共用同一块内存
};

int main(void) {
    struct Person persons[2];

    // 学生：存班级
    persons[0].num = 1001;
    strcpy(persons[0].name, "张三");
    persons[0].sex = 'M';
    persons[0].job = 's';
    persons[0].category.class_num = 501;

    // 教师：存职务
    persons[1].num = 2001;
    strcpy(persons[1].name, "李梅");
    persons[1].sex = 'F';
    persons[1].job = 't';
    strcpy(persons[1].category.position, "教授");

    // 根据职业不同，解释联合体成员的类型也不同
    for (int i = 0; i < 2; i++) {
        if (persons[i].job == 's') {
            printf("学生：%s 班级=%d\n",
                   persons[i].name, persons[i].category.class_num);
        } else {
            printf("教师：%s 职务=%s\n",
                   persons[i].name, persons[i].category.position);
        }
    }

    return 0;
}
```

> **注意**：程序正是靠 `job` 这个"标记字段"来区分联合体中当前存放的是哪种类型，这正是"标记联合体"的思想。

## 联合体的注意事项

### 1. 读取未写入的成员

```c
union Data data;
data.i = 42;
// data.f 的值是未定义的（取决于内存布局）
```

以**类型解释**的方式读取成员：向一个成员写入字节后，用另一个成员读取时，得到的是同一段字节按该成员类型重新解释的结果。

```c
union IntFloat converter;
converter.i = 0x40490FDB;   // 写入 int
// converter.f 就是把这段字节当作 float 来解释（IEEE 754）
printf("%f\n", converter.f);  // 3.141593
```

> **注意**：这种"按其他成员类型读取"依赖机器的字节序（大小端），跨平台移植时结果可能不同。

### 2. 联合体的局限性

- 不能包含柔性数组成员（C99 引入的柔性数组仅限结构体）
- 初始化时只能指定一个成员（C99 通过指定初始化器指定）
- 联合体成员共享内存，多线程下需要额外同步

### 3. 匿名联合体

```c
struct Variant {
    int type;
    union {
        int i;
        float f;
        char c;
    };  // 匿名联合体，可以直接访问成员
};

struct Variant v;
v.type = 1;
v.i = 42;  // 直接访问联合体成员
```

## 联合体的典型应用：标记联合体

标记联合体（Tagged Union）是一种常见的模式，用于存储多种类型的数据。

```c
#include <stdio.h>
#include <string.h>

typedef enum {
    TYPE_INT,
    TYPE_FLOAT,
    TYPE_STRING
} ValueType;

typedef struct {
    ValueType type;
    union {
        int i;
        float f;
        char str[32];
    } data;
} Variant;

void print_variant(const Variant *v) {
    switch (v->type) {
        case TYPE_INT:
            printf("int: %d\n", v->data.i);
            break;
        case TYPE_FLOAT:
            printf("float: %f\n", v->data.f);
            break;
        case TYPE_STRING:
            printf("string: %s\n", v->data.str);
            break;
    }
}

int main(void) {
    Variant v1 = {TYPE_INT, {.i = 42}};
    Variant v2 = {TYPE_FLOAT, {.f = 3.14f}};
    Variant v3 = {TYPE_STRING, {.str = "Hello"}};

    print_variant(&v1);
    print_variant(&v2);
    print_variant(&v3);

    return 0;
}
```

## 联合体与 sizeof

```c
union Data {
    char c;      // 1 字节
    short s;     // 2 字节
    int i;       // 4 字节
    double d;    // 8 字节
};

printf("sizeof(union Data) = %zu\n", sizeof(union Data));  // 输出 8
```

## 联合体与内存对齐

联合体的对齐方式与最大成员的对齐方式一致。

```c
union Data {
    char c;      // 对齐 1
    int i;       // 对齐 4
};
// 联合体的对齐为 4（int 的对齐要求）
// sizeof(union Data) = 4（最大成员 int 的大小）
```

## 联合体的最佳实践

1. **明确当前存储的是哪个成员**（使用标记联合体）
2. **避免读取未写入的成员**
3. **用于类型转换时注意平台差异**
4. **用于节省内存时评估实际需求**
5. **在嵌入式系统中用于寄存器操作**
