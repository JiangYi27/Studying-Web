# 实战闯关 · 说明文档

> 主站「实战闯关」模块：以 Quiz Game 王国冒险体验为基础，接入主站账号、多站点题库与成就体系。

## 快速运行

```bash
npm start            # 启动服务（http://localhost:3000）
node scripts/build.js  # 改过前端代码后重新打包（bundle.js / bundle.css / index.prod.html）
```

登录（`config/users.js` 维护账号）后，点击侧栏「实战闯关」进入。

## 架构与文件

| 文件 | 职责 |
|------|------|
| `public/index.html` | `#roadmapView` 区块：开场标题页/加载动画/地图/战斗面板/关卡秘典过渡页 |
| `public/js/quizgame-data.js` | 游戏常量（`CONFIG`）与关卡秘典（`LEVEL_META`，14 关名称/图标/寓意） |
| `public/js/quizgame-audio.js` | Web Audio 合成音效（`window.Sound`） |
| `public/js/quizgame-game.js` | 游戏核心：地图渲染、相机、波次战斗、营地训练、关卡过渡页、进度桥接 |
| `public/js/quizgame-main.js` | 开场流程（标题→loop→开门→加载→地图）、地图交互（拖拽/缩放/键盘/小地图） |
| `public/js/roadmap.js` | 主站视图切换：`switchView('roadmap')` 调用 `QuizGameMain.enter()/exit()` |
| `public/css/game.css` | 游戏样式（`.qg-view` 视图体系 + 战斗/过渡页/地图样式） |
| `public/css/views/roadmap.css` | 外层 `#roadmapView` 容器样式 |
| `public/image|video|audio` | 游戏素材（图片已压缩为 WebP；视频/音频为原动画） |

## 关键流程

1. **进入**：侧栏「实战闯关」→ `switchView('roadmap')` → `QuizGameMain.enter()` → 每次完整播放开场（标题 → loop 视频 → 开门动画 → 加载 → 地图）。
2. **闯关**：点城堡 → 弹出「关卡秘典」过渡页（第 X 关/关卡名/寓意/小节进度）→ 「开始闯关」→ 3 波答题（按难度 3/4/3+1），15 秒限时、3 心、连击加分；通关标记章节并解锁下一章。
3. **训练**：点营地 → 直接进入该章节「训练战」（5 题、单波、不加通关进度、经验减半、每日首次 +30 经验）。
4. **退出**：地图「← 返回」回到主站主页；`QuizGameMain.exit()` 负责停止音乐/隐藏游戏层。

## 数据与持久化

- **题库**：主站 `public/data/quizzes.json`（C 每章 40 题）/ `grammar.json`（语法 5 章），经 `/api/quizzes` 按站点加载，题型仅选择题。
- **章节**：主站 `public/js/data/chapters.js` 的 `SITES`（C 14 章 / 语法 5 章）。
- **进度**：闯关进度独立存于主站全局状态 `state.quest`（含 `completedSections`、等级经验、`quizStats`、`practiceStats`），按 用户×站点 经 `/api/user-data` 持久化，与课程进度互不干扰。
- **徽章/成就**：营地训练相关徽章定义在 `public/js/data/chapters.js` 的 `COMMON_BADGES`（`camp_rookie` / `camp_veteran` / `camp_streak`），成就进度显示在 `public/js/views/dashboard.js`。

## 常见修改

- **改关卡名/寓意**：编辑 `quizgame-data.js` 的 `LEVEL_META`。
- **调训练题数/奖励**：`quizgame-game.js` 中 `openPractice` 的 `pickQuestions(pool, 5)` 与 `claimDailyPracticeBonus` 的 `30`。
- **改战斗参数**：`quizgame-data.js` 的 `CONFIG`（限时/生命/每级经验等）。
- **加徽章**：在 `chapters.js` 的 `COMMON_BADGES` 增加条目，并在 `dashboard.js` 的成就 switch 补对应进度。
- **地图布局**：C 站使用内联手工布局（14 关城堡/营地/装饰），由原 Quiz Game 的 `tools/editor.html` 工具链生成后内联进 `quizgame-game.js`。

## 注意事项

- 开场视频（`video/loop.mp4` 等）体积较大，已做懒加载（`preload="none"`），仅在进入对应阶段时请求。
- 主站自带背景音乐（`public/audio` 中的大 mp3）与游戏无关，如需瘦身可另行处理。
- 图片素材已转为 WebP 压缩版（原 PNG 备份在系统临时目录 `%TEMP%\studying-web-assets-orig`）。
