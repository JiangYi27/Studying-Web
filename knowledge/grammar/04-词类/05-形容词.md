# 05-形容词

> 形容词（Adjective）用于描述人或事物，可作**定语、表语、补语、状语**；同时还有比较级、最高级等变化。

---

## 一、形容词的用法

### 1.1 作定语

**① 前置定语**——直接放在被修饰对象之前，语序大致为：

> 限定词 + (主观特征 → 尺寸 → 形状 → 新旧 → 颜色 → 来源 → 材料 → 用途) + 名词

> a hungry rabbit；a little white rabbit
> a beautiful big round new black Chinese wooden table

**② 后置定语**——修饰以 -body / -thing 结尾的不定代词时，形容词后置：

> somebody nice、anybody absent、everything possible、nothing wrong

**③ 形容词短语作后置定语**——常可改写为定语从句：

| 短语 | 定语从句 |
|---|---|
| carrots good for the rabbit | carrots that are good for the rabbit |
| the rabbit eager to eat carrots | the rabbit that is eager to eat carrots |
| the rabbit busy eating carrots | the rabbit that is busy eating carrots |

### 1.2 作表语（主语补语）

> The rabbit is hungry.（兔子饿了。）

一些表现身体状况的形容词只能作表语，不能直接作前置定语：

> The rabbit is alive/asleep/alone. → 作定语用 a living/sleeping/lonely rabbit
> The rabbit is ill/well.（生病的/健康的）→ 作定语用 a sick/healthy rabbit

### 1.3 作补语（宾语补语）

> Carrots make rabbits happy.（胡萝卜让兔子开心。）

### 1.4 作状语

> The rabbit came home, tired and hungry.（兔子回到家，又累又饿。）

## 二、形容词的构成

| 类型 | 示例 |
|---|---|
| 简单形容词 | hungry、little、white |
| 形容词 + 形容词 | red-hot（红热的） |
| 形容词 + 现在分词 | good-looking（好看的） |
| 形容词 + 过去分词 | new-born（新生的） |
| 副词 + 形容词 | all-round（全面的） |
| 副词 + 现在分词 | hard-working（努力的） |
| 副词 + 过去分词 | recently-built（最近建成的） |
| 名词 + 形容词 | snow-white（雪白的） |
| 名词 + 现在分词 | carrot-eating（吃胡萝卜的） |
| 名词 + 过去分词 | heart-broken（心碎的） |

> 名词/形容词 + 名词 + -ed 构成的复合形容词，常相当于一个定语从句：white-haired = whose hair is white；heart-broken = whose heart is broken。

## 三、比较级和最高级

### 1. 构成规则

| 规则 | 示例 |
|---|---|
| 一般词尾 + -er / -est | long → longer → longest |
| 以 -e 结尾 + -r / -st | late → later → latest |
| 辅音 + y → 变 y 为 i + -er/-est | happy → happier → happiest |
| 重读闭音节，双写末尾辅音 | big → bigger → biggest |
| 多音节词前加 more / most | interesting → more interesting → most interesting |

**不规则变化：** good→better→best；bad→worse→worst；many/much→more→most；little→less→least。

### 2. 比较级用法

**① …比…更…**
> This carrot is bigger than that one.（这根比那根大。）

**② …和…一样…（原级）**
> This carrot is as big as that one.（这根和那根一样大。）

**③ 越来越…**
> The rabbit is smarter and smarter.（兔子越来越聪明。）

**④ the + 比较级…，the + 比较级…**
> The more carrots the rabbit eats, the smarter he will become.（吃得越多，就越聪明。）

### 3. 最高级用法

> Snow White is the most beautiful woman in the world.（白雪公主是世界上最美的女人。）

- 范围用 in + 地点 / of + 所属范围；"第几最"用 the second…。
- 修饰名词一般加 the；但 a most + 形容词中 most = very（非常）。

## 四、易混易错：-ly 结尾却是形容词 & 形近词

> `-ly` 结尾的词，很多同学以为是副词，其实是一类**以 -ly 结尾的形容词**。它们只能修饰名词或作表语，不能像副词那样修饰动词。这在语法填空里是高频设空点。

### 1. -ly 结尾的形容词一览

| 词 | 意思 | 名词用法 | 副词用法（⚠没有！） |
|---|---|---|---|
| **friendly** | 友好的 | a **friendly** smile | ~~smile friendly~~ → in a friendly way |
| **lovely** | 可爱的 | a **lovely** day | — |
| **lonely** | 孤独的 | a **lonely** rabbit | — |
| **lively** | 活泼的 | a **lively** party | — |
| **deadly** | 致命的 | a **deadly** disease | — |
| **costly** | 昂贵的 | a **costly** mistake | — |
| **ugly** | 丑的 | an **ugly** hat | — |
| **silly** | 傻的 | a **silly** question | — |
| **monthly / daily / weekly / yearly** | 每月的/每日的/每周的/每年的 | a **monthly** report | 可作副词，但更常用作形容词 |

> 判断口诀：**以 -ly 结尾，但前面接的是名词 → 形容词**。`a friendly rabbit`、`a lovely day`、`a lonely road`——它们都在名词前，是形容词。

> 反例提示：**friendly / lovely / lonely / lively / deadly / costly / ugly / silly** 都是形容词，不能用 -ly 修饰动词。

### 2. 副词篇的姊妹篇

> 这部分内容与《06-副词》第四章紧密相关：形容词作副词（fast/early/late/hard）、无 -ly 副词（good→well）、形近词（hard/hardly、high/highly）。建议两篇对照学习。

> - good（adj）→ well（adv）：`She is a good singer.` / `She sings well.`
> - hard（adv 努力地）≠ hardly（几乎不）：`He works hard.` / `He hardly works.`
> - 具体/空间含义用原形，抽象/程度含义用 -ly：`fly high`（飞得高）/ `think highly of`（高度评价）

### 3. 一句话总结

> **-ly 结尾不一定是副词**：friendly、lovely、lonely 等是形容词，只能接名词。想知道能不能作副词，就看它能不能修饰动词——不能，就是形容词。
