# 变量与常量

## 变量

### 变量的定义与初始化

变量是程序中存储数据的命名容器。在 C 语言中，使用变量前必须先声明其类型。

#### 声明与初始化

```c
// 声明但不初始化（值不确定）
int a;

// 声明并初始化
int b = 10;
float pi = 3.14f;
char ch = 'A';

// 声明多个变量
int x = 1, y = 2, z = 3;

// 先声明后赋值
int count;
count = 100;
```

#### 变量的命名规则

- 只能包含字母、数字和下划线
- 不能以数字开头
- 区分大小写
- 不能使用 C 语言关键字
- 命名应具有描述性

```c
// 合法命名
int studentCount;
int _count;
int count2;

// 非法命名
int 2count;      // 以数字开头
int student-count; // 包含连字符
int int;          // 使用关键字
```

### 变量的作用域

变量的作用域决定了变量在程序中哪些部分可以被访问。

#### 局部变量

在函数内部或代码块内部声明的变量，只在该作用域内有效。

```c
#include <stdio.h>

void func(void) {
    int localVar = 10;  // 局部变量
    printf("localVar = %d\n", localVar);
}

int main(void) {
    // localVar 在此处不可访问
    func();
    return 0;
}
```

#### 全局变量

在所有函数外部声明的变量，整个程序都可以访问。

```c
#include <stdio.h>

int globalVar = 100;  // 全局变量

void func(void) {
    printf("globalVar = %d\n", globalVar);
}

int main(void) {
    printf("globalVar = %d\n", globalVar);
    func();
    return 0;
}
```

#### 局部变量与全局变量的优先级

当局部变量与全局变量同名时，局部变量优先。

```c
#include <stdio.h>

int x = 10;  // 全局变量

int main(void) {
    int x = 20;  // 局部变量，屏蔽了全局变量
    printf("x = %d\n", x);  // 输出 20
    return 0;
}
```

> **注意**：这里只是初步了解局部变量与全局变量的概念。关于变量的作用域、存储类别（`auto`、`static`、`register`、`extern`）等内容，在后续章节（函数）中会详细讲解。

### 变量的生命周期

- **局部变量**：进入作用域时创建，离开作用域时销毁
- **全局变量**：程序启动时创建，程序结束时销毁
- **静态变量**：程序整个运行期间都存在

## 常量

常量是在程序运行期间其值不能被改变的量。C 语言提供了多种定义常量的方式。

### 字面常量

直接在代码中写入的值就是字面常量。

```c
3          // 整型常量
3.14       // 浮点型常量
'A'        // 字符常量
"Hello"    // 字符串常量
```

#### 整型常量的字面量规则

整型常量可以写成十进制、八进制或十六进制形式，还可加后缀指定类型：

- **十进制**：`123`、`-456`
- **八进制**：以 `0` 开头，如 `012` 表示八进制 12（十进制 10）
- **十六进制**：以 `0x`（或 `0X`）开头，如 `0x1F` 表示十六进制 1F（十进制 31）
- **后缀**：`L`/`l` 表示 `long`，`U`/`u` 表示无符号，如 `100L`、`0x1FUL`

```c
int a = 012;     // 八进制，十进制为 10
int b = 0x1F;    // 十六进制，十进制为 31
long c = 100L;   // long 类型的常量
unsigned d = 5U; // 无符号常量
```

> **注意**：以 `0` 开头会被当作八进制。例如 `int x = 09;` 是**错误**的（八进制中没有数字 9）。

#### 浮点型常量的字面量规则

浮点常量有两种书写形式：

- **小数形式**：`3.14`、`0.5`、`.5`（必须有小数点）
- **指数形式**：`3.14e2` 表示 3.14 × 10² = 314；`1.5e-3` 表示 0.0015
- **后缀**：`f`/`F` 表示 `float`，`l`/`L` 表示 `long double`，如 `3.14f`、`1.2L`

```c
double x = 3.14e2;  // 等价于 314.0
float  y = 3.14f;   // float 类型
double z = 1.5e-3;  // 等价于 0.0015
```

#### 字符常量的字面量规则

- **单个字符**：用单引号括起来，如 `'A'`、`'9'`
- **转义字符**：如 `'\n'`、`'\t'`、`'\''`
- **`'\0'`**：空字符，也是字符串的结束标志
- 字符常量在内存中就是其 ASCII 码值，本质上是 `int` 类型的整数值

```c
char ch1 = 'A';   // 字符常量
char ch2 = '\n';  // 转义字符常量
```

### `const` 关键字

使用 `const` 关键字声明的变量是常量，其值不能被修改。

```c
const int MAX_SIZE = 100;
const double PI = 3.14159265;

// MAX_SIZE = 200;  // 错误！不能修改 const 变量的值
```

#### const 与指针的结合

```c
int value = 10;

// 指向常量的指针：不能通过指针修改指向的值
const int *p1 = &value;
// *p1 = 20;  // 错误
p1 = &value;  // 正确，可以改变指针本身

// 常量指针：指针本身是常量，不能改变指针的指向
int *const p2 = &value;
*p2 = 20;  // 正确，可以修改指向的值
// p2 = &other;  // 错误

// 指向常量的常量指针：都不能修改
const int *const p3 = &value;
// *p3 = 20;  // 错误
// p3 = &other;  // 错误
```

### `#define` 宏常量

使用 `#define` 预处理器指令定义常量。

```c
#define MAX_SIZE 100
#define PI 3.14159265
#define MESSAGE "Hello, World!"
```

#### `#define` 与 `const` 的区别

| 特性 | `#define` | `const` |
|------|-----------|---------|
| 处理阶段 | 预处理阶段（文本替换） | 编译阶段 |
| 类型检查 | 无类型检查 | 有类型检查 |
| 作用域 | 从定义处到文件结束 | 遵循变量作用域规则 |
| 内存占用 | 不占用内存（替换） | 占用内存 |
| 调试 | 调试器看不到宏名 | 调试器可以看到变量名 |
| 作用 | 简单常量定义 | 复杂类型常量定义 |

```c
#define MAX 100        // 预处理替换，无类型
const int max = 100;   // 有类型，可调试
```

#### 宏常量的经典陷阱

因为 `#define` 是纯文本替换，宏常量在表达式中展开时不会自动加括号：

```c
#define N 3 + 2

int x = N * 2;  // 展开为 3 + 2 * 2 = 7，而不是预期的 10！
```

> **正确做法**：定义宏常量时，表达式一定要用括号括起来，即 `#define N (3 + 2)`。而 `const` 常量是真正的变量，不存在这个问题。

### 枚举常量（`enum`）

使用 `enum` 定义一组命名的整数常量。

```c
enum Color {
    RED,      // 0
    GREEN,    // 1
    BLUE      // 2
};

enum Color c = GREEN;
printf("c = %d\n", c);  // 输出 1
```

#### 指定枚举值

```c
enum Status {
    SUCCESS = 0,
    ERROR = 1,
    UNKNOWN = -1
};
```

### 字符串常量

字符串常量是用双引号括起来的字符序列，末尾自动添加 `'\0'`。

```c
"Hello"      // 存储在内存中，实际为 {'H','e','l','l','o','\0'}
"Hello\0World"  // 包含空字符的字符串
```

## 初始化与未初始化的区别

### 局部变量未初始化

局部变量未初始化时，其值是不确定的（垃圾值）。

```c
#include <stdio.h>

int main(void) {
    int x;          // 未初始化，值不确定
    printf("x = %d\n", x);  // 输出随机值

    int y = 0;      // 初始化为 0
    printf("y = %d\n", y);  // 输出 0

    return 0;
}
```

### 全局变量和静态变量未初始化

全局变量和静态变量未初始化时，自动初始化为 0。

```c
int global_uninit;    // 自动初始化为 0
static int static_uninit;  // 自动初始化为 0

int main(void) {
    printf("global_uninit = %d\n", global_uninit);  // 输出 0
    printf("static_uninit = %d\n", static_uninit);  // 输出 0
    return 0;
}
```

## const 修饰符的位置

```c
const int *p;     // 指向常量的指针，指向的值不能通过 p 修改
int *const p;     // 常量指针，指针本身不能修改
const int *const p;  // 指向常量的常量指针，都不能修改
```

**记忆口诀**：
- `const` 在 `*` 左边：指向的值是常量
- `const` 在 `*` 右边：指针本身是常量
- `const` 在 `*` 两边：都是常量
