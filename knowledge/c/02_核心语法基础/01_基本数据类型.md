# 基本数据类型

C 语言提供了多种基本数据类型，用于表示不同种类的数据。理解每种类型的存储方式和取值范围是编写正确程序的基础。

## 整型（Integer Types）

### `int`

`int` 是最常用的整数类型，通常占用 4 个字节（32 位）。

| 属性 | 值 |
|------|-----|
| 大小 | 4 字节（32 位） |
| 有符号范围 | -2,147,483,648 到 2,147,483,647 |
| 无符号范围 | 0 到 4,294,967,295 |
| 格式说明符 | `%d` 或 `%i` |

```c
int age = 25;
int count = -100;
unsigned int positive_only = 1000;
```

### `short`（短整型）

`short` 通常占用 2 个字节（16 位），适用于较小的整数值。

| 属性 | 值 |
|------|-----|
| 大小 | 2 字节（16 位） |
| 有符号范围 | -32,768 到 32,767 |
| 无符号范围 | 0 到 65,535 |
| 格式说明符 | `%hd` |

```c
short small_number = 100;
unsigned short us = 50000;
```

### `long`（长整型）

`long` 通常占用 4 或 8 个字节，取决于编译器和平台。

| 属性 | 32 位系统 | 64 位系统 |
|------|----------|----------|
| 大小 | 4 字节 | 4 或 8 字节 |
| 有符号范围 | -2,147,483,648 到 2,147,483,647 | 同左或更大 |
| 格式说明符 | `%ld` | `%ld` |

```c
long big_number = 100000L;
long long very_big = 9223372036854775807LL;
```

### `long long`

`long long` 保证至少 8 个字节（64 位），用于表示非常大的整数。

| 属性 | 值 |
|------|-----|
| 大小 | 8 字节（64 位） |
| 有符号范围 | -9,223,372,036,854,775,808 到 9,223,372,036,854,775,807 |
| 格式说明符 | `%lld` |

### 无符号整型

无符号类型只能表示非负数，但可以表示更大的正值。

```c
unsigned int ui = 4000000000U;
unsigned short us = 65535;
unsigned long ul = 4294967295UL;
unsigned long long ull = 18446744073709551615ULL;
```

### 整型大小与范围总结

| 类型 | 大小（典型） | 有符号范围 | 无符号范围 | 格式符 |
|------|-------------|-----------|-----------|--------|
| `char` | 1 字节 | -128 到 127 | 0 到 255 | `%c` / `%hhu` |
| `short` | 2 字节 | -32,768 到 32,767 | 0 到 65,535 | `%hd` / `%hu` |
| `int` | 4 字节 | -2^31 到 2^31-1 | 0 到 2^32-1 | `%d` / `%u` |
| `long` | 4/8 字节 | 依赖平台 | 依赖平台 | `%ld` / `%lu` |
| `long long` | 8 字节 | -2^63 到 2^63-1 | 0 到 2^64-1 | `%lld` / `%llu` |

> **注意**：C 标准只规定了各类型的最小范围，实际大小可能因编译器和平台而异。可以使用 `sizeof()` 运算符获取类型的大小。
>
> 下表是 C 标准（ANSI C）保证的各整型**最小范围**，任何编译器都必须至少支持这些范围（实际值通常更大）：

| 类型 | 最小保证范围 |
|------|-------------|
| `char` | 至少能表示 0 到 127 |
| `int` | -32,768 到 32,767（至少 16 位） |
| `short` | -32,768 到 32,767（至少 16 位） |
| `long` | -2,147,483,648 到 2,147,483,647（至少 32 位） |

> 例如，现代 32 位系统上 `int` 通常是 32 位的，但为了程序的可移植性，不能假设 `int` 一定是 32 位，只应保证其值在最小范围内。

```c
#include <stdio.h>

int main(void) {
    printf("char: %zu bytes\n", sizeof(char));
    printf("short: %zu bytes\n", sizeof(short));
    printf("int: %zu bytes\n", sizeof(int));
    printf("long: %zu bytes\n", sizeof(long));
    printf("long long: %zu bytes\n", sizeof(long long));
    return 0;
}
```

## 浮点型（Floating-Point Types）

### `float`（单精度浮点型）

| 属性 | 值 |
|------|-----|
| 大小 | 4 字节（32 位） |
| 有效数字 | 约 6-7 位十进制有效数字 |
| 取值范围 | 约 ±3.4 × 10^38 |
| 格式说明符 | `%f`（默认6位小数） |
| 后缀 | `f` 或 `F` |

```c
float pi = 3.14159f;
float temperature = 36.5f;
```

### `double`（双精度浮点型）

| 属性 | 值 |
|------|-----|
| 大小 | 8 字节（64 位） |
| 有效数字 | 约 15-16 位十进制有效数字 |
| 取值范围 | 约 ±1.7 × 10^308 |
| 格式说明符 | `%lf` 或 `%f` |

```c
double pi = 3.141592653589793;
double gravity = 9.80665;
```

### `long double`（长双精度浮点型）

| 属性 | 值 |
|------|-----|
| 大小 | 8 或 16 字节（依赖平台） |
| 有效数字 | 依赖平台，通常 18-33 位 |
| 格式说明符 | `%Lf` |

### 浮点数的存储方式

浮点数在内存中按照 IEEE 754 标准存储：

```
float (32位):
┌──────────┬──────────────┬──────────────────┐
│ 符号位(1) │ 指数位(8位)   │ 尾数位(23位)     │
└──────────┴──────────────┴──────────────────┘

double (64位):
┌──────────┬───────────────┬──────────────────────┐
│ 符号位(1) │ 指数位(11位)   │ 尾数位(52位)         │
└──────────┴───────────────┴──────────────────────┘
```

### 浮点数的精度问题

浮点数在计算机中无法精确表示所有十进制小数，这会导致精度误差。

```c
#include <stdio.h>

int main(void) {
    float a = 0.1f;
    float b = 0.2f;
    float c = a + b;

    // 不能直接比较浮点数是否相等
    // printf("%d\n", c == 0.3f);  // 可能输出 0

    // 应该使用误差范围比较
    printf("%.20f\n", c);  // 输出 0.30000001192092895508

    // 正确的比较方式
    if (c - 0.3f < 0.0001f) {
        printf("近似相等\n");
    }

    return 0;
}
```

## 字符型（`char`）

### 基本概念

`char` 类型用于存储单个字符，实际上存储的是字符对应的 ASCII 码值。

| 属性 | 值 |
|------|-----|
| 大小 | 1 字节 |
| 有符号范围 | -128 到 127 |
| 无符号范围 | 0 到 255 |
| 格式说明符 | `%c`（字符）/ `%hhu`（整数值） |

```c
char ch = 'A';       // 字符 A，ASCII 码为 65
char newline = '\n'; // 换行符
char digit = '9';    // 字符 '9'，ASCII 码为 57
```

### 字符与整数的转换

字符在内存中存储的是其 ASCII 码值，因此字符和整数可以互相转换。

```c
char ch = 'A';
int ascii = ch;  // ascii = 65

char ch2 = 65;   // ch2 = 'A'

printf("字符 %c 的 ASCII 码是 %d\n", ch, ascii);
printf("ASCII 码 66 对应的字符是 %c\n", 66);  // 输出 'B'
```

### 转义字符

| 转义字符 | 含义 | ASCII 码 |
|----------|------|----------|
| `\n` | 换行 | 10 |
| `\t` | 水平制表符 | 9 |
| `\r` | 回车 | 13 |
| `\\` | 反斜杠 | 92 |
| `\'` | 单引号 | 39 |
| `\"` | 双引号 | 34 |
| `\0` | 空字符（字符串结束标志） | 0 |
| `\a` | 警报（响铃） | 7 |
| `\b` | 退格 | 8 |
| `\f` | 换页 | 12 |
| `\v` | 垂直制表符 | 11 |
| `\xHH` | 十六进制表示的字符 | - |
| `\ooo` | 八进制表示的字符 | - |

```c
printf("Hello\tWorld\n");   // 输出带制表符和换行
printf("Path: C:\\Users\\name\n");  // 输出路径中的反斜杠
printf("Hex: \x41\n");      // 输出 'A'（十六进制 0x41）
```

### `getchar` / `putchar` 与字符型

字符型数据常与 `getchar`、`putchar` 配合进行单个字符的输入输出：

```c
#include <stdio.h>

int main(void) {
    int ch = getchar();  // 从键盘读入一个字符
    putchar(ch);         // 向屏幕输出一个字符
    putchar('\n');       // 再输出一个换行
    return 0;
}
```

> **注意**：`getchar` 的返回值是 `int` 类型，而不是 `char`，因为需要能返回 `EOF`（值为 -1）来表示输入结束。如果只用 `char` 接收，读到某些高位为 1 的字符时可能与 `EOF` 混淆，判断出错。

## 布尔类型（C99 引入 `_Bool`，C11 引入 `bool`）

C99 标准引入了 `_Bool` 类型，C11 标准通过 `<stdbool.h>` 头文件提供了 `bool`、`true`、`false` 宏。

```c
#include <stdbool.h>
#include <stdio.h>

int main(void) {
    bool is_valid = true;
    bool is_empty = false;

    printf("is_valid = %d\n", is_valid);  // 输出 1
    printf("is_empty = %d\n", is_empty);  // 输出 0

    if (is_valid) {
        printf("有效\n");
    }

    return 0;
}
```

## `sizeof` 运算符

`sizeof` 运算符用于获取数据类型或变量在内存中占用的字节数。

```c
#include <stdio.h>

int main(void) {
    printf("sizeof(char) = %zu\n", sizeof(char));
    printf("sizeof(short) = %zu\n", sizeof(short));
    printf("sizeof(int) = %zu\n", sizeof(int));
    printf("sizeof(long) = %zu\n", sizeof(long));
    printf("sizeof(long long) = %zu\n", sizeof(long long));
    printf("sizeof(float) = %zu\n", sizeof(float));
    printf("sizeof(double) = %zu\n", sizeof(double));
    printf("sizeof(long double) = %zu\n", sizeof(long double));
    printf("sizeof(bool) = %zu\n", sizeof(bool));

    // 也可以用于变量
    int x;
    printf("sizeof(x) = %zu\n", sizeof(x));
    printf("sizeof(int) = %zu\n", sizeof(int));

    return 0;
}
```

## `limits.h` 中的整型范围宏

标准头文件 `<limits.h>` 定义了各整型类型的最大、最小值宏，程序中可以直接使用，避免写死具体的数值：

| 宏 | 含义 |
|----|------|
| `INT_MAX` | `int` 的最大值（通常 2147483647） |
| `INT_MIN` | `int` 的最小值（通常 -2147483648） |
| `UINT_MAX` | `unsigned int` 的最大值（通常 4294967295） |
| `LONG_MAX` | `long` 的最大值 |
| `LONG_MIN` | `long` 的最小值 |
| `SHRT_MAX` | `short` 的最大值 |
| `SHRT_MIN` | `short` 的最小值 |
| `CHAR_BIT` | 一个字节的位数（通常 8） |

```c
#include <stdio.h>
#include <limits.h>

int main(void) {
    printf("INT_MAX = %d\n", INT_MAX);
    printf("INT_MIN = %d\n", INT_MIN);
    printf("UINT_MAX = %u\n", UINT_MAX);
    printf("LONG_MAX = %ld\n", LONG_MAX);
    return 0;
}
```

## printf 中类型不匹配的危害

`printf` **不会**自动进行类型转换，格式说明符必须与实参的实际类型严格对应，否则属于未定义行为：

```c
int a = 65;
printf("%c\n", a);       // 合法：把整数 65 按字符输出 'A'
printf("%f\n", a);       // 危险！%f 期望 double，却传了 int
printf("%d\n", 3.14);    // 危险！%d 期望 int，却传了 double
printf("%s\n", 65);      // 危险！%s 期望字符串地址，却传了整数
```

> **注意**：类型不匹配通常不会导致编译错误（编译器只给警告），但运行时输出是未定义行为——可能输出垃圾值、错误截断，甚至导致程序崩溃。编写 `printf` 时必须让格式说明符与参数类型一一对应。

## 类型转换

### 隐式类型转换（自动类型提升）

当不同类型的数据进行运算时，C 语言会自动进行类型转换。

```c
int a = 5;
double b = 2.0;
double result = a / b;  // a 被自动转换为 double，结果为 2.5

// 整数除法
int c = 5 / 2;  // 结果为 2（小数部分被截断）
double d = 5 / 2;  // 结果仍为 2.0（先整数除法，再转换为 double）
double e = 5.0 / 2;  // 结果为 2.5
```

### 显式类型转换（强制类型转换）

使用强制类型转换运算符 `(类型)` 可以显式转换数据类型。

```c
int a = 7, b = 2;
double result = (double)a / b;  // 结果为 3.5

int x = (int)3.14;  // x = 3（截断小数部分）
```

## 存储方式

### 整数存储

整数在内存中以**补码**形式存储：

- **正数**：原码、反码、补码相同
- **负数**：补码 = 反码 + 1

```
+5 的补码（8位）：0000 0101
-5 的补码（8位）：1111 1011
```

### 浮点数存储

浮点数按照 IEEE 754 标准存储，由符号位、指数位和尾数位组成：

```
(-1)^符号位 × 1.尾数 × 2^(指数-偏移量)
```

例如，`5.0` 的存储：
- 二进制：`101.0` = `1.01 × 2^2`
- 符号位：`0`
- 指数：`2 + 127 = 129`（float 偏移量为 127）
- 尾数：`01`（去掉前导 1）
