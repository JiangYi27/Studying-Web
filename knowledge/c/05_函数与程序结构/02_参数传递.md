# 参数传递

## 值传递（副本机制）

### 基本概念

在 C 语言中，所有函数参数都是通过**值传递**的。这意味着函数接收的是实参的副本，函数内部对参数的修改不会影响原始变量。

### 示例

```c
#include <stdio.h>

void modify(int x) {
    x = 100;  // 修改的是副本
    printf("函数内 x = %d\n", x);
}

int main(void) {
    int a = 5;
    printf("调用前 a = %d\n", a);
    modify(a);
    printf("调用后 a = %d\n", a);  // a 仍然是 5
    return 0;
}
```

输出：
```
调用前 a = 5
函数内 x = 100
调用后 a = 5
```

### 值传递的原理

```
调用前：a = 5
         ↓
调用 modify(a)：
  创建副本 x = 5
  修改 x = 100（不影响 a）
         ↓
调用后：a = 5（未改变）
```

### 基本类型的值传递

```c
void swap(int a, int b) {
    int temp = a;
    a = b;
    b = temp;
    // 只交换了副本，原始变量不受影响
}

int main(void) {
    int x = 1, y = 2;
    swap(x, y);
    // x 仍然是 1，y 仍然是 2
    return 0;
}
```

### 为什么值传递交换失败？

`swap` 函数内部交换的只是形参 `a`、`b` 的**副本**，函数返回后副本销毁，实参 `x`、`y` 自始至终没有参与交换：

```
调用 swap(x, y) 时：
实参 x=1 ──► 形参 a=1（副本）
实参 y=2 ──► 形参 b=2（副本）
函数体内交换 a、b → a=2, b=1
函数返回，a、b 销毁 → x 仍为 1，y 仍为 2
```

要真正交换实参的值，必须传递实参的**地址**，让函数通过指针去修改实参所在的内存单元（见下文"通过指针实现 swap"）。

## 形参（形式参数）与实参（实际参数）

### 基本概念

- **形参**：在函数定义时声明的参数，只在使用时分配内存，函数返回后即销毁。
- **实参**：在函数调用时传给形参的具体值（或表达式）。

```c
// 形参：a、b
int add(int a, int b) {
    return a + b;
}

int main(void) {
    int x = 3, y = 5;
    int result = add(x, y);  // 实参：x、y（值传递，把 3 和 5 复制给 a 和 b）
    return 0;
}
```

### 形参与实参的特点

1. **一一对应**：实参的个数、顺序、类型必须与形参一致（或类型兼容）。
2. **值传递**：C 语言中实参向形参的传递是"值传递"，函数内修改形参不影响实参。
3. **形参是局部变量**：形参只在函数被调用时存在，属于该函数的局部变量。
4. **形参默认未初始化前不能使用**：实参传入后才获得确定的值。

### 参数传递的方向

实参 → 形参是**单向**传递，即只能把实参的值传给形参，不能把形参的值反向传给实参。

```c
void change(int x) {
    x = 999;  // 修改形参
}

int main(void) {
    int a = 1;
    change(a);
    printf("a = %d\n", a);  // 输出 1：单向传递，a 不受影响
    return 0;
}
```

## 地址传递（通过指针模拟）

### 基本概念

通过传递变量的地址（指针），函数可以访问和修改原始变量。

### 示例

```c
#include <stdio.h>

void modify(int *x) {
    *x = 100;  // 通过指针修改原始变量的值
    printf("函数内 *x = %d\n", *x);
}

int main(void) {
    int a = 5;
    printf("调用前 a = %d\n", a);
    modify(&a);  // 传递 a 的地址
    printf("调用后 a = %d\n", a);  // a 现在是 100
    return 0;
}
```

输出：
```
调用前 a = 5
函数内 *x = 100
调用后 a = 100
```

### 通过指针实现 swap

```c
#include <stdio.h>

void swap(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

int main(void) {
    int x = 1, y = 2;
    printf("交换前：x = %d, y = %d\n", x, y);
    swap(&x, &y);
    printf("交换后：x = %d, y = %d\n", x, y);
    return 0;
}
```

输出：
```
交换前：x = 1, y = 2
交换后：x = 2, y = 1
```

### 谭浩强经典 swap：值传递失败 vs 传地址成功

```c
// 情况 1：值传递 → 交换失败
void swap_value(int a, int b) {
    int temp = a;
    a = b;
    b = temp;
}

// 情况 2：传地址（传指针）→ 交换成功
void swap_ptr(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

int main(void) {
    int x = 1, y = 2;

    swap_value(x, y);            // 实参传值，x、y 不变
    printf("值传递后：x = %d, y = %d\n", x, y);  // 1, 2

    swap_ptr(&x, &y);            // 实参传地址，通过指针修改
    printf("传地址后：x = %d, y = %d\n", x, y);  // 2, 1
    return 0;
}
```

输出：
```
值传递后：x = 1, y = 2
传地址后：x = 2, y = 1
```

**结论**：形参是实参的副本，值传递无法改变实参；要想在函数中修改实参，必须把实参的地址（指针）传进去。

## 数组作为参数

### 数组名退化为指针

当数组作为函数参数时，数组名会退化为指向首元素的指针。

```c
void print_array(int arr[], int size) {
    // arr 实际上是 int*，不是数组
    for (int i = 0; i < size; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");
}

int main(void) {
    int nums[] = {1, 2, 3, 4, 5};
    print_array(nums, 5);  // nums 退化为指针
    return 0;
}
```

> **注意**：数组作函数参数退化为指针后，传进去的是数组**首元素的地址**。在函数内 `sizeof(arr)` 得到的是指针大小（32 位系统 4 字节，64 位系统 8 字节），而不是数组大小。因此传数组时通常需要**额外传入数组长度**（如上面的 `size` 参数）。

### 数组参数与指针参数等价

以下三种函数声明是等价的：

```c
void func1(int arr[]);       // 数组形式
void func2(int arr[10]);     // 指定大小（但实际被忽略）
void func3(int *arr);        // 指针形式
```

### 通过指针修改数组元素

```c
void double_array(int *arr, int size) {
    for (int i = 0; i < size; i++) {
        arr[i] *= 2;  // 通过指针修改原始数组
    }
}

int main(void) {
    int nums[] = {1, 2, 3, 4, 5};
    double_array(nums, 5);
    // nums 现在是 {2, 4, 6, 8, 10}
    return 0;
}
```

## 结构体作为参数

### 值传递结构体

```c
#include <stdio.h>

struct Point {
    int x;
    int y;
};

void print_point(struct Point p) {
    printf("(%d, %d)\n", p.x, p.y);
}

int main(void) {
    struct Point pt = {3, 4};
    print_point(pt);  // 传递结构体的副本
    return 0;
}
```

### 指针传递结构体（推荐）

传递结构体指针可以避免复制整个结构体，提高效率。

```c
void print_point_ptr(const struct Point *p) {
    printf("(%d, %d)\n", p->x, p->y);
}

int main(void) {
    struct Point pt = {3, 4};
    print_point_ptr(&pt);  // 传递结构体指针
    return 0;
}
```

## const 与参数传递

### const 保护不修改的参数

使用 `const` 修饰指针参数，表示函数不会修改指向的数据。

```c
void print_string(const char *str) {
    // str 指向的数据不能被修改
    printf("%s\n", str);
    // *str = 'X';  // 错误！不能修改 const 指向的数据
}
```

### const 修饰指针本身

```c
void func(const int *p);    // 指向的值不能修改，指针可以重新指向
void func(int *const p);    // 指针不能重新指向，指向的值可以修改
void func(const int *const p);  // 都不能修改
```

## 数组作为返回值的替代方案

C 语言不能直接返回数组，但可以通过以下方式实现：

### 返回静态数组的指针

```c
int* get_array(void) {
    static int arr[5] = {1, 2, 3, 4, 5};
    return arr;  // 返回静态数组的指针
}
```

### 返回动态分配的数组

```c
int* create_array(int size) {
    int *arr = (int *)malloc(size * sizeof(int));
    if (arr != NULL) {
        for (int i = 0; i < size; i++) {
            arr[i] = i * 10;
        }
    }
    return arr;  // 调用者负责释放内存
}
```

## 参数传递总结

| 传递方式 | 机制 | 是否影响原始变量 | 适用场景 |
|----------|------|------------------|----------|
| 值传递 | 传递副本 | 否 | 基本类型、小型结构体 |
| 地址传递 | 传递指针 | 是 | 需要修改外部变量、大结构体 |
| 数组传递 | 退化为指针 | 是（通过指针修改） | 数组参数 |

## 常见陷阱

### 陷阱 1：忘记取地址符

```c
void modify(int *x) {
    *x = 100;
}

int main(void) {
    int a = 5;
    modify(a);   // 错误！应该用 &a
    modify(&a);  // 正确
    return 0;
}
```

### 陷阱 2：返回局部变量的指针

```c
int* bad_func(void) {
    int arr[5] = {1, 2, 3, 4, 5};
    return arr;  // 错误！arr 是局部变量，函数结束后内存被释放
}
```

### 陷阱 3：数组参数大小被忽略

```c
void func(int arr[10]) {
    // arr[10] 的大小信息被忽略
    // sizeof(arr) 在函数内等于 sizeof(int*)
}
```

### 陷阱 4：const 修饰符位置混淆

```c
const int *p;     // 指向常量的指针
int *const p;     // 常量指针
const int *const p;  // 指向常量的常量指针
```
