# 函数定义与声明

## 函数的基本概念

函数是 C 语言中组织代码的基本单元，用于封装可重用的代码块。

## 函数定义

### 基本语法

```c
返回类型 函数名(参数列表) {
    // 函数体
    return 返回值;
}
```

### 示例

```c
// 无参数、无返回值
void greet(void) {
    printf("Hello, World!\n");
}

// 有参数、有返回值
int add(int a, int b) {
    return a + b;
}

// 无参数、有返回值
int get_random(void) {
    return rand() % 100;
}
```

### 返回类型

| 返回类型 | 说明 | 示例 |
|----------|------|------|
| `void` | 无返回值 | `void print(void)` |
| `int` | 整数 | `int add(int a, int b)` |
| `double` | 双精度浮点数 | `double sqrt(double x)` |
| `char` | 字符 | `char get_char(void)` |
| `int*` | 指针 | `int* create_array(int n)` |

### `void` 返回类型

`void` 表示函数不返回任何值。

```c
void print_hello(void) {
    printf("Hello\n");
    // 不需要 return 语句
}
```

## 函数声明（原型）

### 基本语法

```c
返回类型 函数名(参数类型);
```

### 示例

```c
// 函数声明（原型）
int add(int a, int b);
void greet(void);
double calculate(double x, double y);
```

### 声明的作用

1. **告诉编译器函数的存在**：在函数定义之前调用函数时需要声明
2. **类型检查**：编译器检查调用时的参数类型和返回值类型
3. **头文件中声明**：通常将函数声明放在头文件中

### 声明与定义的关系

```c
// 声明（告诉编译器函数的存在）
int add(int a, int b);

int main(void) {
    int result = add(3, 5);  // 调用函数
    printf("Result: %d\n", result);
    return 0;
}

// 定义（实现函数的具体功能）
int add(int a, int b) {
    return a + b;
}
```

### 声明与定义的区别

| 对比项 | 函数声明（原型） | 函数定义 |
|--------|------------------|----------|
| 作用 | 告诉编译器函数的名字、参数和返回类型 | 实现函数的具体功能（函数体） |
| 是否分配存储 | 否 | 是 |
| 能否重复 | 可以多次声明 | 只能定义一次 |
| 是否带函数体 | 不带 `{}` | 必须带 `{}` |

```c
int add(int a, int b);   // 声明：只有类型信息，没有函数体
int add(int a, int b);   // 声明：可以重复出现

int add(int a, int b) {  // 定义：包含函数体
    return a + b;
}
```

### 为什么必须声明（谭浩强"被调函数声明"规则）

C 语言要求：**被调用的函数必须在调用之前进行声明（函数原型）**，否则编译器无法检查参数类型和返回类型。在 C99 之前的旧标准中，若省略声明，编译器会默认函数返回 `int` 并给出警告；从 C99 起直接报错。

```c
#include <stdio.h>

// 在 main 之前声明被调函数
int max(int x, int y);

int main(void) {
    int a = 3, b = 5;
    printf("max = %d\n", max(a, b));  // 正确：已有声明
    return 0;
}

// 被调函数的定义可以放在调用之后
int max(int x, int y) {
    return x > y ? x : y;
}
```

> **注意**：这就是谭浩强教材强调的"被调函数应先声明后调用"规则。如果被调函数的定义出现在调用点**之前**，则可以省略声明。

## 形参与实参

### 形式参数（形参）

形参是函数定义中声明的参数，用于接收调用时传递的值。

### 实际参数（实参）

实参是函数调用时传递给形参的具体值。

```c
// 形参：a 和 b
int add(int a, int b) {
    return a + b;
}

int main(void) {
    // 实参：3 和 5
    int result = add(3, 5);  // a=3, b=5
    return 0;
}
```

### 形参与实参的匹配规则

1. **数量匹配**：实参个数必须与形参个数一致
2. **类型匹配**：实参类型应与形参类型兼容
3. **顺序匹配**：实参按顺序传递给形参

```c
// 正确
int add(int a, int b);
add(3, 5);

// 错误：实参个数不匹配
add(3);
add(3, 5, 7);
```

## 参数传递方式

### 值传递

C 语言中所有参数都是值传递，即传递的是参数的副本。

```c
void modify(int x) {
    x = 100;  // 修改的是副本，不影响原始变量
}

int main(void) {
    int a = 5;
    modify(a);
    printf("a = %d\n", a);  // 输出 5，未被修改
    return 0;
}
```

### 地址传递（通过指针模拟）

通过传递指针，可以在函数内部修改外部变量的值。

```c
void modify(int *x) {
    *x = 100;  // 通过指针修改原始变量的值
}

int main(void) {
    int a = 5;
    modify(&a);
    printf("a = %d\n", a);  // 输出 100，被修改
    return 0;
}
```

## 函数的返回值

### 返回值的使用

```c
int add(int a, int b) {
    return a + b;
}

int main(void) {
    int result = add(3, 5);  // 接收返回值
    printf("3 + 5 = %d\n", result);
    return 0;
}
```

### 返回多个值

C 语言函数只能返回一个值，但可以通过指针参数返回多个值。

```c
void divide(int a, int b, int *quotient, int *remainder) {
    *quotient = a / b;
    *remainder = a % b;
}

int main(void) {
    int q, r;
    divide(17, 5, &q, &r);
    printf("17 / 5 = %d ... %d\n", q, r);  // 输出 3 ... 2
    return 0;
}
```

## 函数的嵌套调用

```c
int add(int a, int b) {
    return a + b;
}

int multiply(int a, int b) {
    return a * b;
}

int main(void) {
    int result = multiply(add(2, 3), 4);  // 先调用 add(2,3)=5，再调用 multiply(5,4)=20
    printf("Result: %d\n", result);  // 输出 20
    return 0;
}
```

## 函数的递归调用

```c
// 递归计算阶乘
int factorial(int n) {
    if (n <= 1) {
        return 1;  // 递归终止条件
    }
    return n * factorial(n - 1);  // 递归调用
}

int main(void) {
    printf("5! = %d\n", factorial(5));  // 输出 120
    return 0;
}
```

## 函数的作用域

### 局部函数（C 语言不支持）

C 语言不支持局部函数（嵌套定义），所有函数都是全局作用域。

```c
// 错误：C 语言不支持嵌套函数
int main(void) {
    int helper(int x) {  // 错误！
        return x * 2;
    }
    return helper(5);
}
```

### 静态函数（内部链接）

使用 `static` 关键字声明的函数只能在定义它的源文件中访问。

```c
// file1.c
static int helper(int x) {
    return x * 2;
}

void public_func(void) {
    int result = helper(5);  // 正确：同一文件内可访问
}
```

## main 函数

### main 函数的几种形式

`main` 是程序的入口函数，C 标准允许以下几种形式：

```c
// 形式 1：无参数（最常用）
int main(void) {
    return 0;
}

// 形式 2：省略 void 的旧式写法
int main() {
    return 0;
}

// 形式 3：带命令行参数
int main(int argc, char *argv[]) {
    // argc：命令行参数的个数（含程序名本身）
    // argv：字符串数组，依次存放程序名和各参数
    for (int i = 0; i < argc; i++) {
        printf("argv[%d] = %s\n", i, argv[i]);
    }
    return 0;
}

// 形式 4：void main（不符合 C 标准，不推荐）
void main(void) {  // 不符合 C 标准，不应使用
}
```

> **注意**：C 标准规定 `main` 函数应返回 `int`，`return 0;` 表示程序正常结束。`void main` 虽在某些老教材中出现，但不符合 C 标准，建议不要使用。

## 库函数与自定义函数

### 库函数

库函数是系统预先定义好的函数，编译器已经给出函数原型，只需用 `#include` 引入对应头文件即可直接调用。

| 头文件 | 常用函数 | 功能 |
|--------|----------|------|
| `stdio.h` | `printf`、`scanf`、`getchar`、`puts` | 输入输出 |
| `string.h` | `strlen`、`strcpy`、`strcmp` | 字符串处理 |
| `math.h` | `sqrt`、`pow`、`fabs`、`floor` | 数学运算 |
| `stdlib.h` | `malloc`、`free`、`rand`、`exit` | 内存分配、随机数等 |

```c
#include <stdio.h>
#include <math.h>

int main(void) {
    double x = 16.0;
    printf("sqrt(16) = %f\n", sqrt(x));  // 库函数，无需自己实现
    return 0;
}
```

### 自定义函数

自定义函数是用户根据需求自己编写的函数，必须**先声明（或先定义）再调用**。

| 对比项 | 库函数 | 自定义函数 |
|--------|--------|-----------|
| 来源 | 系统提供 | 用户编写 |
| 声明 | 头文件中已声明 | 需用户自行声明 |
| 使用 | 直接调用 | 先声明再调用 |
| 例子 | `printf`、`sqrt` | 自己编写的 `add`、`max` |

## 函数的最佳实践

1. **函数应只做一件事**（单一职责原则）
2. **函数名应清晰表达其功能**
3. **参数个数不宜过多**（一般不超过 5 个）
4. **使用 `const` 保护不修改的参数**
5. **始终检查返回值**（尤其是可能失败的函数）
6. **使用头文件声明函数**
