# 字符数组与字符串

## 字符串结束标志 `'\0'`

### 基本概念

在 C 语言中，字符串是以空字符 `'\0'`（ASCII 码值为 0）结尾的字符数组。`'\0'` 是字符串的结束标志，不可见但占用一个字节。

```c
char str[] = "Hello";
```

内存布局：

```
'H' 'e' 'l' 'l' 'o' '\0'
 0    1    2    3    4    5
```

`sizeof(str)` 的结果是 6（包含 `'\0'`），而 `strlen(str)` 的结果是 5（不包含 `'\0'`）。

### 字符串与字符数组的区别

```c
// 字符串（自动添加 '\0'）
char str1[] = "Hello";  // 长度 6

// 字符数组（不自动添加 '\0'）
char str2[] = {'H', 'e', 'l', 'l', 'o'};  // 长度 5，不是字符串
```

## 字符串输入输出

### `gets` 和 `fgets`

#### `gets`（已废弃，不应使用）

```c
char buf[100];
gets(buf);  // 不检查缓冲区大小，存在缓冲区溢出风险
```

`gets` 已被 C11 标准移除，不应在任何代码中使用。需要输入单个字符（包括空格和换行）时，可用 `getchar()`，它的返回值是 `int`（以便返回 `EOF`），例如 `int c = getchar();`。

#### `fgets`（推荐）

```c
char buf[100];
fgets(buf, sizeof(buf), stdin);  // 安全，最多读取 sizeof(buf)-1 个字符

// fgets 会保留换行符，需要手动去除
size_t len = strlen(buf);
if (len > 0 && buf[len - 1] == '\n') {
    buf[len - 1] = '\0';
}
```

### `puts` 和 `fputs`

#### `puts`

```c
puts("Hello");  // 输出字符串并自动添加换行
```

#### `fputs`

```c
fputs("Hello", stdout);  // 输出字符串，不自动添加换行
fputs("Hello\n", stdout);  // 手动添加换行
```

## 标准库 `<string.h>` 常用函数

### `strlen` — 计算字符串长度

```c
#include <string.h>

char str[] = "Hello";
size_t len = strlen(str);  // 返回 5（不包含 '\0'）
```

#### 实现原理

```c
size_t my_strlen(const char *s) {
    size_t count = 0;
    while (s[count] != '\0') {
        count++;
    }
    return count;
}
```

### `strcpy` — 字符串复制

```c
char dest[50];
char src[] = "Hello, World!";
strcpy(dest, src);  // 将 src 复制到 dest
```

#### 注意事项

- 目标缓冲区必须足够大
- 会复制 `'\0'`
- 不检查缓冲区大小，存在溢出风险

#### 安全替代：`strncpy`

```c
strncpy(dest, src, sizeof(dest) - 1);
dest[sizeof(dest) - 1] = '\0';  // 确保以 '\0' 结尾
```

### `strcat` — 字符串连接

```c
char dest[50] = "Hello";
char src[] = " World";
strcat(dest, src);  // dest = "Hello World"
```

#### 注意事项

- 目标缓冲区必须足够大以容纳连接后的字符串
- 会覆盖目标字符串末尾的 `'\0'`

#### 安全替代：`strncat`

```c
strncat(dest, src, sizeof(dest) - strlen(dest) - 1);
```

### `strcmp` — 字符串比较

```c
int result = strcmp("abc", "abd");

// 返回值：
// < 0  : 第一个字符串小于第二个字符串
// 0    : 两个字符串相等
// > 0  : 第一个字符串大于第二个字符串
```

#### 实现原理

```c
int my_strcmp(const char *s1, const char *s2) {
    while (*s1 && (*s1 == *s2)) {
        s1++;
        s2++;
    }
    return *(unsigned char *)s1 - *(unsigned char *)s2;
}
```

### `strncmp` — 限制长度的字符串比较

```c
int result = strncmp("abc", "abd", 2);  // 只比较前 2 个字符
```

## 字符串输入输出完整示例

```c
#include <stdio.h>
#include <string.h>

int main(void) {
    char name[50];

    // 输入
    printf("请输入姓名：");
    fgets(name, sizeof(name), stdin);

    // 去除换行符
    size_t len = strlen(name);
    if (len > 0 && name[len - 1] == '\n') {
        name[len - 1] = '\0';
    }

    // 输出
    printf("你好，%s！\n", name);
    printf("姓名长度：%zu\n", strlen(name));

    // 字符串操作
    char greeting[100];
    strcpy(greeting, "Hello, ");
    strcat(greeting, name);
    printf("%s\n", greeting);

    // 字符串比较
    if (strcmp(name, "Alice") == 0) {
        printf("你好，Alice！\n");
    }

    return 0;
}
```

## 字符串与指针

### 字符指针

```c
char *str = "Hello";  // 指向字符串常量的指针
```

字符串常量存储在只读内存中，不能通过指针修改。

```c
char *str = "Hello";
// str[0] = 'h';  // 错误！可能导致段错误
```

### 字符数组

```c
char str[] = "Hello";  // 可修改的字符数组
str[0] = 'h';  // 正确
```

### 字符指针 vs 字符数组

| 特性 | 字符指针 | 字符数组 |
|------|----------|----------|
| 存储位置 | 指向只读内存 | 栈上可写内存 |
| 可修改性 | 不可修改内容 | 可修改内容 |
| 大小 | 指针大小（8 字节） | 字符串长度 + 1 |
| 初始化 | `char *s = "Hello"` | `char s[] = "Hello"` |

## 字符串常见操作

### 字符串反转

```c
void reverse_string(char *str) {
    int len = strlen(str);
    for (int i = 0; i < len / 2; i++) {
        char temp = str[i];
        str[i] = str[len - 1 - i];
        str[len - 1 - i] = temp;
    }
}
```

### 字符串查找

```c
char *strchr(const char *s, int c);  // 查找字符首次出现的位置
char *strrchr(const char *s, int c); // 查找字符最后一次出现的位置
char *strstr(const char *haystack, const char *needle);  // 查找子串
```

### 字符串分割

```c
char str[] = "apple,banana,cherry";
char *token = strtok(str, ",");

while (token != NULL) {
    printf("%s\n", token);
    token = strtok(NULL, ",");
}
```

## 字符串常见错误

1. **忘记 `'\0'`**：手动构造字符串时忘记添加结束符
2. **缓冲区溢出**：字符串操作超出缓冲区大小
3. **使用 `gets`**：已废弃且不安全
4. **修改字符串常量**：通过指针修改只读内存中的字符串
5. **未检查 `NULL` 指针**：对空指针调用字符串函数
6. **用 `==` 比较字符串内容**：`str1 == str2` 比较的是两个字符串的**首地址**而非内容，比较内容应使用 `strcmp`
