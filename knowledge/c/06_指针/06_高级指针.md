# 高级指针

## 二级指针（多级指针）

### 基本概念

二级指针是指向指针的指针。

```c
int x = 10;
int *p = &x;    // 一级指针，存储 x 的地址
int **pp = &p;  // 二级指针，存储 p 的地址
```

### 解引用

```c
int x = 10;
int *p = &x;
int **pp = &p;

printf("x = %d\n", x);       // 输出 10
printf("*p = %d\n", *p);     // 输出 10
printf("**pp = %d\n", **pp); // 输出 10
```

### 地址关系

```
x 的地址：0x1000，值：10
p 的地址：0x2000，值：0x1000（指向 x）
pp 的地址：0x3000，值：0x2000（指向 p）
```

### 二级指针作为函数参数

#### 修改指针本身

```c
void allocate_memory(int **ptr) {
    *ptr = (int *)malloc(sizeof(int));
    **ptr = 42;
}

int main(void) {
    int *p = NULL;
    allocate_memory(&p);
    printf("*p = %d\n", *p);  // 输出 42
    free(p);
    return 0;
}
```

#### 修改字符串指针

```c
void set_string(char **str) {
    *str = "New String";
}

int main(void) {
    char *s = "Old String";
    set_string(&s);
    printf("%s\n", s);  // 输出 "New String"
    return 0;
}
```

### 二级指针与字符串数组

```c
char *names[] = {"Alice", "Bob", "Charlie"};
char **pp = names;

for (int i = 0; i < 3; i++) {
    printf("%s\n", pp[i]);  // 等价于 *(pp + i)
}
```

### 三级指针

```c
int x = 10;
int *p = &x;
int **pp = &p;
int ***ppp = &pp;

printf("***ppp = %d\n", ***ppp);  // 输出 10
```

## 指针数组与数组指针

### 指针数组：`int *arr[N]`

指针数组是一个数组，**每个元素都是指针**。常用于处理多个字符串或一维数组。

```c
int a = 1, b = 2, c = 3;
int *arr[3] = {&a, &b, &c};   // 3 个 int* 组成的数组

char *strs[3] = {"abc", "def", "ghi"};  // 3 个字符指针
```

### 数组指针：`int (*arr)[N]`

数组指针是一个指针，**指向一个数组**。

```c
int matrix[3][4];
int (*p)[4] = matrix;   // p 是指向"包含 4 个 int 的数组"的指针
```

### 区分口诀

看 `*` 与 `[]` 的**结合优先级**：`[]` 优先级高于 `*`。

```c
int *arr[3];    // arr 先与 [] 结合，是数组；元素是 int*  → 指针数组
int (*arr)[3];  // arr 先与 * 结合，是指针；指向 int[3] → 数组指针
```

### 用指针数组处理多个字符串（谭浩强经典例题）

用指针数组存放若干字符串，配合排序实现"按字母顺序输出月份"等：

```c
#include <stdio.h>
#include <string.h>

void sort_strings(char *strs[], int n) {
    // 冒泡排序：只交换指针，不移动字符串内容
    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < n - 1 - i; j++) {
            if (strcmp(strs[j], strs[j + 1]) > 0) {
                char *temp = strs[j];
                strs[j] = strs[j + 1];
                strs[j + 1] = temp;
            }
        }
    }
}

int main(void) {
    char *months[] = {"January", "February", "March", "April",
                      "May", "June", "July", "August",
                      "September", "October", "November", "December"};
    int n = 12;

    sort_strings(months, n);

    for (int i = 0; i < n; i++) {
        printf("%s\n", months[i]);
    }
    return 0;
}
```

> **注意**：排序时**只交换指针变量**（几个月字节），而不是整体移动字符串，效率很高。这是指针数组相对二维字符数组的重要优势。

### 指向常量的指针

```c
const int *p;
// p 指向的值不能通过 p 修改，但 p 本身可以指向其他地址
```

```c
int x = 10, y = 20;
const int *p = &x;
// *p = 20;  // 错误！不能修改指向的值
p = &y;      // 正确，可以改变指针指向
```

### 常量指针

```c
int *const p;
// p 本身不能改变指向，但可以通过 p 修改指向的值
```

```c
int x = 10, y = 20;
int *const p = &x;
*p = 20;  // 正确，可以修改 x 的值
// p = &y;  // 错误！不能改变指针指向
```

### 指向常量的常量指针

```c
const int *const p;
// 都不能修改
```

```c
int x = 10;
const int *const p = &x;
// *p = 20;  // 错误！
// p = &y;    // 错误！
```

### const 与指针的记忆口诀

```
const int *p;     // 指向常量的指针（*const）
int *const p;     // 常量指针（p const）
const int *const p;  // 指向常量的常量指针（*const, p const）
```

**记忆方法**：`const` 修饰的是它左边的内容，如果 `const` 在 `*` 左边，则指向的值是常量；如果 `const` 在 `*` 右边，则指针本身是常量。

### const 在函数参数中的应用

```c
// 保护不修改的输入参数
void print_string(const char *str) {
    printf("%s\n", str);
}

// 保护不修改的数组参数
void print_array(const int *arr, int size) {
    for (int i = 0; i < size; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");
}
```

## void 指针

### 基本概念

`void*` 是一种通用指针类型，可以指向任何类型的数据。

```c
int x = 10;
double d = 3.14;
char c = 'A';

void *vp;

vp = &x;   // 指向 int
vp = &d;   // 指向 double
vp = &c;   // 指向 char
```

### void 指针的限制

1. **不能直接解引用**
   ```c
   void *vp = &x;
   // *vp = 20;  // 错误！void 指针不能直接解引用
   ```

2. **不能进行指针算术**
   ```c
   void *vp = &x;
   // vp++;  // 错误！void 指针不能进行算术运算
   ```

### void 指针的使用

必须先转换为具体类型的指针才能使用。

```c
int x = 10;
void *vp = &x;

// 转换为 int* 后解引用
printf("%d\n", *(int *)vp);  // 输出 10

// 转换为 int* 后进行算术运算
int *ip = (int *)vp;
ip++;
```

### void 指针的应用

#### 通用内存操作函数

```c
void *memset(void *s, int c, size_t n);
void *memcpy(void *dest, const void *src, size_t n);
void *memmove(void *dest, const void *src, size_t n);
int memcmp(const void *s1, const void *s2, size_t n);
```

#### 通用比较函数

```c
typedef int (*CompareFunc)(const void *, const void *);
```

## 函数指针与 const

### const 修饰函数指针

```c
// 函数指针本身是 const（不能指向其他函数）
int (*const func_ptr)(int, int) = add;

// 函数指针指向的函数返回值是 const
const int *(*func_ptr)(int, int);
```

## 指针与 volatile

### volatile 关键字

`volatile` 告诉编译器不要优化对该变量的访问。

```c
volatile int *p;  // 指向 volatile int 的指针
int *volatile p;  // volatile 指针指向 int
```

### 应用场景

1. **硬件寄存器访问**
2. **中断服务程序中使用的变量**
3. **多线程共享变量**

```c
volatile int *hardware_reg = (volatile int *)0xFFFF0000;
*hardware_reg = 1;  // 不会被编译器优化掉
```

## 指针与 restrict（C99）

### restrict 关键字

`restrict` 告诉编译器指针是访问某块内存的唯一方式，允许编译器进行优化。

```c
void add_arrays(int *restrict dst, const int *restrict src, int n) {
    for (int i = 0; i < n; i++) {
        dst[i] = src[i];
    }
}
```

### restrict 的含义

- `dst` 和 `src` 指向的内存区域不重叠
- 编译器可以据此进行优化

## 指针与 _Generic（C11）

### _Generic 关键字

`_Generic` 允许根据类型选择不同的表达式。

```c
#include <stdio.h>

#define print_value(x) _Generic((x), \
    int: print_int, \
    double: print_double, \
    char*: print_string \
)(x)

void print_int(int x) { printf("int: %d\n", x); }
void print_double(double x) { printf("double: %f\n", x); }
void print_string(char *s) { printf("string: %s\n", s); }

int main(void) {
    print_value(42);        // 输出 int: 42
    print_value(3.14);      // 输出 double: 3.140000
    print_value("Hello");   // 输出 string: Hello
    return 0;
}
```

## 高级指针的综合示例

### 动态二维数组

```c
#include <stdio.h>
#include <stdlib.h>

int **create_matrix(int rows, int cols) {
    int **matrix = (int **)malloc(rows * sizeof(int *));
    if (matrix == NULL) {
        return NULL;
    }

    for (int i = 0; i < rows; i++) {
        matrix[i] = (int *)malloc(cols * sizeof(int));
        if (matrix[i] == NULL) {
            // 清理已分配的内存
            for (int j = 0; j < i; j++) {
                free(matrix[j]);
            }
            free(matrix);
            return NULL;
        }
    }

    return matrix;
}

void free_matrix(int **matrix, int rows) {
    for (int i = 0; i < rows; i++) {
        free(matrix[i]);
    }
    free(matrix);
}

int main(void) {
    int **matrix = create_matrix(3, 4);
    if (matrix == NULL) {
        return 1;
    }

    // 初始化
    for (int i = 0; i < 3; i++) {
        for (int j = 0; j < 4; j++) {
            matrix[i][j] = i * 4 + j;
        }
    }

    // 打印
    for (int i = 0; i < 3; i++) {
        for (int j = 0; j < 4; j++) {
            printf("%3d ", matrix[i][j]);
        }
        printf("\n");
    }

    free_matrix(matrix, 3);
    return 0;
}
```

## 指针常见错误总结

1. **野指针**：未初始化或已释放的指针
2. **空指针解引用**：对 NULL 指针解引用
3. **越界访问**：指针超出数组范围
4. **类型不匹配**：强制转换导致数据错误
5. **内存泄漏**：忘记释放动态分配的内存
6. **重复释放**：对同一块内存多次调用 free
7. **返回局部变量指针**：函数返回后内存已释放
