# 指针与函数

## 指针作为函数参数

### 基本概念

通过指针作为函数参数，可以在函数内部修改调用者的变量。

### 值传递 vs 地址传递

```c
// 值传递：无法修改原始变量
void modify_value(int x) {
    x = 100;
}

// 地址传递：可以修改原始变量
void modify_address(int *x) {
    *x = 100;
}

int main(void) {
    int a = 5;

    modify_value(a);
    printf("值传递后 a = %d\n", a);  // 输出 5

    modify_address(&a);
    printf("地址传递后 a = %d\n", a);  // 输出 100

    return 0;
}
```

### 交换两个变量

```c
#include <stdio.h>

void swap(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

int main(void) {
    int x = 1, y = 2;
    printf("交换前：x = %d, y = %d\n", x, y);
    swap(&x, &y);
    printf("交换后：x = %d, y = %d\n", x, y);
    return 0;
}
```

### 通过指针返回多个值

```c
#include <stdio.h>

void divide(int a, int b, int *quotient, int *remainder) {
    *quotient = a / b;
    *remainder = a % b;
}

int main(void) {
    int q, r;
    divide(17, 5, &q, &r);
    printf("17 / 5 = %d ... %d\n", q, r);  // 输出 3 ... 2
    return 0;
}
```

## 函数指针（回调机制）

### 基本概念

函数指针存储的是函数的地址，可以像调用函数一样通过函数指针调用函数。

### 定义与使用

```c
// 定义函数指针类型
int (*func_ptr)(int, int);

// 指向函数的指针
int add(int a, int b) {
    return a + b;
}

int main(void) {
    func_ptr = add;  // 将函数地址赋给指针

    int result = func_ptr(3, 5);  // 通过函数指针调用函数
    printf("3 + 5 = %d\n", result);  // 输出 8

    return 0;
}
```

### 函数指针的声明

```c
// 直接声明
int (*p)(int, int);

// 使用 typedef 简化
typedef int (*BinaryOp)(int, int);
BinaryOp op = add;
```

### 回调函数

函数指针最常见的用途是实现回调机制。

```c
#include <stdio.h>

// 回调函数类型
typedef void (*Callback)(int);

// 注册回调函数
void register_callback(Callback cb) {
    cb(42);  // 调用回调函数
}

// 回调函数实现
void on_event(int value) {
    printf("事件触发，值 = %d\n", value);
}

int main(void) {
    register_callback(on_event);  // 注册回调
    return 0;
}
```

### 回调函数的应用：排序

```c
#include <stdio.h>

// 比较函数类型
typedef int (*CompareFunc)(const void *, const void *);

// 冒泡排序（使用回调）
void bubble_sort(void *arr, int n, int elem_size, CompareFunc cmp) {
    char *base = (char *)arr;
    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < n - 1 - i; j++) {
            char *a = base + j * elem_size;
            char *b = base + (j + 1) * elem_size;
            if (cmp(a, b) > 0) {
                // 交换
                for (int k = 0; k < elem_size; k++) {
                    char temp = a[k];
                    a[k] = b[k];
                    b[k] = temp;
                }
            }
        }
    }
}

// 整数比较函数
int compare_int(const void *a, const void *b) {
    return *(int *)a - *(int *)b;
}

int main(void) {
    int arr[] = {5, 2, 8, 1, 9};
    int n = 5;

    bubble_sort(arr, n, sizeof(int), compare_int);

    for (int i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");

    return 0;
}
```

## 指针函数（返回指针的函数）

### 基本概念

指针函数是返回指针的函数。

### 语法

```c
返回类型 *函数名(参数列表) {
    // ...
}
```

> **注意**：函数指针（`int (*p)(int, int)`）与指针函数（`int *func(int)`）容易混淆。**括号位置**是区分关键：`(*p)` 先结合说明 `p` 是指针，指向函数；`int *func` 说明 `func` 返回 `int *`。

### 示例

```c
#include <stdio.h>
#include <stdlib.h>

// 返回指向动态分配内存的指针
int *create_array(int size) {
    int *arr = (int *)malloc(size * sizeof(int));
    if (arr != NULL) {
        for (int i = 0; i < size; i++) {
            arr[i] = i * 10;
        }
    }
    return arr;
}

// 返回静态变量的指针
int *get_static_value(void) {
    static int value = 42;
    return &value;
}

// 返回字符串常量指针
char *get_greeting(void) {
    return "Hello, World!";
}

int main(void) {
    // 使用返回的指针
    int *arr = create_array(5);
    if (arr != NULL) {
        for (int i = 0; i < 5; i++) {
            printf("arr[%d] = %d\n", i, arr[i]);
        }
        free(arr);
    }

    int *p = get_static_value();
    printf("静态值 = %d\n", *p);

    char *greeting = get_greeting();
    printf("%s\n", greeting);

    return 0;
}
```

### 危险：返回局部变量的指针

```c
int *bad_func(void) {
    int arr[5] = {1, 2, 3, 4, 5};
    return arr;  // 错误！arr 是局部变量，函数结束后内存被释放
}
```

## 函数指针数组

### 基本概念

函数指针数组是存储多个函数指针的数组。

### 示例：简单计算器

```c
#include <stdio.h>

int add(int a, int b) { return a + b; }
int subtract(int a, int b) { return a - b; }
int multiply(int a, int b) { return a * b; }
int divide(int a, int b) { return b != 0 ? a / b : 0; }

int main(void) {
    // 函数指针数组
    int (*operations[])(int, int) = {add, subtract, multiply, divide};
    const char *names[] = {"加法", "减法", "乘法", "除法"};

    int a = 10, b = 5;
    for (int i = 0; i < 4; i++) {
        printf("%s: %d\n", names[i], operations[i](a, b));
    }

    return 0;
}
```

### 用函数指针数组改写 switch 计算器

谭浩强教材中的计算器通常用 `switch` 分支实现，可以用函数指针数组简化：

```c
// switch 写法：每多一种运算就要加一个 case 分支
switch (op) {
    case '+': result = a + b; break;
    case '-': result = a - b; break;
    case '*': result = a * b; break;
    case '/': result = a / b; break;
}

// 函数指针数组写法：函数和运算符按下标一一对应
int (*operations[4])(int, int) = {add, subtract, multiply, divide};
char ops[] = {'+', '-', '*', '/'};

char op;
scanf("%d %c %d", &a, &op, &b);
for (int i = 0; i < 4; i++) {
    if (op == ops[i]) {
        result = operations[i](a, b);
        break;
    }
}
```

**优点**：新增运算只需往数组里加一个函数，代码更易扩展、更好维护。

## 指向函数指针的指针

```c
int add(int a, int b) { return a + b; }

int main(void) {
    int (*func_ptr)(int, int) = add;
    int (**func_ptr_ptr)(int, int) = &func_ptr;

    // 通过二级函数指针调用函数
    int result = (*func_ptr_ptr)(3, 5);
    printf("3 + 5 = %d\n", result);

    return 0;
}
```

## typedef 与函数指针

### 简化函数指针声明

```c
// 原始声明
int (*func_ptr)(int, int);

// 使用 typedef 简化
typedef int (*BinaryOp)(int, int);
BinaryOp op = add;
```

### 回调函数的类型定义

```c
typedef void (*EventCallback)(int event_id);
typedef int (*CompareFunc)(const void *a, const void *b);
typedef double (*MathFunc)(double x);
```

## 指针与函数的最佳实践

1. **使用 `const` 保护不修改的数据**
2. **检查函数指针是否为 NULL 后再调用**
3. **使用 typedef 简化函数指针声明**
4. **避免返回局部变量的指针**
5. **使用函数指针实现回调和策略模式**
6. **在 API 设计中使用函数指针实现扩展性**
