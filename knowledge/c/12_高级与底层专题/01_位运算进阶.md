# 位运算进阶

## 六种位运算符

C 语言共提供 6 种位运算符，操作对象是整型数据（`char`、`int`、`unsigned` 等）的二进制位：

| 运算符 | 含义 | 示例 | 结果 |
|--------|------|------|------|
| `&` | 按位与 | `0b1010 & 0b1100` | `0b1000` |
| `\|` | 按位或 | `0b1010 \| 0b1100` | `0b1110` |
| `^` | 按位异或 | `0b1010 ^ 0b1100` | `0b0110` |
| `~` | 按位取反 | `~0b1010` | `0b0101`（对 4 位而言） |
| `<<` | 左移 | `0b0001 << 2` | `0b0100` |
| `>>` | 右移 | `0b1000 >> 2` | `0b0010` |

注意：在 Markdown 表格中 `|` 需要写作 `\|` 才能正确显示。

```c
#include <stdio.h>

int main(void) {
    unsigned char a = 0b1010;   // 10
    unsigned char b = 0b1100;   // 12

    printf("a & b  = %u\n", a & b);   // 0b1000 = 8
    printf("a | b  = %u\n", a | b);   // 0b1110 = 14
    printf("a ^ b  = %u\n", a ^ b);   // 0b0110 = 6
    printf("~a     = %u\n", ~a);      // 对 8 位而言 0b11110101 = 245
    printf("a << 2 = %u\n", a << 2);  // 0b101000 = 40
    printf("a >> 2 = %u\n", a >> 2);  // 0b0010 = 2
    return 0;
}
```

> **注意**：位运算符中，`&`、`|`、`^` 的优先级都低于关系（比较）运算符，例如 `x & 0xF0 == 0x80` 实际会先执行 `0xF0 == 0x80`，务必加括号：`(x & 0xF0) == 0x80`。详见下文"位运算的优先级"一节。

## 掩码操作

### 基本概念

掩码（Mask）是一个二进制数，用于选择、设置、清除或翻转特定位。

### 常见掩码操作

#### 设置位（置 1）

使用按位或 `|` 运算符将特定位设置为 1。

```c
// 将第 n 位置 1
value |= (1 << n);

// 示例：将第 3 位置 1
unsigned char flags = 0b00000000;  // 0x00
flags |= (1 << 3);                  // 0b00001000 = 0x08
```

#### 清除位（置 0）

使用按位与 `&` 和按位取反 `~` 运算符将特定位清除为 0。

```c
// 将第 n 位清 0
value &= ~(1 << n);

// 示例：将第 3 位清 0
unsigned char flags = 0b00001111;  // 0x0F
flags &= ~(1 << 3);                // 0b00000111 = 0x07
```

#### 翻转位

使用按位异或 `^` 运算符翻转特定位。

```c
// 翻转第 n 位
value ^= (1 << n);

// 示例：翻转第 3 位
unsigned char flags = 0b00001000;  // 0x08
flags ^= (1 << 3);                  // 0b00000000 = 0x00
```

#### 检查位

使用按位与 `&` 运算符检查特定位是否为 1。

```c
// 检查第 n 位是否为 1
if (value & (1 << n)) {
    // 第 n 位为 1
}

// 示例：检查第 3 位
unsigned char flags = 0b00001000;  // 0x08
if (flags & (1 << 3)) {
    printf("第 3 位为 1\n");
}
```

### 多位掩码操作

```c
// 设置多个位
flags |= (1 << 2) | (1 << 4);  // 设置第 2 位和第 4 位

// 清除多个位
flags &= ~((1 << 2) | (1 << 4));  // 清除第 2 位和第 4 位

// 翻转多个位
flags ^= (1 << 2) | (1 << 4);  // 翻转第 2 位和第 4 位

// 检查多个位是否都为 1
if ((flags & ((1 << 2) | (1 << 4))) == ((1 << 2) | (1 << 4))) {
    // 第 2 位和第 4 位都为 1
}
```

## 位字段（bit-field）

### 基本概念

位字段允许在结构体中指定成员占用的位数，常用于寄存器编程和协议解析。

### 语法

```c
struct {
    类型名 成员名 : 位数;
} 变量名;
```

### 示例

```c
// 寄存器位域定义
struct ControlRegister {
    unsigned int enable    : 1;  // 使能位
    unsigned int mode      : 2;  // 模式位
    unsigned int priority  : 3;  // 优先级位
    unsigned int reserved  : 2;  // 保留位
};

struct ControlRegister ctrl;
ctrl.enable = 1;
ctrl.mode = 2;
ctrl.priority = 5;
```

### 位字段的内存布局

```c
struct Flags {
    unsigned int read    : 1;  // 位 0
    unsigned int write   : 1;  // 位 1
    unsigned int execute : 1;  // 位 2
    unsigned int         : 5;  // 5 位填充（无名位字段）
};
// sizeof(struct Flags) = 4 字节（32 位）
```

### 位字段的应用：IP 地址解析

```c
struct IPHeader {
    unsigned int version : 4;  // IP 版本（4 位）
    unsigned int ihl     : 4;  // 首部长度（4 位）
    unsigned int dscp    : 6;  // 差分服务代码点（6 位）
    unsigned int ecn     : 2;  // 显式拥塞通知（2 位）
};

struct IPHeader header;
header.version = 4;
header.ihl = 5;
header.dscp = 46;  // EF 转发
header.ecn = 0;
```

### 位字段的注意事项

1. **位字段的布局依赖于编译器和平台**
2. **位字段不能是 `static` 或 `extern`**
3. **位字段不能是数组**
4. **无名位字段用于填充**
5. **位字段的大小不能超过其类型的位宽**

## 位运算的应用场景

### 1. 权限管理

```c
#define READ    (1 << 0)   // 0b001
#define WRITE   (1 << 1)   // 0b010
#define EXECUTE (1 << 2)   // 0b100
#define DELETE  (1 << 3)   // 0b1000

int permissions = READ | WRITE;  // 读写权限

// 检查权限
if (permissions & READ) {
    printf("有读权限\n");
}

// 添加权限
permissions |= EXECUTE;

// 移除权限
permissions &= ~WRITE;
```

### 2. 状态标志

```c
#define STATE_IDLE      (1 << 0)
#define STATE_RUNNING   (1 << 1)
#define STATE_PAUSED    (1 << 2)
#define STATE_ERROR     (1 << 3)

int state = STATE_IDLE;

// 设置状态
state |= STATE_RUNNING;

// 清除状态
state &= ~STATE_RUNNING;

// 切换状态
state ^= STATE_PAUSED;

// 检查状态
if (state & STATE_RUNNING) {
    printf("正在运行\n");
}
```

### 3. 颜色操作

```c
// RGB 颜色：每通道 8 位
#define RED_MASK   0xFF0000
#define GREEN_MASK 0x00FF00
#define BLUE_MASK  0x0000FF

unsigned int color = 0xFF5733;  // RGB(255, 87, 51)

// 提取各通道
unsigned int red   = (color & RED_MASK) >> 16;
unsigned int green = (color & GREEN_MASK) >> 8;
unsigned int blue  = (color & BLUE_MASK);

// 合成颜色
unsigned int new_color = (red << 16) | (green << 8) | blue;
```

### 4. 哈希函数

```c
unsigned int hash(const char *str) {
    unsigned int hash = 5381;
    int c;

    while ((c = *str++) != 0) {
        hash = ((hash << 5) + hash) + c;  // hash * 33 + c
    }

    return hash;
}
```

### 5. 交换变量（不使用临时变量）

```c
int a = 5, b = 10;
a ^= b;
b ^= a;
a ^= b;
// 现在 a = 10, b = 5
```

### 6. 判断奇偶

利用最低位判断：偶数的最低位为 0，奇数的最低位为 1。

```c
// 判断 n 是否为偶数
int is_even(int n) {
    return (n & 1) == 0;
}

// 判断 n 是否为奇数
int is_odd(int n) {
    return n & 1;   // 返回 1 表示奇数
}
```

### 7. 取某一位的值

```c
// 取出第 n 位的值（0 或 1）
int get_bit(unsigned int value, int n) {
    return (value >> n) & 1;
}

// 示例：取 0b10110010 的第 5 位
// 0b10110010 >> 5 = 0b101，& 1 = 1
```

## 算术右移与逻辑右移

`>>` 右移分为两种：

| 类型 | 适用对象 | 最高位填充 | 结果 |
|------|----------|------------|------|
| 逻辑右移 | 无符号数 | 高位补 0 | `1000 0000 >> 1 = 0100 0000` |
| 算术右移 | 有符号正数 | 高位补 0 | 同逻辑右移 |
| 算术右移 | 有符号负数 | 高位补符号位（1） | `1000 0000 >> 1 = 1100 0000` |

```c
#include <stdio.h>

int main(void) {
    unsigned char u = 0b10000000;   // 128
    signed char   s = -128;         // 0b10000000（二进制补码）

    // 无符号数：逻辑右移，高位补 0
    printf("u >> 1 = %u\n", u >> 1);      // 64（高位补 0）

    // 有符号负数：算术右移，高位补符号位 1
    printf("s >> 1 = %d\n", s >> 1);      // -64（高位补 1）

    return 0;
}
```

> **注意**：对负的有符号数做右移是**实现相关**的行为（绝大多数编译器采用算术右移）。C 语言标准只保证：无符号数的右移是逻辑右移；正有符号数的右移结果相当于除以 2 的幂。因此用 `>>` 模拟除法时，请只对无符号数或正数使用。

## 位运算的优先级

位运算符的优先级**都低于比较（关系）运算符和算术运算符**，很多初学者在这里出错。

从高到低依次为（仅列相关部分）：

| 优先级 | 运算符 |
|--------|--------|
| 高 | `<<` `>>`（移位） |
| | `&`（按位与） |
| | `^`（按位异或） |
| | `|`（按位或） |
| | `<` `>` `==` `!=`（比较） |
| 低 | `&&` `||`（逻辑与、逻辑或） |

常见的错误写法：

```c
// 错误：先计算 0xF0 == 0x80（结果为 0），再 x & 0，恒为 0
if (x & 0xF0 == 0x80) { ... }

// 正确：必须加括号
if ((x & 0xF0) == 0x80) { ... }
```

> **注意**：`&`、`|`、`^` 的优先级甚至低于 `==`、`!=`，所以凡是位运算与比较混用的表达式，都要显式加括号，否则很容易写出与预期不符的代码。

## 位运算的优化技巧

### 乘除法优化

```c
// 乘以 2 的幂
x << n   // 等价于 x * (2^n)
x >> n   // 等价于 x / (2^n)（对无符号数和正有符号数）

// 示例
x << 1   // x * 2
x << 3   // x * 8
x >> 2   // x / 4
```

### 判断 2 的幂

```c
int is_power_of_two(unsigned int x) {
    return x != 0 && (x & (x - 1)) == 0;
}
```

### 获取最低有效位

```c
unsigned int lowest_bit(unsigned int x) {
    return x & (-x);
}
```

### 清除最低有效位

```c
unsigned int clear_lowest_bit(unsigned int x) {
    return x & (x - 1);
}
```

## 位字段在寄存器编程中的应用

### 硬件寄存器操作

```c
// 假设寄存器地址为 0x40000000
#define REG_CONTROL (*(volatile unsigned int *)0x40000000)

// 定义位域
#define CONTROL_ENABLE_BIT  0
#define CONTROL_MODE_BIT    1
#define CONTROL_PRIORITY_BIT 3

// 设置使能位
REG_CONTROL |= (1 << CONTROL_ENABLE_BIT);

// 清除使能位
REG_CONTROL &= ~(1 << CONTROL_ENABLE_BIT);

// 翻转使能位
REG_CONTROL ^= (1 << CONTROL_ENABLE_BIT);

// 检查使能位
if (REG_CONTROL & (1 << CONTROL_ENABLE_BIT)) {
    printf("外设已使能\n");
}
```

### 使用位字段访问寄存器

```c
typedef struct {
    unsigned int enable    : 1;
    unsigned int mode      : 2;
    unsigned int priority  : 3;
    unsigned int reserved  : 26;
} ControlReg;

#define REG_CONTROL (*(volatile ControlReg *)0x40000000)

REG_CONTROL.enable = 1;
REG_CONTROL.mode = 2;
REG_CONTROL.priority = 5;
```

## 可变参数函数

### stdarg.h 概述

`stdarg.h` 提供了处理可变参数列表的宏和类型。

### 基本用法

```c
#include <stdarg.h>

double average(int count, ...) {
    va_list args;
    va_start(args, count);

    double sum = 0;
    for (int i = 0; i < count; i++) {
        sum += va_arg(args, double);
    }

    va_end(args);
    return sum / count;
}
```

### va_list、va_start、va_arg、va_end

| 宏 | 说明 |
|------|------|
| `va_list` | 定义可变参数列表的类型 |
| `va_start(ap, last_fixed)` | 初始化 ap，使其指向第一个可变参数 |
| `va_arg(ap, type)` | 获取下一个参数，类型为 type |
| `va_end(ap)` | 清理 ap |

### 模拟 printf

```c
#include <stdio.h>
#include <stdarg.h>

int my_printf(const char *format, ...) {
    va_list args;
    va_start(args, format);

    int count = 0;
    while (*format) {
        if (*format == '%') {
            format++;
            switch (*format) {
                case 'd': {
                    int i = va_arg(args, int);
                    count += printf("%d", i);
                    break;
                }
                case 'f': {
                    double d = va_arg(args, double);
                    count += printf("%f", d);
                    break;
                }
                case 's': {
                    char *s = va_arg(args, char *);
                    count += printf("%s", s);
                    break;
                }
                case 'c': {
                    int c = va_arg(args, int);
                    count += printf("%c", c);
                    break;
                }
                default:
                    putchar('%');
                    putchar(*format);
                    count += 2;
                    break;
            }
        } else {
            putchar(*format);
            count++;
        }
        format++;
    }

    va_end(args);
    return count;
}
```

### 可变参数的限制

1. **必须至少有一个固定参数**
2. **无法自动确定可变参数的类型和数量**
3. **参数提升规则**：`char`/`short` 提升为 `int`，`float` 提升为 `double`
4. **类型安全**：编译器无法检查可变参数的类型
