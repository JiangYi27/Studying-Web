# 结构体（struct）

## 定义与声明

### 基本语法

```c
struct 结构体名 {
    成员1类型 成员1;
    成员2类型 成员2;
    // ...
};
```

### 示例

```c
struct Point {
    int x;
    int y;
};

struct Student {
    char name[50];
    int age;
    float score;
};
```

## 结构体变量的定义与初始化

### 定义结构体变量

```c
struct Point p1;              // 定义结构体变量
struct Point p2 = {3, 4};     // 定义并初始化
struct Point p3 = {.x = 5, .y = 6};  // 指定成员初始化（C99）
```

### 嵌套定义

```c
struct Rectangle {
    struct Point top_left;
    struct Point bottom_right;
    int width;
    int height;
};
```

## 成员访问

### 使用点运算符（`.`）

```c
struct Point p = {3, 4};
p.x = 10;
p.y = 20;
printf("(%d, %d)\n", p.x, p.y);
```

### 使用箭头运算符（`->`）

当通过指针访问结构体成员时，使用 `->` 运算符。

```c
struct Point p = {3, 4};
struct Point *ptr = &p;

ptr->x = 10;  // 等价于 (*ptr).x = 10;
ptr->y = 20;
printf("(%d, %d)\n", ptr->x, ptr->y);
```

### 点运算符与箭头运算符对比

```c
#include <string.h>

struct Student s = {"Alice", 20, 95.5};
struct Student *ps = &s;

// 点运算符（直接访问）
strcpy(s.name, "Bob");  // 数组成员不能整体赋值，需用 strcpy
s.age = 21;

// 箭头运算符（通过指针访问）
strcpy(ps->name, "Charlie");
ps->age = 22;
```

## 结构体数组

### 定义与初始化

```c
struct Student students[3] = {
    {"Alice", 20, 95.5},
    {"Bob", 21, 88.0},
    {"Charlie", 19, 92.5}
};
```

### 遍历结构体数组

```c
for (int i = 0; i < 3; i++) {
    printf("Name: %s, Age: %d, Score: %.1f\n",
           students[i].name, students[i].age, students[i].score);
}
```

### 使用指针遍历

```c
for (int i = 0; i < 3; i++) {
    struct Student *ps = &students[i];
    printf("Name: %s, Age: %d, Score: %.1f\n",
           ps->name, ps->age, ps->score);
}
```

## 结构体嵌套

```c
struct Date {
    int year;
    int month;
    int day;
};

struct Student {
    char name[50];
    struct Date birthday;
    float score;
};

int main(void) {
    struct Student s = {
        "Alice",
        {2003, 5, 15},
        95.5
    };

    printf("Name: %s\n", s.name);
    printf("Birthday: %d-%02d-%02d\n", s.birthday.year, s.birthday.month, s.birthday.day);
    printf("Score: %.1f\n", s.score);

    return 0;
}
```

## 结构体与函数

### 值传递

```c
void print_student(struct Student s) {
    printf("Name: %s, Age: %d\n", s.name, s.age);
}
```

### 指针传递（推荐）

```c
void print_student_ptr(const struct Student *s) {
    printf("Name: %s, Age: %d\n", s->name, s->age);
}
```

### 返回结构体

```c
struct Point create_point(int x, int y) {
    struct Point p = {x, y};
    return p;
}
```

### 传值与传地址对比

| 特性 | 传值（值传递） | 传地址（指针传递） |
|------|----------------|-------------------|
| 参数形式 | `struct Student s` | `const struct Student *s` |
| 复制开销 | 复制整个结构体 | 只复制一个指针 |
| 能否修改原结构体 | 不能（修改的是副本） | 能（通过指针修改） |
| 访问成员 | 用 `.` | 用 `->` |
| 适用场景 | 小结构体、只读 | 大结构体、需要修改 |

> **注意**：结构体较大时传值会复制整块内存（可能几十上百字节），传地址只复制一个指针（4/8 字节）。因此处理大型结构体时优先使用指针传递，并加 `const` 保护只读参数。

## 谭浩强经典例题：学生成绩表

《C程序设计》中通过**结构体数组**处理学生成绩的经典例题：输入 5 个学生的学号、姓名和 3 门课成绩，计算平均分并输出成绩表。

```c
#include <stdio.h>

#define N 5  // 学生人数

struct Student {
    int num;            // 学号
    char name[20];      // 姓名
    float score[3];     // 3 门课成绩
    float aver;         // 平均分
};

int main(void) {
    struct Student stu[N];
    int i, j;
    float sum;

    // 输入 5 个学生的信息
    for (i = 0; i < N; i++) {
        printf("请输入第 %d 个学生的学号、姓名、三门课成绩：\n", i + 1);
        scanf("%d%s", &stu[i].num, stu[i].name);
        sum = 0;
        for (j = 0; j < 3; j++) {
            scanf("%f", &stu[i].score[j]);
            sum += stu[i].score[j];
        }
        stu[i].aver = sum / 3;
    }

    // 输出学生成绩表
    printf("\n学号   姓名       成绩1   成绩2   成绩3   平均分\n");
    for (i = 0; i < N; i++) {
        printf("%5d  %-8s", stu[i].num, stu[i].name);
        for (j = 0; j < 3; j++) {
            printf("%7.1f", stu[i].score[j]);
        }
        printf("%8.1f\n", stu[i].aver);
    }

    return 0;
}
```

## typedef 与结构体的结合

结构体定义常与 `typedef` 结合使用，为结构体起一个"新类型名"，此后定义变量时不必再写 `struct` 关键字。

```c
// 一般写法：定义变量时要写 struct
struct Point {
    int x;
    int y;
};
struct Point p1 = {3, 4};

// 结合 typedef 的经典写法：直接用新类型名
typedef struct {
    int x;
    int y;
} Point;

Point p2 = {5, 6};    // 不必再写 struct
Point *ptr = &p2;     // 定义结构体指针也更简洁
```

> **注意**：`typedef struct { ... } 新类型名;` 把"定义结构体类型"与"起别名"合二为一，是工程中最常见的写法，详见本章"类型重定义"。

## 内存对齐与结构体大小计算

### 对齐规则

1. **结构体第一个成员的偏移量为 0**
2. **每个成员的偏移量必须是其大小的整数倍**（或编译器指定的对齐数）
3. **结构体的总大小必须是最大成员大小的整数倍**

### 示例分析

```c
struct Example1 {
    char a;    // 1 字节，偏移 0
    int b;     // 4 字节，偏移 4（需要 4 字节对齐）
    short c;   // 2 字节，偏移 8
};
// 总大小 = 12（最大成员 int 为 4 字节，12 是 4 的倍数）
```

```c
struct Example2 {
    char a;    // 1 字节，偏移 0
    char b;    // 1 字节，偏移 1
    char c;    // 1 字节，偏移 2
    int d;     // 4 字节，偏移 4（需要 4 字节对齐）
};
// 总大小 = 8（最大成员 int 为 4 字节，8 是 4 的倍数）
```

### 使用 offsetof 宏

```c
#include <stddef.h>

struct Example {
    char a;
    int b;
    short c;
};

printf("offsetof(a) = %zu\n", offsetof(struct Example, a));  // 0
printf("offsetof(b) = %zu\n", offsetof(struct Example, b));  // 4
printf("offsetof(c) = %zu\n", offsetof(struct Example, c));  // 8
printf("sizeof(struct Example) = %zu\n", sizeof(struct Example));  // 12
```

### 控制内存对齐

```c
#pragma pack(1)  // 1 字节对齐，取消填充
struct Packed {
    char a;    // 1 字节，偏移 0
    int b;     // 4 字节，偏移 1
    short c;   // 2 字节，偏移 5
};  // sizeof(struct Packed) = 7
#pragma pack()  // 恢复默认对齐
```

### 对齐的影响

```c
// 默认对齐（通常 8 字节）
struct Default {
    char a;    // 1 字节 + 7 字节填充
    int b;     // 4 字节
    char c;    // 1 字节 + 3 字节填充
};  // sizeof = 16

// 1 字节对齐
#pragma pack(1)
struct Packed {
    char a;    // 1 字节
    int b;     // 4 字节
    char c;    // 1 字节
};  // sizeof = 6
#pragma pack()
```

## 结构体位字段

位字段允许指定成员占用的位数，常用于寄存器编程和协议解析。

```c
struct Flags {
    unsigned int read    : 1;  // 1 位
    unsigned int write   : 1;  // 1 位
    unsigned int execute : 1;  // 1 位
    unsigned int         : 5;  // 5 位填充（无名位字段）
};

struct IPAddress {
    unsigned int version : 4;
    unsigned int ihl     : 4;
    unsigned int dscp    : 6;
    unsigned int ecn     : 2;
};
```

## 结构体最佳实践

1. **使用 `const` 保护不修改的结构体参数**
2. **使用指针传递大型结构体**（避免复制开销）
3. **注意内存对齐对性能的影响**
4. **使用 `offsetof` 宏计算成员偏移**
5. **使用位字段优化内存使用**
