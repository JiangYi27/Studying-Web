# 枚举（enum）

## 基本概念

枚举是一种用户自定义的整数类型，用于定义一组命名的常量。枚举提高了代码的可读性和可维护性。

## 定义与声明

### 基本语法

```c
enum 枚举名 {
    枚举常量1,
    枚举常量2,
    // ...
};
```

### 示例

```c
enum Color {
    RED,
    GREEN,
    BLUE
};

enum Status {
    SUCCESS,
    ERROR,
    UNKNOWN
};
```

## 枚举常量的值

### 默认值

枚举常量默认从 0 开始，依次递增。

```c
enum Color {
    RED,    // 0
    GREEN,  // 1
    BLUE    // 2
};
```

### 指定值

可以为枚举常量指定特定的值。

```c
enum Status {
    SUCCESS = 0,
    ERROR = 1,
    UNKNOWN = -1
};
```

### 部分指定值

未指定的常量从上一个常量的值开始递增。

```c
enum Status {
    SUCCESS = 0,
    ERROR,      // 1
    UNKNOWN = 5,
    TIMEOUT     // 6
};
```

## 枚举变量的使用

### 定义枚举变量

```c
enum Color color;
color = RED;
color = GREEN;
color = BLUE;
```

### 枚举变量与整数

枚举常量本质上是整数，可以与整数进行运算和比较，也可以直接用作 `switch` 的**整型常量**：

```c
enum Color color = RED;

// 比较
if (color == RED) {
    printf("红色\n");
}

// 赋值（隐式转换）
color = (enum Color)1;  // 等价于 color = GREEN;

// 与整数运算（不推荐）
int value = color + 1;  // value = 1
```

## 枚举与 #define 的对比

| 特性 | enum | #define |
|------|------|---------|
| 类型安全 | 有类型 | 无类型 |
| 调试 | 调试器可见 | 调试器不可见 |
| 作用域 | 遵循作用域规则 | 从定义处到文件结束 |
| 自动编号 | 支持 | 不支持 |
| 类型检查 | 编译器检查 | 无类型检查 |

## 枚举的优势

### 1. 类型安全

```c
enum Color { RED, GREEN, BLUE };
enum Color c = RED;

// 编译器会检查类型
// enum Color c = 5;  // 警告：整数赋值给枚举类型
```

### 2. 代码可读性

```c
// 使用枚举
enum Direction { NORTH, SOUTH, EAST, WEST };
enum Direction dir = NORTH;

// 使用 #define
#define DIR_NORTH 0
#define DIR_SOUTH 1
#define DIR_EAST 2
#define DIR_WEST 3
int dir = DIR_NORTH;
```

### 3. 调试友好

调试器可以显示枚举常量的名称，而不是整数值。

## 枚举的常见应用

### 状态机

```c
enum State {
    STATE_IDLE,
    STATE_RUNNING,
    STATE_PAUSED,
    STATE_STOPPED
};

enum State current_state = STATE_IDLE;

void handle_event(enum State state) {
    switch (state) {
        case STATE_IDLE:
            printf("空闲状态\n");
            break;
        case STATE_RUNNING:
            printf("运行状态\n");
            break;
        case STATE_PAUSED:
            printf("暂停状态\n");
            break;
        case STATE_STOPPED:
            printf("停止状态\n");
            break;
    }
}
```

### 错误码

```c
enum ErrorCode {
    ERR_NONE = 0,
    ERR_INVALID_INPUT,
    ERR_OUT_OF_MEMORY,
    ERR_FILE_NOT_FOUND,
    ERR_PERMISSION_DENIED
};

const char *error_message(enum ErrorCode code) {
    switch (code) {
        case ERR_NONE:
            return "无错误";
        case ERR_INVALID_INPUT:
            return "无效输入";
        case ERR_OUT_OF_MEMORY:
            return "内存不足";
        case ERR_FILE_NOT_FOUND:
            return "文件未找到";
        case ERR_PERMISSION_DENIED:
            return "权限不足";
        default:
            return "未知错误";
    }
}
```

### 选项标志

```c
enum Options {
    OPT_NONE = 0,
    OPT_VERBOSE = 1 << 0,
    OPT_DEBUG = 1 << 1,
    OPT_FORCE = 1 << 2
};

int options = OPT_VERBOSE | OPT_DEBUG;

if (options & OPT_VERBOSE) {
    printf("详细模式\n");
}
```

## 枚举与 typedef

使用 typedef 可以简化枚举类型的使用。

```c
typedef enum {
    RED,
    GREEN,
    BLUE
} Color;

Color c = RED;  // 不需要写 enum Color
```

## 枚举的注意事项

1. **枚举常量是 int 类型**
2. **枚举变量可以存储任何整数值**（不局限于定义的常量）
3. **枚举常量之间可以用 == 和 != 比较**
4. **枚举常量可以参与整数运算**（但不推荐）
5. **枚举的作用域取决于定义位置**（在函数外为文件作用域，在函数内为块作用域）
6. **枚举常量不是变量，不能赋值**：例如 `RED = 5;` 是错误的，只能在定义时通过 `RED = 5` 指定初始值
