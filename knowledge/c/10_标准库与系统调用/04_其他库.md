# 其他标准库

## string.h — 字符串库

### 字符串复制与连接

| 函数 | 说明 |
|------|------|
| `strcpy(dst, src)` | 复制字符串（含 `\0`，需保证 dst 空间足够） |
| `strncpy(dst, src, n)` | 复制最多 n 个字符 |
| `strcat(dst, src)` | 将 src 追加到 dst 末尾 |
| `strncat(dst, src, n)` | 追加最多 n 个字符 |

### 字符串比较与查找

| 函数 | 说明 |
|------|------|
| `strlen(s)` | 返回字符串长度（不含 `\0`） |
| `strcmp(s1, s2)` | 逐字节比较，返回 0 / 正数 / 负数 |
| `strncmp(s1, s2, n)` | 比较前 n 个字符 |
| `strchr(s, c)` | 查找字符 c 第一次出现的位置 |
| `strrchr(s, c)` | 查找字符 c 最后一次出现的位置 |
| `strstr(s1, s2)` | 查找子串 s2 在 s1 中出现的位置 |
| `strtok(s, delim)` | 按分隔符分割字符串 |

### 内存操作函数

| 函数 | 说明 |
|------|------|
| `memcpy(dst, src, n)` | 复制 n 字节（源和目标不能重叠） |
| `memmove(dst, src, n)` | 复制 n 字节（允许重叠） |
| `memset(ptr, c, n)` | 将前 n 字节都设置为 c |
| `memcmp(s1, s2, n)` | 比较前 n 字节 |

### 字符串复制示例

```c
#include <stdio.h>
#include <string.h>

int main(void) {
    char buf[50];

    strcpy(buf, "Hello");          // 复制
    strcat(buf, ", World!");       // 连接
    printf("%s\n", buf);           // Hello, World!

    printf("长度: %zu\n", strlen(buf));  // 13

    if (strcmp(buf, "Hello, World!") == 0) {
        printf("字符串相等\n");
    }

    char *p = strstr(buf, "World");  // 查找子串
    if (p != NULL) {
        printf("找到子串: %s\n", p);  // 从 World 开始输出
    }

    return 0;
}
```

### 使用 strtok 分割字符串

```c
#include <stdio.h>
#include <string.h>

int main(void) {
    char line[] = "Alice,20,95.5";

    char *token = strtok(line, ",");
    while (token != NULL) {
        printf("%s\n", token);
        token = strtok(NULL, ",");  // 后续调用传 NULL
    }

    return 0;
}
```

### 字符串安全

1. `strcpy`/`strcat` 不做边界检查，容易造成缓冲区溢出，优先使用 `strncpy`/`strncat` 并指定长度
2. `memcpy` 要求源和目标不重叠，可能重叠时必须用 `memmove`
3. `strtok` 会修改原字符串，且不是线程安全的

### 随机数函数

```c
#include <stdlib.h>

// 设置随机种子
srand((unsigned int)time(NULL));

// 生成随机数
int r = rand();  // 返回 0 到 RAND_MAX 之间的整数

// 生成指定范围的随机数
int random_in_range(int min, int max) {
    return min + rand() % (max - min + 1);
}
```

### qsort 示例

```c
#include <stdio.h>
#include <stdlib.h>

int compare_ints(const void *a, const void *b) {
    return (*(int *)a - *(int *)b);
}

int main(void) {
    int arr[] = {5, 2, 8, 1, 9, 3};
    int n = 6;

    qsort(arr, n, sizeof(int), compare_ints);

    for (int i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");

    return 0;
}
```

## ctype.h — 字符判断

### 字符分类函数

| 函数 | 说明 |
|------|------|
| `isalpha(c)` | 是否为字母 |
| `isdigit(c)` | 是否为数字 |
| `isalnum(c)` | 是否为字母或数字 |
| `isspace(c)` | 是否为空白字符 |
| `isupper(c)` | 是否为大写字母 |
| `islower(c)` | 是否为小写字母 |
| `iscntrl(c)` | 是否为控制字符 |
| `ispunct(c)` | 是否为标点符号 |
| `isxdigit(c)` | 是否为十六进制数字 |
| `isprint(c)` | 是否为可打印字符 |
| `isgraph(c)` | 是否为图形字符（不含空格） |

### 字符转换函数

| 函数 | 说明 |
|------|------|
| `toupper(c)` | 转换为大写 |
| `tolower(c)` | 转换为小写 |

### 示例

```c
#include <stdio.h>
#include <ctype.h>

int main(void) {
    char ch = 'A';

    if (isalpha(ch)) {
        printf("%c 是字母\n", ch);
    }

    if (isupper(ch)) {
        printf("%c 是大写字母\n", ch);
    }

    printf("小写: %c\n", tolower(ch));
    printf("大写: %c\n", toupper('a'));

    // 字符串处理
    char str[] = "Hello World 123";
    for (int i = 0; str[i]; i++) {
        if (isdigit(str[i])) {
            printf("数字: %c\n", str[i]);
        }
    }

    return 0;
}
```

## assert.h — 断言调试

### 基本用法

```c
#include <assert.h>

int divide(int a, int b) {
    assert(b != 0);  // 断言 b 不为零
    return a / b;
}
```

### 断言的工作原理

- **调试模式**：断言失败时输出错误信息并终止程序
- **发布模式**：定义 `NDEBUG` 后，断言被忽略

```c
#define NDEBUG
#include <assert.h>
// 此时 assert 宏被定义为 ((void)0)
```

### 断言的最佳实践

1. **用于检查不可能发生的情况**
2. **用于检查函数的前置条件**
3. **不要用断言替代错误处理**
4. **发布版本中禁用断言**
5. **断言失败应立即终止程序**

### 断言 vs 错误处理

| 特性 | assert | 错误处理 |
|------|--------|----------|
| 用途 | 检查内部错误 | 检查外部错误 |
| 发布模式 | 禁用 | 始终有效 |
| 失败行为 | 终止程序 | 返回错误码 |
| 性能 | 无开销 | 有开销 |

## errno.h — 错误码

### errno 全局变量

`errno` 是全局变量，存储最近一次系统调用或库函数的错误码。

```c
#include <errno.h>
#include <stdio.h>
#include <string.h>

FILE *fp = fopen("nonexistent.txt", "r");
if (fp == NULL) {
    printf("错误码: %d\n", errno);
    printf("错误信息: %s\n", strerror(errno));
    perror("fopen");  // 输出 "fopen: No such file or directory"
}
```

### 常见 errno 值

| 错误码 | 常量 | 说明 |
|--------|------|------|
| 1 | EPERM | 操作不被允许 |
| 2 | ENOENT | 文件或目录不存在 |
| 5 | EIO | I/O 错误 |
| 13 | EACCES | 权限不足 |
| 22 | EINVAL | 无效参数 |
| 24 | EMFILE | 打开文件数过多 |

### perror() — 输出错误信息

```c
void perror(const char *s);
```

输出格式：`s: 错误信息\n`

```c
FILE *fp = fopen("nonexistent.txt", "r");
if (fp == NULL) {
    perror("fopen");  // 输出 "fopen: No such file or directory"
}
```

## 防御式编程

### 错误码处理

```c
#include <stdio.h>
#include <errno.h>
#include <string.h>

typedef enum {
    SUCCESS = 0,
    ERR_NULL_PTR,
    ERR_INVALID_INPUT,
    ERR_IO_ERROR
} ErrorCode;

const char *error_message(ErrorCode code) {
    switch (code) {
        case SUCCESS:
            return "成功";
        case ERR_NULL_PTR:
            return "空指针";
        case ERR_INVALID_INPUT:
            return "无效输入";
        case ERR_IO_ERROR:
            return "I/O 错误";
        default:
            return "未知错误";
    }
}

ErrorCode safe_open(const char *filename, FILE **fp) {
    if (fp == NULL) {
        return ERR_NULL_PTR;
    }

    *fp = fopen(filename, "r");
    if (*fp == NULL) {
        return ERR_IO_ERROR;
    }

    return SUCCESS;
}

int main(void) {
    FILE *fp;
    ErrorCode code = safe_open("test.txt", &fp);

    if (code != SUCCESS) {
        fprintf(stderr, "错误: %s\n", error_message(code));
        if (code == ERR_IO_ERROR) {
            perror("fopen");
        }
        return 1;
    }

    // 使用文件...
    fclose(fp);
    return 0;
}
```

### 防御式编程原则

1. **检查所有输入参数**
2. **检查所有函数返回值**
3. **使用断言检查内部不变量**
4. **使用 const 保护不修改的数据**
5. **避免未定义行为**
6. **使用静态分析工具**
7. **编写单元测试**
