# 输入/输出库（stdio.h）

## 标准 I/O 概述

`stdio.h` 是 C 语言的标准输入输出库，提供了文件流操作和格式化输入输出功能。

## printf — 格式化输出

### 格式说明符结构

`printf` 的每个转换说明符以 `%` 开头，完整结构为：

```
%[标志][宽度][.精度][长度修饰符]转换字符
```

### 转换字符

| 转换字符 | 说明 | 示例 |
|----------|------|------|
| `%d` / `%i` | 有符号十进制整数 | 123 |
| `%u` | 无符号十进制整数 | 123 |
| `%o` | 无符号八进制 | 173 |
| `%x` / `%X` | 无符号十六进制（小写/大写） | 7b / 7B |
| `%f` | 十进制浮点数 | 3.140000 |
| `%e` / `%E` | 科学计数法 | 3.14e+00 |
| `%g` / `%G` | 自动选择 `%f` 或 `%e` | 3.14 |
| `%c` | 单个字符 | A |
| `%s` | 字符串 | hello |
| `%p` | 指针地址 | 0x7ffc... |
| `%%` | 输出一个百分号 | % |

### 标志

| 标志 | 说明 |
|------|------|
| `-` | 左对齐（默认右对齐） |
| `+` | 正数前显示 `+` 号 |
| 空格 | 正数前显示空格（与 `+` 冲突） |
| `#` | 备选形式，如 `%#x` 输出 `0x` 前缀 |
| `0` | 用 `0` 填充空白位（左对齐时无效） |

### 宽度与精度

- **宽度**：`%5d` 表示输出宽度至少 5 位，不足用空格补齐
- **精度**：`%.2f` 表示两位小数；`%.3s` 表示最多输出 3 个字符；`%.5d` 表示至少 5 位数字
- **组合**：`%8.3f`、`%-10s`、`%08.2f`

### 长度修饰符

| 修饰符 | 对应类型 | 示例 |
|--------|----------|------|
| `h` | `short` / `unsigned short` | `%hd` |
| `l` | `long` / `double` | `%ld`、`%lf` |
| `ll` | `long long` | `%lld` |
| `L` | `long double` | `%Lf` |
| `z` | `size_t` | `%zu` |

### 示例

```c
#include <stdio.h>

int main(void) {
    int n = 42;
    double pi = 3.14159;
    char name[] = "Alice";

    printf("%5d|\n", n);      // "   42|"，右对齐，宽度 5
    printf("%-5d|\n", n);     // "42   |"，左对齐
    printf("%+d\n", n);       // "+42"，显示正号
    printf("%05d\n", n);      // "00042"，用 0 填充
    printf("%.2f\n", pi);     // "3.14"，两位小数
    printf("%8.2f\n", pi);    // "    3.14"，宽度 8
    printf("%.3s\n", name);   // "Ali"，最多 3 个字符
    printf("%#x\n", n);       // "0x2a"，十六进制前缀
    printf("%ld\n", 123456L);        // long
    printf("%zu\n", sizeof(int));    // size_t

    return 0;
}
```

## scanf — 格式化输入

### 基本语法

```c
int scanf(const char *format, ...);
```

### 必须使用变量地址

`scanf` 需要修改调用者的变量，因此必须传入**变量的地址**（使用 `&` 取地址运算符）：

- 基本类型变量（int、double 等）必须写 `&变量名`
- 字符数组名本身就是地址，不需要再加 `&`

```c
#include <stdio.h>

int main(void) {
    int age;
    double height;
    char name[50];

    printf("请输入姓名：");
    scanf("%s", name);          // 数组名本身就是地址，不需要 &
    printf("请输入年龄：");
    scanf("%d", &age);          // 基本类型必须取地址
    printf("请输入身高：");
    scanf("%lf", &height);      // double 使用 %lf

    printf("姓名: %s, 年龄: %d, 身高: %.1f\n", name, age, height);

    return 0;
}
```

### 返回值

`scanf` 返回成功读取并赋值的参数个数，可用它判断是否读取成功：

```c
int n;
int result = scanf("%d", &n);
if (result == 1) {
    // 成功读取一个整数
} else if (result == EOF) {
    // 读取失败或遇到文件结束
} else {
    // 匹配失败（如输入了非数字）
}
```

### 注意事项

1. 默认以空白字符（空格、Tab、换行）分隔输入数据
2. `%s` 不能读取含空格的字符串，需要读取整行时用 `fgets`
3. `scanf` 后立即 `fgets` 可能读到残留的换行符，可用 `while (getchar() != '\n');` 清空输入缓冲区

## 文件流指针（FILE*）

### 基本概念

`FILE` 是 `stdio.h` 中定义的结构体类型，用于表示文件流。每个打开的文件都对应一个 `FILE*` 指针。

```c
FILE *fp;  // 文件流指针
```

### 文本文件与二进制文件

| 类型 | 特点 | 适用场景 |
|------|------|----------|
| 文本文件 | 以字符形式存储，自动处理换行转换 | 配置文件、源代码、日志 |
| 二进制文件 | 以原始字节形式存储 | 图片、音频、视频、数据文件 |

## 文件打开与关闭

### fopen() — 打开文件

```c
FILE *fopen(const char *filename, const char *mode);
```

### 打开模式

| 模式 | 说明 | 文件不存在 | 文件已存在 |
|------|------|-----------|-----------|
| `"r"` | 只读（文本） | 失败 | 从头读取 |
| `"w"` | 只写（文本） | 创建新文件 | 清空内容 |
| `"a"` | 追加（文本） | 创建新文件 | 在末尾追加 |
| `"rb"` | 只读（二进制） | 失败 | 从头读取 |
| `"wb"` | 只写（二进制） | 创建新文件 | 清空内容 |
| `"ab"` | 追加（二进制） | 创建新文件 | 在末尾追加 |
| `"r+"` | 读写（文本） | 失败 | 从头读写 |
| `"w+"` | 读写（文本） | 创建新文件 | 清空内容 |
| `"a+"` | 读写（文本） | 创建新文件 | 读取+追加 |

### 示例

```c
#include <stdio.h>

int main(void) {
    // 打开文件
    FILE *fp = fopen("test.txt", "r");
    if (fp == NULL) {
        perror("打开文件失败");
        return 1;
    }

    // 操作文件...

    // 关闭文件
    fclose(fp);

    return 0;
}
```

### fclose() — 关闭文件

```c
int fclose(FILE *fp);
```

关闭文件时会刷新缓冲区，释放资源。

## 顺序读写

### 字符读写

#### fputc — 写字符

```c
int fputc(int character, FILE *stream);
```

```c
FILE *fp = fopen("output.txt", "w");
fputc('A', fp);
fputc('\n', fp);
fclose(fp);
```

#### fgetc — 读字符

```c
int fgetc(FILE *stream);
```

```c
FILE *fp = fopen("input.txt", "r");
int ch;
while ((ch = fgetc(fp)) != EOF) {
    putchar(ch);
}
fclose(fp);
```

### 字符串读写

#### fputs — 写字符串

```c
int fputs(const char *str, FILE *stream);
```

```c
FILE *fp = fopen("output.txt", "w");
fputs("Hello, World!\n", fp);
fclose(fp);
```

#### fgets — 读字符串

```c
char *fgets(char *str, int n, FILE *stream);
```

```c
FILE *fp = fopen("input.txt", "r");
char buf[100];
while (fgets(buf, sizeof(buf), fp) != NULL) {
    printf("%s", buf);
}
fclose(fp);
```

### 格式化读写

#### fprintf — 格式化写

```c
int fprintf(FILE *stream, const char *format, ...);
```

```c
FILE *fp = fopen("output.txt", "w");
fprintf(fp, "Name: %s, Age: %d\n", "Alice", 20);
fclose(fp);
```

#### fscanf — 格式化读

```c
int fscanf(FILE *stream, const char *format, ...);
```

```c
FILE *fp = fopen("input.txt", "r");
char name[50];
int age;
fscanf(fp, "Name: %s, Age: %d", name, &age);
fclose(fp);
```

## 二进制读写

### fwrite — 写二进制数据

```c
size_t fwrite(const void *ptr, size_t size, size_t nmemb, FILE *stream);
```

```c
int arr[] = {1, 2, 3, 4, 5};
FILE *fp = fopen("data.bin", "wb");
fwrite(arr, sizeof(int), 5, fp);
fclose(fp);
```

### fread — 读二进制数据

```c
size_t fread(void *ptr, size_t size, size_t nmemb, FILE *stream);
```

```c
int arr[5];
FILE *fp = fopen("data.bin", "rb");
size_t count = fread(arr, sizeof(int), 5, fp);
printf("读取了 %zu 个元素\n", count);
fclose(fp);
```

## 标准流

| 流 | 指针 | 说明 |
|------|------|------|
| stdin | `stdin` | 标准输入（键盘） |
| stdout | `stdout` | 标准输出（终端） |
| stderr | `stderr` | 标准错误输出 |

### 重定向

```bash
# 输出重定向
./program > output.txt

# 输入重定向
./program < input.txt

# 错误重定向
./program 2> error.txt

# 读写重定向
./program < input.txt > output.txt 2> error.txt
```

## 文件操作最佳实践

1. **始终检查 fopen 的返回值**
2. **操作完成后关闭文件**
3. **使用 perror 输出错误信息**
4. **使用二进制模式读写二进制数据**
5. **使用 fgets 替代 fscanf 读取字符串**
