# 时间库（time.h）

## 概述

`time.h` 提供了时间相关的函数，包括时间戳获取、日期格式化和性能计时。

## 时间戳

### time() — 获取当前时间

```c
time_t time(time_t *timer);
```

返回自 1970 年 1 月 1 日 00:00:00 UTC（Unix 纪元）以来的秒数。

```c
#include <stdio.h>
#include <time.h>

int main(void) {
    time_t now = time(NULL);
    printf("当前时间戳: %ld\n", now);

    // 转换为本地时间
    struct tm *local = localtime(&now);
    printf("本地时间: %d-%02d-%02d %02d:%02d:%02d\n",
           local->tm_year + 1900, local->tm_mon + 1, local->tm_mday,
           local->tm_hour, local->tm_min, local->tm_sec);

    return 0;
}
```

## 日期格式化

### struct tm 结构

```c
struct tm {
    int tm_sec;    // 秒 (0-61)
    int tm_min;    // 分 (0-59)
    int tm_hour;   // 时 (0-23)
    int tm_mday;   // 日 (1-31)
    int tm_mon;    // 月 (0-11)
    int tm_year;   // 年 (从 1900 年起)
    int tm_wday;   // 星期 (0-6, 0=周日)
    int tm_yday;   // 一年中的第几天 (0-365)
    int tm_isdst;  // 夏令时标志
};
```

### asctime() — 格式化时间字符串

```c
char *asctime(const struct tm *timeptr);
```

```c
time_t now = time(NULL);
struct tm *local = localtime(&now);
printf("%s", asctime(local));  // 输出类似 "Wed Jun 15 10:30:00 2024\n"
```

### ctime() — 时间戳转字符串

```c
char *ctime(const time_t *timer);
```

```c
time_t now = time(NULL);
printf("%s", ctime(&now));  // 输出类似 "Wed Jun 15 10:30:00 2024\n"
```

### strftime() — 自定义格式化

```c
size_t strftime(char *str, size_t maxsize, const char *format, const struct tm *timeptr);
```

#### 常用格式说明符

| 说明符 | 含义 | 示例 |
|--------|------|------|
| `%Y` | 四位年份 | 2024 |
| `%m` | 两位月份 | 01-12 |
| `%d` | 两位日期 | 01-31 |
| `%H` | 两位小时（24小时制） | 00-23 |
| `%M` | 两位分钟 | 00-59 |
| `%S` | 两位秒 | 00-59 |
| `%A` | 星期全称 | Monday |
| `%a` | 星期缩写 | Mon |
| `%B` | 月份全称 | January |
| `%b` | 月份缩写 | Jan |
| `%I` | 两位小时（12小时制） | 01-12 |
| `%p` | AM/PM | AM |
| `%j` | 一年中的第几天 | 001-366 |
| `%U` | 一年中的第几周（周日为一周第一天） | 00-53 |
| `%W` | 一年中的第几周（周一为一周第一天） | 00-53 |
| `%z` | UTC 时区偏移 | +0800 |
| `%Z` | 时区名称或缩写 | CST |
| `%F` | 等价于 `%Y-%m-%d`（C99） | 2024-06-15 |
| `%T` | 等价于 `%H:%M:%S`（C99） | 10:30:00 |

```c
time_t now = time(NULL);
struct tm *local = localtime(&now);

char buf[100];
strftime(buf, sizeof(buf), "%Y-%m-%d %H:%M:%S", local);
printf("格式化时间: %s\n", buf);

strftime(buf, sizeof(buf), "%Y年%m月%d日 %A", local);
printf("中文格式: %s\n", buf);
```

## 性能计时

### clock() — CPU 时间

```c
clock_t clock(void);
```

返回程序启动以来的 CPU 时间（时钟滴打数）。

```c
#include <stdio.h>
#include <time.h>

int main(void) {
    clock_t start = clock();

    // 执行一些操作
    long sum = 0;
    for (int i = 0; i < 100000000; i++) {
        sum += i;
    }

    clock_t end = clock();
    double elapsed = (double)(end - start) / CLOCKS_PER_SEC;
    printf("耗时: %.3f 秒\n", elapsed);
    printf("结果: %ld\n", sum);

    return 0;
}
```

### difftime() — 时间差

```c
double difftime(time_t time1, time_t time0);
```

返回两个时间戳之间的差值（秒）。

```c
time_t start = time(NULL);
// 执行一些操作
time_t end = time(NULL);
double elapsed = difftime(end, start);
printf("耗时: %.0f 秒\n", elapsed);
```

## 时间转换函数

### gmtime() — UTC 时间

```c
struct tm *gmtime(const time_t *timer);
```

将时间戳转换为 UTC 时间（不考虑时区）。

### localtime() — 本地时间

```c
struct tm *localtime(const time_t *timer);
```

将时间戳转换为本地时间（考虑时区）。

### mktime() — 时间结构转时间戳

```c
time_t mktime(struct tm *timeptr);
```

将 `struct tm` 转换为时间戳。

```c
struct tm timeinfo = {0};
timeinfo.tm_year = 2024 - 1900;  // 年份从 1900 年起
timeinfo.tm_mon = 5;              // 月份 0-11（5 = 6 月）
timeinfo.tm_mday = 15;            // 日
timeinfo.tm_hour = 10;            // 时
timeinfo.tm_min = 30;             // 分
timeinfo.tm_sec = 0;              // 秒

time_t timestamp = mktime(&timeinfo);
printf("时间戳: %ld\n", timestamp);
```

## 时间库示例

### 计算程序运行时间

```c
#include <stdio.h>
#include <time.h>

int main(void) {
    clock_t start = clock();

    // 模拟耗时操作
    for (volatile int i = 0; i < 100000000; i++) {
        // 空循环
    }

    clock_t end = clock();
    double cpu_time = (double)(end - start) / CLOCKS_PER_SEC;
    printf("CPU 时间: %.3f 秒\n", cpu_time);

    return 0;
}
```

### 生成随机种子

```c
#include <stdio.h>
#include <stdlib.h>
#include <time.h>

int main(void) {
    srand((unsigned int)time(NULL));  // 使用当前时间作为随机种子

    for (int i = 0; i < 5; i++) {
        printf("随机数: %d\n", rand());
    }

    return 0;
}
```

## 时间库注意事项

1. **`localtime` 和 `gmtime` 返回静态分配的指针**，多次调用会覆盖结果
2. **`time_t` 在 32 位系统上可能溢出**（2038 年问题）
3. **`clock()` 测量的是 CPU 时间，不是墙上时钟时间**
4. **`CLOCKS_PER_SEC` 的值因平台而异**
5. **`strftime` 的缓冲区大小应足够**
