# 10-条件状语从句

> 条件状语从句表达"如果/除非/只要…就…"，由 if、unless、as long as、provided (that)、in case 等引导。

---

## 一、真实条件句

真实条件句分为三类，分别对应**一般/过去/将来**的场景。

### ① 零条件句（Zero conditional）

表达**普遍真理、习惯、自然现象**的一般性条件。

> **If water reaches 100°C, it boils.**（水达到 100 度就烧开。）
> If you heat ice, it melts.
> If you put salt in soup, it tastes salty.

| 结构 | 主 + 谓 | 从 + 谓 |
|---|---|---|
| 普遍真理 | if + 一般现在 | 一般现在 |

### ② 第一条件句（First conditional）

表达**将来可能性较大的条件**。

> **If it rains tomorrow, I will stay home.**（如果明天下雨，我就待在家里。）
> If you work hard, you will succeed.

| 结构 | 主 + 谓 | 从 + 谓 |
|---|---|---|
| 真实可能 | will + 动词原形 | if + 一般现在 |

### ③ 第二条件句（Second conditional）

表达**与现在/将来事实相反、可能性较小的条件**。

> **If I were rich, I would buy a huge carrot farm.**（要是我有钱，就会买农场。——但我并不有钱。）

| 结构 | 主 + 谓 | 从 + 谓 |
|---|---|---|
| 现在/将来相反 | would + 动词原形 | if + 过去式 (were / did) |

> **Grammar Club 观点**：英语的 `were` 在第二条件中不受人称限制 —— `If I were you`、`If he were taller` 都是标准写法，这正是「语气」而非「时态」的体现。

---

## 二、虚拟条件句

虚拟条件句表示与**过去事实**相反（第三条件）或跨**时间**影**响**（混合条件）。

### ① 第三条件句（Third conditional）

> **If the rabbit had saved the carrot, he would not have been hungry.**（如果兔子保存了胡萝卜，就不会饿了。——但他没保存。）

| 结构 | 主 + 谓 | 从 + 谓 |
|---|---|---|
| 过去相反 | would have + 过去分词 | if + had + 过去分词 |

### ② 混合条件句（Mixed conditional）

把不同**时间**虚拟形式混合使用，表达跨**时间**的因果。

| 组合 | 解释 | 例句 |
|---|---|---|
| if + 过去完成 → would + 原形 | **过去**影响现在 | **If I had studied**, I **would know** the answer. |
| if + 过去式 → would have + 过去分词 | **现在**影响**过去** | **If I weren't** lazy, I **would have finished**. |

> **例1**（过去影响现在）：If the rabbit had saved the carrot yesterday, he would not be hungry now.
> **例2**（现在影响过去）：If I weren't so shy, I would have spoken up at the meeting.

---

## 三、基本引导词：if

- 条件永远用**现在时**替代将来时（从句不用 will）：
  > If it rains, we will stay home.（如果下雨，我们就待在家里。）
- 虚拟条件的“退一格”原则详见《01-虚拟语气》。

> **Grammar Club 观点**：条件句的“如果”不是简单的因果，而是一种**“可能空间”的设定**。零/一条件映射到现实可能性；二/三条件把动词往“过去”退一格，从而把假设的可能性等级清楚地传递给读者。

---

## 四、其他引导词

| 引导词 | 含义 | 例句 |
|---|---|---|
| unless | 除非 | Unless you like this video, you will not give it a thumbs-up.（除非你喜欢这个视频，否则你不会给它点赞。） |
| as long as / so long as | 只要 | As long as I make excellent videos, you will remain my follower.（只要我做出优质视频，你就会一直是我的粉丝。） |
| provided (that) / providing (that) | 假如、如果 | Provided that my video is excellent, you will give it a thumbs-up. |
| in case | 万一 | In case you don't understand, please comment below.（如果你不明白，请在下方留言。） |
| even if / even though | 即使 | Even if it rains, I'll watch your video.（即使下雨，我也会看你的视频。） |
| as if / as though | 好像似的 | She speaks as if she were the teacher.（她说话好像自己就是老师。） |
| now that | 既然 | Now that you've found this video, give it a thumbs-up! |

> 提示：`unless` 相当于 `if … not`；`as long as` / `so long as` 强调“只要满足某条件”；`in case` 表达防备而非普通条件（= “以防”）。

## 五、常见条件句模板背诵

| 类别 | 公式 | 例句 |
|---|---|---|
| 零条件 | if + 一般现在，一般现在 | If water reaches 100°C, it boils. |
| 第一条件 | if + 一般现在，will + 原形 | If it rains, I'll stay home. |
| 第二条件 | if + 过去式，would + 原形 | If I were rich, I'd buy a farm. |
| 第三条件 | if + 过去完成，would have + 过去分词 | If I had studied, I'd have passed. |
| 混合条件 | if + 过去完成，would + 原形 | If you'd told me, I'd help you now. |
