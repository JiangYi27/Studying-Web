# 13-原因、目的、结果状语从句

---

## 一、原因状语从句：because / since / as / for

> **The rabbit ate the carrot because he was hungry.**（兔子吃了胡萝卜，因为他饿了。）

| 引导词 | 语气强度 | 例句 |
|---|---|---|
| because | 最强（原因核心） | I ate because I was hungry. |
| since | 中（既然） | Since you are hungry, you can eat the carrot.（既然你饿了，你可以吃这根胡萝卜。） |
| as | 较弱（附带原因） | As you were not here, we ate the carrot without you.（因为你不在，我们没带你吃。） |

### 语序

- because 从句可放在主句前或后。
- since / as 从句通常放在句首或句后的随意，语气较委婉。

### because vs for

for 是并列连词，连接两个并列句，表示"于是/因为"的补充解释，并非原因状语从句：

> **You must really like me, for you have given all my videos a thumbs-up.**（你一定很喜欢我，因为你给我所有视频都点了赞。）

---

## 二、目的状语从句：in order that / so that

目的"事件A"（主句）＋ 目的从句（用 in order that / so that 引导），从句中一般用情态助动词 can / could / may / might / should / would：

> **In order that I could finish the video in time, I pulled an all-nighter.**（为了按时完成视频，我熬了个通宵。）

> **I left early so that I could catch the bus.**（我早点出发，以便赶上公交。）

---

## 三、结果状语从句：so that / so … that / such … that

结果从句解释主句动作产生的结果；或说明原因达到某种程度：

| 结构 | 例句 |
|---|---|
| so that + 从句（结果） | I ate a lot of carrots for lunch, **so that I wasn't hungry in the afternoon.**（我中午吃很多胡萝卜，因此下午不饿。） |
| so + 形/副 + that | I ate **so many** carrots that I felt sick. |
| so that（程度导致结果） | The temperature was low **so that** the lake froze.（温度很低，湖面都结了冰。） |

### So 连接并列句（不是结果从句）

So（因此、所以）连接两个并列句构成并列复合句，而非结果状语从句：

> I like this video, **so** I'll give it a thumbs-up.（我喜欢这个视频，所以我会给它点赞。）

---

## 四、易混易错：so … that vs such … that

> "如此…以至于"有两种写法——`so + 形容词/副词 + that` 和 `such + 名词 + that`。**关键在于 that 前面跟的是形容词/副词，还是名词**。这是结果从句最高频的考点。

### 1. 一句话认清区别

| 结构 | that 前面接什么 | 例句 |
|---|---|---|
| **so + 形/副 + that** | 形容词或副词 | The carrot was **so big that** the rabbit couldn't finish it. |
| **such + 名词 + that** | 名词（名词可前带形容词） | It was **such a big carrot that** the rabbit couldn't finish it. |

> - so 后面**只能接形容词/副词**：`so big`、`so quickly`
> - such 后面**必须接名词**：`such a big carrot`、`such big carrots`

### 2. 同一个意思，两种写法

> - `The carrot was **so big that** the rabbit couldn't finish it.`（so + 形容词 big）
> - `It was **such a big carrot that** the rabbit couldn't finish it.`（such + 名词 a big carrot）

两者意思相同（"胡萝卜太大，兔子吃不完"），只是 so 强调"有多大多大"、such 强调"是这样一种东西"。

### 3. 三个高频陷阱

**① such + a/an + 形容词 + 单数名词**
> 单数可数名词前，such 后要有冠词：`such **a** big carrot`。不能说 ~~such big carrot~~。

**② so + many / much / few / little + 名词**
> 当要强调"数量多/少"时，即使后面是名词，也用 **so**（不能用 such）：
> - `There were **so many** carrots that ...`（有那么多胡萝卜…）
> - `There was **so little** time that ...`（时间那么少…）
> - 这里 many/much/few/little 是**量词**，规则是"so + 量词 + 名词"。

**③ 名词是复数 / 不可数时，such 后无冠词**
> - `They were **such big carrots that** ...`（复数，无 a/an）
> - `It was **such good news that** ...`（不可数，无 a/an）

### 4. 速查表

| 要写 | 结构 | 例子 |
|---|---|---|
| 形容词 | so + 形 + that | so **hot** that |
| 副词 | so + 副 + that | so **fast** that |
| 单数名词（带形容词） | such + a/an + 形 + 名 + that | such **a hot day** that |
| 复数名词 | such + 形 + 复数名 + that | such **hot days** that |
| 数量（many/much/few/little） | so + 量词 + 名 + that | so **many people** that |

### 5. 一句话总结

> **so + 形容词/副词；such + 名词**。见到名词就用 such（并注意 a/an、复数、不可数三种冠词处理）；见到形容词/副词或 many/much/few/little 就用 so。
