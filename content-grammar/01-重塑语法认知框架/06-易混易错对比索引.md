## 二、速查（一句话记住每类对比的核心）

| 易混对 | 一秒区分 |
|---|---|
| 主谓宾宾补 vs 主谓宾宾 | 第二个名词能加 be 连到宾语上 = 宾补 |
| 谓语 vs 谓语动词 | 谓语动词是谓语的一部分 |
| which vs that | 不定代词/最高级 → that；逗号/介词前 → which |
| 表语从句 vs 同位语从句 | 在 be 后 = 表语；在名词后 = 同位语 |
| 不定式 vs 动名词 | to do = 还没做；doing = 已做了 |
| mustn't vs don't have to | 禁止 vs 不必 |
| a number of vs the number of | a number→复数；the number→单数 |
| its vs it's | 无撇号=它(的)；有撇号=它是 |
