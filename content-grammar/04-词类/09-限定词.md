# 09-限定词

> 限定词（Determiner）是限定其后名词"讨论/描述范围"的词。任何能限定名词的词都可视为限定词；它们以**位置**又可分前位、中位、后位限定词。

---

## 一、什么是限定词

| 限定词 | 示例 |
|---|---|
| 指示代词 | this carrot、that carrot（这根、那根胡萝卜） |
| 物主代词 | my carrot、your carrot（我的、你的胡萝卜） |
| 名词所有格 | the wolf's carrot、the pig's carrot |
| 不定代词 | every carrot、no carrot、many carrots、few carrots |
| 量词 | a lot of carrots、a small number of carrots |
| 基数词 | two carrots、three carrots |
| 序数词 | the second carrot、the third carrot |

结论：**只要是限定了其后名词的词，都可称作"限定词"**。

---

## 二、按词类划分的限定词

| 类别 | 示例 |
|---|---|
| 冠词 | a / an / the |
| 名词所有格 | the rabbit's、the wolf's |
| 物主代词 | my、your、his、her… |
| 指示代词 | this、that… |
| 疑问代词 | whose、which… |
| 关系代词 | whose、which… |
| 不定代词 | some、many、each、any… |
| 量词 | a lot of、plenty of… |
| 基数词 | one、two、three… |
| 序数词 | the first、the second… |

---

## 三、按位置划分的限定词

一个名词前可叠加多个限定词，按先后位置分三类：

| 位置 | 包含的限定词 |
|---|---|
| 前位限定词 | 某些不定代词（all、both、half）、倍数词、分数词… |
| 中位限定词 | 冠词、物主代词、指示代词、某些不定代词… |
| 后位限定词 | 基数词、序数词、量词… |

**顺序示例（先前位，再中位，最后后位）：**

| 正确 | 错误 |
|---|---|
| half **my** carrots（我一半的胡萝卜） | ~~my half carrots~~ |
| her **last** carrot（她最后一根胡萝卜） | ~~last her carrot~~ |
| all **ten** carrots（全部十根胡萝卜） | ~~ten all carrots~~ |

> 规律：前位 > 中位 > 后位，顺序基本固定，不可随意调换。记忆口诀：all/both/half（前）+ 冠词/物主（中）+ 数个/序数/量词（后）。

---

## 四、语法填空实战 · 限定词

> 限定词在语法填空中常作为"填一个词限定名词"的考点。最容易挖空的是**易混限定词对**——它们看着像，用法差很远。

### 1. each vs every（每个）

| 限定词 | 强调 | 谓语 | 能否单独作代词 |
|---|---|---|---|
| each | **个体**（一个一个） | 单数 | 能（Each of them is…） |
| every | **整体**（所有） | 单数 | 不能（不说 Every of…，要说 every one of） |

> - `**Each** rabbit has a carrot.`（每只兔子——强调各自）
> - `**Every** rabbit has a carrot.`（所有兔子——强调全体）
> - 对：`Each of the rabbits`；错：~~Every of the rabbits~~ → every **one** of the rabbits

### 2. another vs other vs others（另一个/其它的）

| 词 | 用法 | 例子 |
|---|---|---|
| **another** | 另一个（单数，不限定范围内） | I want **another** carrot.（再来一根） |
| **the other** | 两者中的**另一个** | I have two carrots. One is big, **the other** is small. |
| **other** + 复数 | 其它的（作定语） | I don't like **other** vegetables. |
| **others** | 其它的（作代词，= other + 复数名词） | Some like carrots, **others** like potatoes. |
| **the others** | 剩余的那些（特指） | Three left, **the others** stayed. |

> **判断**：两者中另一个用 the other；不限定"再来一个"用 another；作代词泛指用 others。

### 3. few / a few / little / a little（几乎没有 vs 有一点）

| 词 | 修饰 | 含义 | 例子 |
|---|---|---|---|
| **few** | 可数复数 | 几乎没有（否定） | Few rabbits like this.（很少兔子喜欢，几乎没） |
| **a few** | 可数复数 | 有几个（肯定） | I have **a few** carrots.（有几个） |
| **little** | 不可数 | 几乎没有（否定） | There is **little** water left.（水几乎没了） |
| **a little** | 不可数 | 有一点（肯定） | I have **a little** milk.（有一点） |

> **记忆**：**a few / a little 有 a 就是"有一点"（肯定）**；**few / little 没 a 就是"几乎没有"（否定）**。

### 4. many / much / a lot of / plenty of（数量）

| 词 | 修饰 | 谓语 |
|---|---|---|
| many | 可数复数 | 复数 |
| much | 不可数 | 单数 |
| a lot of / lots of | 可数/不可数都行 | 看名词 |
| plenty of | 可数/不可数都行 | 看名词 |
| a number of | 可数复数 | 复数 |
| the number of | 可数复数 | 单数（"数量"是主语） |

> 填空：空后是可数复数名词 → many / a number of；空后是不可数名词 → much；两者皆可 → a lot of / plenty of。

### 5. 易错点：限定词与名词的单复数搭配

> - **each / every / either / neither + 单数名词**：`each rabbit`、`either side`
> - **both / many / a few / several + 复数名词**：`both rabbits`、`several carrots`
> - **much / little / a little + 不可数名词**：`much water`

### 6. 一句话总结

> **限定词填空先看名词的可数性与单复数**：each/every + 单数，both/many + 复数，much/little + 不可数；再辨析易混对（each/every、another/the other/others、few/a few、little/a little）。
