# 07-不规则动词高频表

> 不规则动词没有统一的过去式 / 过去分词变化规律，只能记。但它们出现频率极高——把下面这张表背熟，阅读和写作的流畅度会显著提升。

---

## 一、为什么需要这张表

上一篇《16 种时态》里提到，过去完成时（had + 过去分词）、被动语态（be + 过去分词）、完成进行时（have been + 现在分词）都需要动词的**过去式**和**过去分词**。

- 规则动词：过去式 / 过去分词都是加 **-ed**（play → played → played）。
- **不规则动词**：变化没有规律，只能逐个记。

> 虽然叫"不规则"，但很多词的变化其实可以归入若干常见模式——找到规律后记忆难度会大幅降低。

---

## 三、易混词对照（考试 / 阅读高频陷阱）

| 原形 | 过去式 | 过去分词 | 易混淆点 |
|---|---|---|---|
| lie（躺） | lay | lain | 与"放置 lay / laid / laid"混淆 |
| lay（放置） | laid | laid | — |
| lie（说谎） | lied | lied | 与"躺 lie / lay / lain"混淆 |
| rise（升起） | rose | risen | 与"raise 及物 raise / raised / raised"混淆 |
| raise（抬起） | raised | raised | — |
| set（放置） | set | set | 与"sit / sat / sat"混淆 |
| sit（坐） | sat | sat | — |

> - **lie（躺）→ lay → lain**：不及物，无宾语：`I lay down on the grass.`
> - **lay（放置）→ laid → laid**：及物，要带宾语：`I laid the carrot on the table.`
> - **rise → rose → risen**：不及物，自行升起：`The sun rose.`
> - **raise → raised → raised**：及物，主动举起：`I raised my hand.`
