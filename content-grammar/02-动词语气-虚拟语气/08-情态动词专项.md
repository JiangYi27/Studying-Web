# 08-情态动词专项

> 《04-助动词》已经介绍了 can / may / will / shall 这一类情态助动词的基本用法。本篇在这基础上补全剩余的情态动词——**must、have to、need、dare、used to**——并重点讲清"情态动词表推测"这块中文学习者最容易混淆的点。

---

## 一、情态动词的共性（回顾）

情态动词（Modal verb / Modal auxiliary）都遵循同样的规则：

1. 后接**动词原形**，本身没有 to、不加 -s、不变时态（个别除外）。
   > 对：The rabbit **must eat** a carrot.（兔子必须吃根胡萝卜。）
   > 错：The rabbit must **to eat** / must **eats** …（×）
2. 否定在情态动词后加 **not**，疑问把情态动词提前。
   > **Must** I eat this carrot?　**Need** you go now?
3. 大多数情态动词有"本义"（能力、义务、许可）和"推测义"（对现在 / 过去的推断）两副面孔。

---

## 二、义务与必须：must vs have to

两者都表示"必须"，但出发点不同——这是最经典的辨析题。

| 对比 | must | have to |
|---|---|---|
| 出发点 | **主观**（说话人认为必须） | **客观**（外在规则 / 情况迫使） |
| 时态 | 只有现在时 | 可有时态变化（had to、will have to） |
| 否定含义 | mustn't = **禁止** | don't have to = **不必**（≠ 禁止） |

> - `The rabbit must go now.`（兔子主观认为必须走了。）
> - `The rabbit has to go now.`（有外部原因——比如门要关了——逼得兔子不得不走。）
> - `You mustn't eat the carrot.`（**千万别吃**这根胡萝卜——禁止。）
> - `You don't have to eat the carrot.`（你**不必**吃，但可以吃——并非禁止。）

> 记忆：**must 出于内心，have to 出于客观；mustn't 是禁止，don't have to 是没必要。**

---

## 三、need：需要；dare：敢于

`need` 和 `dare` 很特殊——它们既可以作**情态动词**，也可以作**实义动词**，用法完全不同。

### 1. Need 的两种身份

| 身份 | 用法 | 例句 |
|---|---|---|
| 情态动词（用于否定 / 疑问） | need + 动词原形，不加 to | `You needn't come.`（你不必来。）`Need I go?`（我需要去吗？） |
| 实义动词（用于陈述） | need + to do / need to be | `You need **to** come.`（你需要来。） |

> 规律：**情态 need 常见于否定（needn't）和疑问**；陈述句里需要帮助时，用实义动词 `need to do`。

> `needn't have done`（**本不必做却做了**）：
> **You needn't have cooked so much.**（你原本不必做这么多菜——但你做了。）

### 2. Dare 的两种身份

| 身份 | 用法 | 例句 |
|---|---|---|
| 情态动词（否定 / 疑问） | dare + 动词原形 | `I daren't go.`（我不敢去。）`Dare you jump?`（你敢跳吗？） |
| 实义动词（正式语境） | dare to do | `I don't dare to go.`（我不敢去。） |

> 现代口语里，实义动词用法（don't dare to do）更常见；情态 dare 多见于正式文体或否定句。

## 四、used to：过去常常（现在不）

`used to do` 表示"过去经常发生、但现在已经不再"的习惯或状态。

| 结构 | 例句 | 含义 |
|---|---|---|
| used to + 原形（过去习惯） | The rabbit **used to eat** a carrot every hour. | 兔子过去每小时吃一根，现在不了 |
| used to + be（过去状态） | There **used to be** a carrot farm here. | 这里曾经有个胡萝卜农场 |
| be used to + 名词 / 动名词（习惯） | The rabbit **is used to** eating carrots. | 兔子已习惯吃胡萝卜（现在） |

> **易混淆**：
> - `used to do`＝过去（习惯），后面接**动词原形**。
> - `be used to doing`＝现在已习惯，后面接**动名词（-ing）**。
> - `be used to do`＝被用来做……（被动），后面接动词原形。

> - `I used to watch cartoons.`（我过去常看动画片。）
> - `I am used to getting up early.`（我习惯了早起。）
> - `The hammer is used to hit nails.`（锤子被用来敲钉子。）

## 五、情态动词表推测（判断"可能性高低"）

这是情态动词最难的用法：不用来表示"能力 / 义务"，而是**根据已知情况推断**某件事"有多大可能"发生或已经发生。关键是**记住可能性等级**。

### 1. 对现在的推测：情态动词 + 动词原形 / be

| 可能程度 | 情态动词 | 例句 |
|---|---|---|
| 几乎确定（肯定） | must | The carrots are gone, so the rabbit **must have eaten** them.（胡萝卜不见了，兔子肯定吃了它们。） |
| 很可能 | should / ought to | The rabbit **should be** at home by now.（兔子这会儿应该到家了。） |
| 有可能（中性） | may / can | It **may rain** tomorrow.（明天可能下雨。） |
| 可能性较低 | might / could | He **might be** sick.（他或许病了——把握不大。） |
| 几乎不可能 | can't / couldn't | That **can't be** the rabbit's carrot——he's a vegetarian！（那不可能是兔子的胡萝卜——他吃素！） |

> **must ≠ can't**：must 表达"几乎肯定"，can't 表达"几乎肯定不是"。两者表示确定的推测，语气相反，但都不能用来表示"可能是也可能不是"（那是 may / might）。

### 2. 对过去的推测：情态动词 + have + 过去分词

| 可能程度 | 结构 | 例句 |
|---|---|---|
| 几乎肯定（过去） | must have done | The dishes are clean, so the rabbit **must have washed** them.（盘子很干净，兔子肯定洗过了。） |
| 本可却没做 / 责怪 | should have done | You **should have told** me earlier.（你本该早点告诉我的。） |
| 本不必却做了 | needn't have done | We **needn't have worried**.（我们本不必担心的。） |
| 可能已做过 | may / might have done | He **may have taken** the wrong road.（他可能走了错路。） |
| 几乎不可能做过 | can't / couldn't have done | She **can't have said** that.（她不可能说过那话。） |

> **must have done（肯定做过）** 与 **can't have done（肯定没做过）** 是一对对立的过去推测；`may/might/could have done` 表示不确定的过去可能。

## 六、情态动词 + 完成态的意义重心（总表）

做完一件事之后，用"情态动词 + have + 过去分词"回看这件事，附带一种评价语气：

| 结构 | 核心含义 | 典型语气 |
|---|---|---|
| must have done | 过去几乎肯定发生了 | 推测、确定 |
| could have done | 过去本可以（但没做） | 惋惜、假设 |
| would have done | 虚拟条件下本会做 | 假设（与虚拟语气相扣） |
| should / ought to have done | 本应该做（却没做） | 责备、遗憾 |
| needn't have done | 本不必做（却做了） | 轻微责怪 / 多余 |
| may / might have done | 过去或许发生了 | 不确定推测 |

> 这组结构是"虚拟语气 + 情态动词"的交叉地带，建议与《02-虚拟语气》的"与过去相反"一节对照学习。

## 七、情态动词否定含义对照表

同一个"Do it"用不同情态动词否定，意思差别很大：

| 句子 | 含义 |
|---|---|
| You **can't** do it.（can't） | 你**不能 / 没能力**做 |
| You **may not** do it.（may not） | 你**不可以**做（不许可） |
| You **mustn't** do it.（mustn't） | 你**禁止 / 千万别**做 |
| You **don't have to** do it.（don't have to） | 你**不必**做（但可以做） |
| You **needn't** do it.（needn't） | 你**不必**做（没必要） |
| You **shouldn't** do it.（shouldn't） | 你**不应该**做（有建议劝告） |
| You **sha'n't** do it.（shan't） | 正式用语，你**不许**做 |

> 重点区分三组：
> - **mustn't（禁止）** vs **don't have to / needn't（不必）**——语气天差地别。
> - **can't（没能力 / 不可能）** vs **may not（不许可）**。
> - **shouldn't（有劝告）** 比 **mustn't（命令）** 语气柔和。
